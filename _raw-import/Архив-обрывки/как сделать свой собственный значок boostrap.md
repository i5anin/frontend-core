Чтобы сделать свой собственный значок в Bootstrap, вы можете создать новый SVG-значок или использовать существующий SVG-файл, а затем выполнить следующие шаги:

1.  Wrap your SVG in a `<span>` tag with the class `icon` and the `aria-hidden` attribute set to `true`. You can also include any additional classes for styling.

```html
<span class="icon my-custom-icon" aria-hidden="true">
  <svg>
    <!-- Your SVG code here -->
  </svg>
</span>

```

2.  Define the icon's styles in your [CSS](../Работа/CSS). You can set the `fill` and `stroke` colors, as well as the `width` and `height`.

```css
.my-custom-icon {
  display: inline-block;
  width: 1em;
  height: 1em;
  fill: currentColor;
  stroke: currentColor;
  stroke-width: 0;
}

```

3.  Optionally, add the icon to a custom icon font by using a tool like Fontello or IcoMoon. You can upload your SVG icon and generate a custom font file with a [CSS](../Работа/CSS) file that includes the necessary classes to use the icons.

```css
/* Generated by Fontello (https://fontello.com) */

@font-face {
  font-family: 'my-custom-icons';
  src: url('my-custom-icons.eot?84236939');
  src: url('my-custom-icons.eot?84236939#iefix') format('embedded-opentype'),
       url('my-custom-icons.woff2?84236939') format('woff2'),
       url('my-custom-icons.woff?84236939') format('woff'),
       url('my-custom-icons.ttf?84236939') format('truetype'),
       url('my-custom-icons.svg?84236939#my-custom-icons') format('svg');
  font-weight: normal;
  font-style: normal;
}

[class^="icon-"], [class*=" icon-"] {
  /* use !important to prevent issues with browser extensions that change fonts */
  font-family: 'my-custom-icons' !important;
  font-style: normal;
  font-weight: normal;
  font-variant: normal;
  text-transform: none;
  line-height: 1;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

```
