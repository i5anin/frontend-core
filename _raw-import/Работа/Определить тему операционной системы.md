На сайте можно определить тему операционной системы с помощью [JavaScript](./JavaScript). Вот пример кода, который определит, является ли тема операционной системы темной или светлой:


```javascript
if (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
  // темная тема
  console.log('Темная тема');
} else {
  // светлая тема
  console.log('Светлая тема');
}

```

Этот код проверяет, поддерживает ли браузер запрос `prefers-color-scheme`, и если да, проверяет, соответствует ли текущая тема темной. Если это так, код выводит сообщение о том, что тема темная, в противном случае - что тема светлая.

Вы можете использовать этот код на своем сайте, чтобы определить тему операционной системы посетителя.
