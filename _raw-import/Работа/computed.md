**`computed`** (вычисляемые свойства) в [../Vue/Vue.js](#) — это специальные свойства, которые автоматически вычисляются на основе зависимостей от реактивных данных. Эти &lt;u&gt;свойства кэшируются&lt;/u>, что означает, что их значение пересчитывается только тогда, когда изменяются данные, от которых они зависят. В отличие от методов, вычисляемые свойства не будут пересчитываться каждый раз при рендере, если их зависимости не изменились.

**Основное использование `computed`:**

1. **Кэширование**: Вычисляемые свойства кэшируются и пересчитываются только при изменении зависимых данных.
2. **Читабельность кода**: `computed` часто используется для логики, связанной с вычислением на основе данных, что делает код более организованным.
3. **Простота использования в шаблонах**: Вычисляемые свойства могут быть легко интегрированы в шаблон без необходимости вызова их как функций.

**Пример использования `computed` в Vue 2 и Vue 3:**

```html
<template>
  <div>
    <p>Сообщение: {{ message }}</p>
    <p>Сообщение в верхнем регистре: {{ uppercaseMessage }}</p>
    <input v-model="message" />
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: 'Привет, мир!'
    };
  },
  computed: {
    uppercaseMessage() {
      return this.message.toUpperCase();
    }
  }
};
</script>
```

**Как это работает:**

- `message` — это реактивное свойство из объекта `data`.
- `uppercaseMessage` — это вычисляемое свойство, которое зависит от `message`. Каждый раз, когда изменяется `message`, пересчитывается и обновляется `uppercaseMessage`, и обновляется только тогда, когда это необходимо.

**Пример в Vue 3 с [../Vue/Composition API](#):**

```html
<template>
  <div>
    <p>Число: {{ count }}</p>
    <p>Удвоенное число: {{ doubleCount }}</p>
    <button @click="increment">Увеличить</button>
  </div>
</template>

<script>
import { ref, computed } from 'vue';

export default {
  setup() {
    const count = ref(0);

    // Вычисляемое свойство
    const doubleCount = computed(() => count.value * 2);

    const increment = () => {
      count.value++;
    };

    return {
      count,
      doubleCount,
      increment
    };
  }
};
</script>
```

**Ключевые моменты:**

1. **Кэширование вычисляемых свойств**:
   Вычисляемое свойство пересчитывается только тогда, когда изменяются данные, от которых оно зависит. Если зависимости не изменились, результат будет взят из кэша, что оптимизирует производительность.

2. **Использование в шаблоне**:
   В отличие от методов, вычисляемые свойства используются в шаблоне Vue как обычные свойства, без необходимости вызывать их как функции.

**Пример использования `computed` для фильтрации данных:**

```html
<template>
  <div>
    <input v-model="search" placeholder="Поиск по товарам" />
    <ul>
      <li v-for="product in filteredProducts" :key="product.id">
        {{ product.name }}
      </li>
    </ul>
  </div>
</template>

<script>
export default {
  data() {
    return {
      search: '',
      products: [
        { id: 1, name: 'Яблоко' },
        { id: 2, name: 'Банан' },
        { id: 3, name: 'Апельсин' }
      ]
    };
  },
  computed: {
    filteredProducts() {
      return this.products.filter(product =>
        product.name.toLowerCase().includes(this.search.toLowerCase())
      );
    }
  }
};
</script>
```

Здесь `filteredProducts` — это вычисляемое свойство, которое фильтрует массив продуктов на основе поискового запроса `search`. Каждое изменение в `search` автоматически пересчитывает фильтрованный список.

**Когда использовать [computed](./computed):**

- Когда нужно производить вычисления на основе других данных и повторно использовать результат в нескольких местах.
- Когда нужно кэшировать результат вычисления для оптимизации производительности.
- Для чистых вычислений, которые зависят только от реактивных данных и не должны вызывать побочные эффекты.

**Отличия [computed](./computed) от [../Vue/vue new/methods](#):**

- **[computed](./computed)**: Используется для вычислений, которые зависят от реактивных данных и &lt;u&gt;должны быть кэшированы&lt;/u> до тех пор, пока данные не изменятся.
- **[../Vue/vue new/methods](#)**: Методы &lt;u&gt;не кэшируются&lt;/u>, и при каждом вызове возвращают результат, что может быть менее эффективно, если вычисления затратны.

Пример:

```html
<template>
  <div>
    <p>
	Удвоенное число через method: {{ doubleCountMethod() }}
    </p>
    <p>
	Удвоенное число через computed: {{ doubleCountComputed }}
    </p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      count: 5
    };
  },
  methods: {
    doubleCountMethod() {
      return this.count * 2;
    }
  },
  computed: {
    doubleCountComputed() {
      return this.count * 2;
    }
  }
};
</script>
```

Разница в том, что `doubleCountMethod()` будет пересчитываться каждый раз при рендере компонента, тогда как `doubleCountComputed` пересчитывается только при изменении `count`.

**Итог:**
- **`computed`** в [../Vue/Vue.js](#).js используется для создания вычисляемых свойств, которые автоматически обновляются при изменении зависимых данных и кэшируются для оптимизации производительности.
- В отличие от методов, вычисляемые свойства пересчитываются только при изменении зависимых данных, что делает их более эффективными для вычислений, которые часто используются в шаблоне.
