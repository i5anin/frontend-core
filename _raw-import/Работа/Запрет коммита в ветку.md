# Запрет коммита в ветку

> GitHub Branch Protection — платно или только для публичных репо. Но то же самое можно сделать через **pre-commit хук локально**.

---

## Через pre-commit хук

Файл `.git/hooks/pre-commit`:

```sh
#!/bin/sh
BRANCH=$(git symbolic-ref --short HEAD)
FORBIDDEN="main master"

for branch in $FORBIDDEN; do
  if [ "$BRANCH" = "$branch" ]; then
    echo "❌ Прямой коммит в '$branch' запрещён. Используй feature-ветку."
    exit 1
  fi
done
```

> [!warning] Только локально
> Хук живёт в `.git/hooks/` — в git не попадает. Защищает только твою машину.

---

## Через Husky (для команды)

```sh
# .husky/pre-commit
BRANCH=$(git symbolic-ref --short HEAD)
if [ "$BRANCH" = "main" ]; then
  echo "❌ Прямой коммит в main запрещён"
  exit 1
fi
```

Этот файл **коммитится** → работает у всех после `npm install`.

---

## Запрет push (надёжнее)

Хук `pre-push` срабатывает при `git push` — даже если коммит уже создан локально.

Файл `.git/hooks/pre-push`:

```sh
#!/bin/sh
BRANCH=$(git symbolic-ref --short HEAD)
if [ "$BRANCH" = "main" ]; then
  echo "❌ Push в main запрещён. Открой Pull Request."
  exit 1
fi
```

> [!tip] pre-push надёжнее pre-commit
> `pre-commit` можно обойти через `--no-verify`. `pre-push` — тоже, но психологически сложнее: человек уже написал `git push main`.

---

## Бесплатная защита на GitHub

GitHub даёт Branch Protection **бесплатно** для **публичных репо**.

Для приватных — два варианта без платной подписки:

| Вариант | Как |
|---|---|
| Husky `pre-push` | Блокирует на уровне каждой машины |
| Сделать репо публичным | Branch Protection становится доступным |
| GitLab Free | Защита веток есть бесплатно даже для приватных |
