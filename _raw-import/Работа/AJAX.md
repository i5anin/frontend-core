AJAX (Asynchronous [JavaScript](./JavaScript) and [XML](./XML)) — это технология, позволяющая обновлять части веб-страницы без полной её перезагрузки. Она используется для асинхронной отправки запросов к серверу, получения данных и динамического обновления контента страницы на основе ответа, что делает взаимодействие с сайтом более плавным и быстрым.

Основные моменты о [AJAX](./AJAX):

- **Асинхронность**: запросы отправляются в фоновом режиме, и пользователь может продолжать взаимодействовать с веб-страницей.
- **XML/JSON**: хотя в названии упоминается [XML](./XML), чаще всего данные передаются в формате [JSON](./JSON).
- **Использование XMLHttpRequest или Fetch [API](./API)**: для выполнения запросов.

Пример использования [AJAX](./AJAX) с [Fetch API](./Fetch API):

```javascript
fetch('https://example.com/api/data')
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => console.error('Ошибка:', error));
```

Этот код отправляет асинхронный GET-запрос на сервер и получает данные в формате [JSON](./JSON) без перезагрузки страницы.
