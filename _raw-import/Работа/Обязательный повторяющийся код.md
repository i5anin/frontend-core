**Binding repeating code**
[Привязка повторяющегося кода](./Привязка повторяющегося кода)
Чтобы избежать повторения кода в этом сценарии, вы можете создать отдельный файл данных, хранящий общую информацию, и импортировать его в `App.vue` и `index.js`.

Например, вы можете создать файл `data.js` в каталоге `src` со следующим кодом:

```JavaScript
export const tabs = ['Home', 'About', 'Projects', 'Contact']; 
export const tabRoutes = ['/', '/about', '/projects', '/contact'];
```

Затем, в `App.vue`, вы можете импортировать массивы `tabs` и `tabRoutes` из `data.js`:

```JavaScript
import { tabs, tabRoutes } from './data'; 
export default {   
	data() {     
		return {tabs, tabRoutes, activeTab: 0,};   
	},   
// ... };
```
Аналогично, в `index.js` вы можете импортировать массивы `tabs` и `tabRoutes` из `data.js`:

```JavaScript
import { tabs, tabRoutes } from '@/data';  
const 
routes = [   
{ path: '/', name: tabs[0], component: HomePage },   
{ path: '/about', name: tabs[1], component: AboutPage },   
{ path: '/projects', name: tabs[2], component: ProjectsPage },   
{ path: '/contact', name: tabs[3], component: ContactPage },   
{ path: '/:pathMatch(.*)', name: 'Error404', component: ErrorPage }, 
];  

export default new VueRouter({mode: 'history', base: process.env.BASE_URL, routes,});
```

Таким образом, вам нужно определить массивы `tabs` и `tabRoutes` только один раз, и все изменения, которые вы внесете в них, будут отражены в файлах `App.vue` и `index.js`.
