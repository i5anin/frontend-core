**[CDN](./CDN)** (Content Delivery Network) — это сеть серверов, предназначенная для доставки контента, например, библиотек и фреймворков, через различные географические точки. При использовании [CDN](./CDN) можно быстро подключить нужный ресурс (например, библиотеку [../Vue/Vue.js](#)) напрямую в проект без необходимости установки через пакетные менеджеры.

**Установка [../Vue/Vue.js](#)**:

1. **Через [CDN](./CDN)**:
   - Быстрый и простой способ начать работу с Vue.js. Просто добавьте ссылку на [../Vue/Vue.js](#) в [HTML](./HTML)-файл. Например:

     ```html
     <script 
	     src="https://cdn.jsdelivr.net/npm/vue@3"
     >
     </script>
     ```

   Это удобно для прототипирования и простых проектов, но может быть не лучшим решением для сложных приложений из-за ограниченных возможностей управления версиями и настройками.

2. **Через [CLI](#)** (Command Line Interface):
   - Установка [../Vue/Vue.js](#) через [CLI](#) позволяет создать проект с более продвинутыми настройками, сборкой, возможностью работы с компонентами, маршрутизацией и другими инструментами. Команда для создания проекта через [Vue CLI](#):

     ```bash
     npm install -g @vue/cli
     vue create my-project
     ```

   Этот способ рекомендуется для крупных проектов и приложений с более сложной структурой, требующих поддержки сборщиков модулей и конфигурации.
