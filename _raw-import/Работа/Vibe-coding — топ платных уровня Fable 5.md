# Vibe-coding — топ платных уровня Fable 5

> Только премиум-сервисы максимального качества. Где можно положиться на агента не глядя в код.

> [!tip] Критерий
> **Уровень Fable 5** = эталон reasoning + длинный контекст + автономия.
> Не «помощник», а полноценный инженер.

---

## 🥇 Топ-3 — играют в одной лиге с Fable 5

**1. Claude Code Max (Anthropic)**

🔗 [claude.com/code](https://www.claude.com/claude-code)
💰 **$100 / $200 в месяц** (Max plan)
🖥️ CLI / VS Code / JetBrains
🧠 **Fable 5 / Opus 4.8** под капотом

**Что даёт:**
- Сам Fable 5 — топ модель Anthropic
- Длинный контекст репо
- Workflows для оркестрации
- Hooks для автоматизации
- Multi-agent (subagents)

**Когда выбирать:** если хочешь **именно ту модель**, что в Claude. Лучший reasoning.

> [!warning]
> Требует VPN + не-российская карта.

---

**2. Devin (Cognition Labs)**

🔗 [devin.ai](https://devin.ai/)
💰 **$500 / $2000 / $10 000 в месяц** (Team / Pro / Enterprise)
🌐 Web

**Что даёт:**
- **Полностью автономный** инженер
- Ставишь задачу → уходишь → приходит готовый PR
- Сам пишет, тестирует, дебажит, деплоит
- Использует Claude / GPT-5 под капотом
- Параллельная работа над десятками тасок

**Когда выбирать:** когда задач **больше, чем ты успеваешь**, и нужно реально делегировать.

> [!danger] Цена кусается
> $500/мес базовый. Это для **команд** или **серьёзных продуктов**.

---

**3. Cursor Ultra / Business**

🔗 [cursor.com](https://cursor.com/)
💰 **$40 / $200 в месяц** (Business / Ultra)
🖥️ Свой IDE

**Что даёт:**
- Доступ ко **всем топ-моделям**: Fable 5, GPT-5, Gemini 2.5 Pro
- Agent Mode на максималках
- Background agents — работают пока ты отдыхаешь
- Composer мультифайл
- Tab-автокомплит уровня магии

**Когда выбирать:** если нужна **гибкость моделей** + лучший IDE-experience.

## Что брать **тебе** (один разработчик, бюджет фиксированный)

> [!tip] Рекомендация
> **Claude Code Max ($100/мес)** + **Cursor Pro ($20/мес)** = $120/мес.
>
> - Claude Code — для агентских задач (рефакторы, фичи целиком)
> - Cursor — для повседневной работы с Tab и Composer
>
> Это **топ-стек 2026** за разумные деньги.

Если **денег не считаешь** — добавь **Devin Team ($500)** для делегирования рутины.

## Что НЕ выбирать (для качества Fable 5)

- ❌ **Trae** — бесплатно, но качество не сравнить
- ❌ **GigaCode** — автокомплит, не агент
- ❌ **Aider / Cline open-source** — хороши, но требуют ручной настройки моделей
- ❌ **ChatGPT Plus ($20)** — лимиты слишком жёсткие для агентского кодинга
