**`unshift()`** — это метод массивов в [JavaScript](./JavaScript), который добавляет один или несколько элементов в **начало** массива. Он изменяет исходный массив и возвращает его новую длину.

**Синтаксис:**

```javascript
array.unshift(element1, element2, ..., elementN)
```

- **`element1, element2, ..., elementN`** — элементы, которые нужно добавить в начало массива.
- Метод изменяет исходный массив, добавляя элементы перед его первым элементом, и возвращает новую длину массива.

**Пример использования:**

```javascript
let fruits = ['яблоко', 'банан'];
let newLength = fruits.unshift('апельсин');

console.log(fruits);       // ['апельсин', 'яблоко', 'банан']
console.log(newLength);    // 3
```

Здесь в массив `fruits` добавлен новый элемент `'апельсин'` в начало, и метод `unshift()` вернул новую длину массива (3).

**Пример с добавлением нескольких элементов:**

```javascript
let numbers = [3, 4, 5];
numbers.unshift(1, 2);

console.log(numbers);  // [1, 2, 3, 4, 5]
```

В этом примере элементы `1` и `2` добавлены в начало массива `numbers`.

**Основные моменты:**
- Метод **`unshift()`** добавляет элементы в начало массива.
- Метод изменяет исходный массив и возвращает его новую длину.
