**Точки разума кода с использованием [../Vue/Options API](#) и [Компоненты Vue](#)**

1. **Создание основных переменных:**
   ```js
   const startDate = ref(null)
   const endDate = ref(null)
   let info = ref([])
   let fields = ref([])
   let dataTable = ref([])
   let dataLoaded = ref(false) // [Флаг](#) для контроля загрузки данных
   ```
   - Используются реактивные переменные с [ref](./ref), чтобы отслеживать состояния, такие как `startDate`, `endDate`, и статусы загрузки таблицы.

2. **Функция для загрузки данных с сервера:**
   ```js
   const loadOrders = async () => {
     try {
       dataLoaded.value = false // Сбрасываем флаг перед загрузкой данных
       const response = await getOrders(1, 15, '', null, null, startDate.value, endDate.value)
       console.log(response)

       info.value = response.header
       fields.value = response.table.fields
       dataTable.value = response.table.data

       dataLoaded.value = true // Устанавливаем флаг после успешной загрузки данных
     } catch (error) {
       console.error('Ошибка загрузки данных заказов:', error)
     }
   }
   ```
   - Перед загрузкой данных флаг `dataLoaded` устанавливается в `false`, чтобы избежать преждевременного рендеринга.
   - После успешной загрузки данных флаг снова устанавливается в `true`, что позволяет компоненту отобразиться.

3. **Использование [Дебаунс](#) для оптимизации запросов:**
   ```js
   const debouncedLoadOrders = debounce(loadOrders, 500)
   ```
   - Используем [debounce](./debounce) из [../JavaScript/Библиотеки/Lodash](#), чтобы уменьшить количество запросов к серверу при частых изменениях даты (например, когда пользователь активно меняет [период](#)).

4. **Наблюдение за изменениями дат:**
   ```js
   watch([startDate, endDate], () => {
     debouncedLoadOrders()
   })
   ```
   - При изменении `startDate` или `endDate` вызывается функция загрузки данных с помощью [watch](./watch), что обеспечивает реактивность компонента.

5. **Начальная загрузка данных при монтировании компонента:**
   ```js
   onMounted(() => {
     loadOrders()
   })
   ```
   - Используется [../Vue/Options API](#) `onMounted`, чтобы данные были загружены при первой загрузке компонента.

6. **Контроль рендеринга компонента с помощью флага `dataLoaded`:**
   ```vue
   <UniversalTable
     v-if="dataLoaded"
     ref="ordersTable"
     :info="info"
     :fields="fields"
     :data-table="dataTable"
     class="display"
     width="100%"
   />
   ```
   - С помощью `v-if="dataLoaded"` таблица рендерится только после полной загрузки и форматирования данных. Это помогает избежать ошибок, связанных с преждевременным отображением пустых или некорректных данных.

**Простой пример для `v-if="dataLoaded"`**

```vue
<template>
  <div>
    <div v-if="dataLoaded">
      <p>Данные успешно загружены!</p>
    </div>
    <div v-else>
      <p>Загрузка данных...</p>
    </div>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'

const dataLoaded = ref(false)

onMounted(() => {
  setTimeout(() => {
    dataLoaded.value = true // Устанавливаем флаг, чтобы показать, что данные загружены
  }, 2000) // Симуляция задержки для загрузки данных
})
</script>
```

- В этом примере используются два блока: `v-if="dataLoaded"` отображает сообщение "Данные успешно загружены!", когда данные готовы, а `v-else` — сообщение о загрузке.
- Такой подход помогает наглядно видеть, когда данные ещё не готовы и рендер не должен происходить.
