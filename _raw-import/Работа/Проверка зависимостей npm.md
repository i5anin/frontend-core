Для проверки обновлений всех зависимостей в вашем проекте вы можете использовать следующую команду с помощью npm или npx:

**1. **Проверка обновлений с помощью `npm`****

```bash
npm outdated
```

Эта команда покажет таблицу с текущей, желаемой и последней доступной версией каждого пакета.

---

**2. **Автоматическое обновление зависимостей****

Чтобы обновить все зависимости до последних версий:

```bash
npm update
```

---

**3. **Обновление до последних мажорных версий****

Используйте `npx npm-check-updates` (если у вас установлен `npm-check-updates`):

**Установить `npm-check-updates` глобально:**

```bash
npm install -g npm-check-updates
```

**Запуск обновления:**

```bash
ncu -u
npm install
```

- `ncu -u` обновляет `package.json` до последних версий.
- `npm install` устанавливает обновленные зависимости.
