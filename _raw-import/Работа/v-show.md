**`v-show`** — это директива во [../../Vue/Vue.js](#), которая позволяет условно отображать элементы на странице, изменяя их видимость с помощью свойства [CSS](./CSS) `display`. В отличие от `v-if`, который полностью добавляет или удаляет элемент из [DOM](./DOM), `v-show` просто меняет стиль элемента на `display: none` или убирает его, в зависимости от условия.

---

****Основы использования `v-show`****

**Синтаксис:**
```html
<div v-show="условие">   
<!-- содержимое --> </div>
```

Если `условие` истинно (`true`), элемент будет отображен. Если ложно (`false`), элемент будет скрыт с помощью `display: none`.

---

****Простой пример****

**Шаблон:**

```html
<div id="app">
  <button @click="isVisible = !isVisible">
    {{ isVisible ? 'Скрыть' : 'Показать' }} сообщение
  </button>
  <p v-show="isVisible">Это сообщение может быть скрыто или показано.</p>
</div>
```

**Скрипт:**

```js
new Vue({
  el: '#app',
  data: {
    isVisible: true
  }
});

```

**Объяснение:**

- **`data`**: Определяем переменную `isVisible`, которая контролирует видимость элемента.
- **`@click`**: При клике на кнопку переключаем значение `isVisible` на противоположное.
- **`v-show="isVisible"`**: Абзац `<p>` будет отображаться или скрываться в зависимости от значения `isVisible`.

---

****Сравнение `v-show` и `v-if`****

**`v-show`:**

- Элемент всегда присутствует в [DOM](./DOM).
- Видимость элемента контролируется через `display: none`.
- Подходит для частого переключения видимости элемента.

**`v-if`:**

- Элемент добавляется или удаляется из [DOM](./DOM) в зависимости от условия.
- Более тяжелый с точки зрения производительности при частом переключении.
- Подходит, когда элемент нужно отобразить или скрыть редко.

**Пример с `v-if`:**

```html
<p v-if="isVisible">
Это сообщение может быть скрыто или показано.
</p>
```

---

****Пример с формой логина****

**Шаблон:**
```html
<div id="app">
  <button @click="isLoggedIn = !isLoggedIn">
    {{ isLoggedIn ? 'Выйти' : 'Войти' }}
  </button>
  
  <div v-show="!isLoggedIn">
    <h2>Пожалуйста, войдите</h2>
    <!-- Форма логина -->
  </div>
  
  <div v-show="isLoggedIn">
    <h2>Добро пожаловать!</h2>
    <!-- Содержимое для авторизованных пользователей -->
  </div>
</div>

```

**Скрипт:**

```js
new Vue({
  el: '#app',
  data: {
    isLoggedIn: false
  }
});

```

**Объяснение:**

- **`isLoggedIn`**: Переменная, которая определяет, авторизован ли пользователь.
- **Два блока с `v-show`**: Один отображается, когда пользователь не авторизован, другой — когда авторизован.

---

****Пример с переключением вкладок****

**Шаблон:**

```html
<div id="app">
  <div>
    <button @click="activeTab = 'home'">Главная</button>
    <button @click="activeTab = 'profile'">Профиль</button>
    <button @click="activeTab = 'settings'">Настройки</button>
  </div>
  
  <div v-show="activeTab === 'home'">
    <h2>Главная страница</h2>
    <!-- Содержимое главной страницы -->
  </div>
  
  <div v-show="activeTab === 'profile'">
    <h2>Профиль пользователя</h2>
    <!-- Содержимое профиля -->
  </div>
  
  <div v-show="activeTab === 'settings'">
    <h2>Настройки</h2>
    <!-- Содержимое настроек -->
  </div>
</div>

```

**Скрипт:**

```js
new Vue({
  el: '#app',
  data: {
    activeTab: 'home'
  }
});

```

**Объяснение:**

- **`activeTab`**: Определяет, какая вкладка активна.
- **`v-show`** на разделах контента: Отображает соответствующий раздел в зависимости от значения `activeTab`.

****Динамическое отображение списка элементов****

**Шаблон:**

```html
<div id="app">
  <input v-model="searchQuery" placeholder="Поиск...">
  
  <ul>
    <li 
    v-for="item in items" 
    :key="item.id" 
    v-show="matchesSearch(item)"
    >
      {{ item.name }}
    </li>
  </ul>
</div>
```

**Скрипт:**

```js
new Vue({
  el: '#app',
  data: {
    searchQuery: '',
    items: [
      { id: 1, name: 'Яблоко' },
      { id: 2, name: 'Банан' },
      { id: 3, name: 'Апельсин' },
      // другие элементы
    ]
  },
  methods: {
    matchesSearch(item) {
      return item.name.toLowerCase().includes(this.searchQuery.toLowerCase());
    }
  }
});

```

**Объяснение:**

- **`searchQuery`**: Строка поиска, обновляется при вводе пользователя.
- **`v-show="matchesSearch(item)"`**: Показывает элемент списка только если он соответствует поисковому запросу.
- **`matchesSearch`**: Метод, который проверяет, содержит ли название элемента поисковый запрос.

****Стиль и анимация с `v-show`****

При использовании `v-show` можно применять [CSS](./CSS)-анимации для плавного появления и исчезновения элементов.

**Пример:**

```html
<div id="app">
  <button @click="isVisible = !isVisible">
    Переключить блок
  </button>
  
  <div v-show="isVisible" class="fade">
    <p>Этот блок появляется и исчезает с анимацией.</p>
  </div>
</div>
```

**Стили:**

```css
.fade {
  transition: opacity 0.5s;
}
.fade[style*="display: none"] {
  opacity: 0;
}
.fade[style*="display: block"] {
  opacity: 1;
}
```

**Скрипт:**

```js
new Vue({
  el: '#app',
  data: {
    isVisible: true
  }
});
```

**Объяснение:**

- **Класс `fade`**: Добавляет переход для свойства `opacity`.
- **CSS-селекторы**: Изменяют непрозрачность в зависимости от стиля `display`.
- **Результат**: При переключении `isVisible` блок будет плавно появляться и исчезать.

---

****Когда использовать `v-show`****

- **Частое переключение видимости**: Если вам нужно часто показывать и скрывать элемент, `v-show` предпочтительнее, так как не удаляет и не добавляет элемент в [DOM](./DOM).
- **Инициализация раз**: Если элемент содержит сложные компоненты или тяжелые операции при создании, `v-show` предотвращает повторную инициализацию.

**Когда лучше использовать `v-if`**

- **Редкое отображение**: Если элемент показывается редко или по условию, которое меняется нечасто.
- **Условная отрисовка**: Если вы не хотите, чтобы элемент был в DOM, пока условие не станет истинным, например, для оптимизации производительности.

---

****Комбинирование с другими директивами****

**Использование вместе с `v-for`:**

Хотя `v-show` можно использовать вместе с `v-for`, следует помнить, что все элементы будут отрисованы в DOM, но некоторые могут быть скрыты.

**Пример:**

html

Копировать код

```html
<ul>
  <li v-for="item in items" :key="item.id" v-show="item.isActive">
    {{ item.name }}
  </li>
</ul>
```

**Объяснение:**

- Все элементы `items` будут присутствовать в DOM.
- Элементы, где `item.isActive` ложно, будут скрыты через `display: none`.

**Предупреждение:**

- Если список большой, это может негативно сказаться на производительности.
- В таких случаях лучше использовать `v-if` внутри `v-for` или фильтровать массив заранее.

---

****Обработка событий с `v-show`****

Элементы, скрытые с помощью `v-show`, все еще присутствуют в DOM, поэтому события могут срабатывать, даже если элемент невидим. Будьте внимательны при работе с событиями на скрытых элементах.

**Пример:**
```html
<button @click="isVisible = !isVisible">Переключить</button>
<div v-show="isVisible" @click="handleClick">
  Нажмите здесь
</div>
```

**Объяснение:**

- Если `isVisible` ложно, блок все равно находится в [DOM](./DOM).
- Если есть способы взаимодействия с этим блоком (например, через клавиатуру или скрипты), событие `@click` может сработать.
- Чтобы избежать этого, можно дополнительно проверять условие внутри обработчика
