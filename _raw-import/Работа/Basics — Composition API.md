[Vue.js](./Basics — Vue.js) 3 [Composition API](./Basics — Composition API) ([API](./API) композиции) - это новый подход к написанию компонентов во фреймворке [Vue.js](./Basics — Vue.js).js версии 3. Он предоставляет разработчикам более гибкий и мощный способ организации логики компонентов, делая код более понятным, модульным и переиспользуемым.

Вместо использования опций компонента, таких как [Объект data (vue)](../../Изучение/Объект data (vue)), [computed](./computed), [../../Vue/vue new/methods](#) и т. д., в Composition API вы можете использовать функции, называемые "композициями" (composables), которые объединяют связанный код вместе. Композиции позволяют разделить логику компонента на более мелкие и независимые части, что упрощает понимание и поддержку кода.

Преимущества использования [Composition API](./Basics — Composition API) включают:

1. Более ясная организация кода: Логика компонента разделена на отдельные композиции, что облегчает чтение и понимание кода.
    
2. Переиспользуемость: Композиции могут быть использованы в разных компонентах, что способствует повторному использованию кода и уменьшению дублирования.
    
3. Более гибкая логика: [Composition API](./Basics — Composition API)] предоставляет более широкие возможности для организации логики, такие как использование реактивных переменных, эффектов и т. д.
    
4. Лучшая типизация: [Composition API](./Basics — Composition API) предоставляет лучшую поддержку типизации благодаря использованию [../../TypeScript/TypeScript](#) или других инструментов для проверки типов.
    

Пример использования [Composition API](./Basics — Composition API)включает создание композиции с помощью функции `reactive`, которая позволяет объявить реактивную переменную, и использование функции `computed` для вычисления зависимых значений. Кроме того, Composition API предоставляет много других функций и хуков для более гибкого управления состоянием, эффектами и событиями в компонентах.

Обратите внимание, что [Composition API](./Basics — Composition API) вводит новый подход к разработке с использованием [Vue.js](./Basics — Vue.js).js и не заменяет классический подход с использованием опций компонента. Оба подхода могут использоваться вместе или по отдельности, в зависимости от потребностей проекта и предпочтений разработчика.

[Options API](./Basics — Options API) и [Composition API](./Basics — Composition API)  являются двумя разными подходами к созданию компонентов во [Vue.js](./Basics — Vue.js).

Composition API  является новым подходом, представленным в Vue.js 3.0, который предлагает более гибкую и мощную модель композиции компонентов. Вместо определения опций компонента в одном объекте, Composition API позволяет объединять логически связанные функции и состояние в виде композиций. Это делает код более модульным, переиспользуемым и позволяет более гибко организовывать логику компонента. Пример компонента, созданного с использованием Composition API, может выглядеть следующим образом:

```js
import { ref, computed } from 'vue';

export default {
  setup() {
    const message = ref('Hello, Vue!');

    function showMessage() {
      alert(message.value);
    }

    const uppercaseMessage = computed(() => {
      return message.value.toUpperCase();
    });

    return {
      message,
      showMessage,
      uppercaseMessage
    };
  }
};

```
