## 📦 **Список проектов в программе обучения**

**🔹 1. **Интернет-магазин****

- Каталог товаров
- Поиск и фильтрация
- Личный кабинет пользователя
- Корзина
- Подключение модуля оплаты  
    **🛠 Стек:** React, Git, CSS/HTML, API

---

**🔹 2. **Блог на React****

- Регистрация / авторизация
- CRUD статьи, роли (admin, user)
- Комментарии
- Пагинация, фильтры  
    **🛠 Стек:** React, Router, Axios, localStorage

---

**🔹 3. **Калькулятор****

- Арифметика
- Сохранение данных в localStorage
- Простая логика и UI  
    **🛠 Стек:** React, JS

---

**🔹 4. **CRM manager****

- Заявка для клиента (форма)
- Таблица заявок для оператора
- Сортировка, фильтрация, поиск  
    **🛠 Стек:** React, Formik или React Hook Form, Redux/Context

---

**🔹 5. **Квиз (викторина)****

- Создание вопросов с вариантами
- Прохождение теста
- Подсчет баллов  
    **🛠 Стек:** React, useState/useEffect

---

**🔹 6. **Хакатон №1: Git/JS проект****

- Командная разработка
- Мини-приложение: плагин контекстного меню  
    **🛠 Стек:** JavaScript, Git, HTML/CSS

---

**🔹 7. **Хакатон №2: React-приложение****

- Командная разработка
- Полноценный React-проект  
    **🛠 Стек:** React, Git, Agile

---

**🔹 8. **Дипломная работа: Fullstack-проект****

- Сочетание frontend и backend
- Авторизация, хранение данных, API  
    **🛠 Стек:** React, Express или Firebase, TypeScript

---

**🔹 9. **Модульный блог/новостная лента****

- Публикации, фильтрация, лайки
- Поддержка нескольких пользователей  
    **🛠 Стек:** React, Router, API

---

**🔹 10. **Сайт с анимацией и вёрсткой****

- UI/UX практика
- Scroll-анимации, адаптив  
    **🛠 Стек:** HTML/CSS, JS

---

**🔹 11. **ToDo-лист с фильтрацией****

- Простые CRUD-операции
- Хранение в памяти/локальном хранилище  
    **🛠 Стек:** React или Vanilla JS

---

**🔹 12. **Форма обратной связи с валидацией****

- Input/Select
- Проверка данных
- Отправка на API  
    **🛠 Стек:** React Hook Form / JS

---

**🔹 13. **Приложение с таймером / секундомером****

- Управление состоянием
- Работа с setInterval  
    **🛠 Стек:** React

---

**🔹 14. **Кастомный UI-компонент (например, дропдаун или табы)****

- Переиспользуемость
- Отзывчивость  
    **🛠 Стек:** React, HTML/CSS, JS
