В [JavaScript](./JavaScript) существует два способа объявления функций: функциональное выражение (function expression) и функциональное объявление ([function](./function) [Declaration](./Declaration)).

1. Функциональное выражение (Function [Expression](./Expression)): Функциональное выражение представляет собой создание функции и присваивание ее в переменную. Оно имеет следующий синтаксис:

```js
var myFunction = function() { 
// тело функции 
};
```
1. В этом случае, функция является значением и может быть использована как другие переменные. Функциональное выражение может быть анонимным (когда имя переменной используется для ссылки на функцию) или именованным (когда имя функции также указывается после ключевого слова `function`).
    
2. Функциональное объявление (Function Declaration): Функциональное объявление определяет функцию как часть объявления блока кода. Оно имеет следующий синтаксис:
```js
function myFunction() {
  // тело функции
}

```
    
В этом случае, функция объявляется с использованием ключевого слова `function` и имени функции. Функциональное объявление создает функцию, которая доступна в области видимости, в которой оно объявлено (глобальная область видимости или область видимости функции).
    

Различия между функциональным выражением и функциональным объявлением:

- Время создания: Функции, объявленные с помощью функционального выражения, создаются во время выполнения (выполнение строки кода), тогда как функции, объявленные с помощью функционального объявления, создаются при компиляции (перед выполнением кода).
- Всплытие (Hoisting): Функциональные объявления подвергаются всплытию, что означает, что их можно вызвать до их фактического определения в коде. Функциональные выражения не подвергаются всплытию, их можно вызывать только после их определения в коде.
- Область видимости: Функции, объявленные с помощью функционального выражения, имеют область видимости, которая определяется контекстом, в котором они созданы. Функции, объявленные с помощью функционального объявления, имеют область видимости, определенную внутри текущей области видимости (например, глобальная или функция).

В обоих случаях функции могут принимать аргументы и выполняться при вызове с передачей соответствующих значений. Выбор между функциональным выражением и функциональным объявлением зависит от требований конкретной ситуации и предпочтений программиста.
