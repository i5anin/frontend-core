# Как установить и запустить Portainer с помощью [Docker](./Docker) 

Portainer — это популярная платформа для управления [Docker](./Docker)-контейнерами с простым и интуитивно понятным веб-интерфейсом. В этой статье я расскажу, как быстро и легко установить Portainer на вашем устройстве с использованием [Docker](./Docker).

---

## Что нужно для начала

1. Установленный Docker (Desktop для Windows или Linux).
2. Доступ к командной строке/терминалу.
3. Браузер для доступа к веб-интерфейсу.

---

## Команда для запуска Portainer

Просто выполните следующую команду в терминале:

```bash
docker run -d -p 8000:8000 -p 9443:9443 --name portainer --restart=always \ -v /var/run/docker.sock:/var/run/docker.sock \ -v portainer_data:/data portainer/portainer:latest
```

**Что делает эта команда:**

- `-d` — запускает контейнер в фоновом режиме.
- `-p 8000:8000` — пробрасывает порт 8000 для Edge Compute (можно не использовать, если не нужно).
- `-p 9443:9443` — пробрасывает порт 9443 для доступа к веб-интерфейсу через HTTPS.
- `--name portainer` — задает имя контейнера `portainer`.
- `--restart=always` — контейнер будет автоматически перезапускаться в случае сбоя или перезагрузки системы.
- `-v /var/run/docker.sock:/var/run/docker.sock` — подключает Docker сокет, чтобы Portainer мог управлять контейнерами.
- `-v portainer_data:/data` — создаёт volume для хранения данных Portainer.

---

## Доступ к интерфейсу

После запуска контейнера:

1. Откройте браузер и перейдите по адресу:
    
    ```
    https://localhost:9443
    ```
    
2. В первый раз откроется страница настройки. Создайте учетную запись администратора:
    - Укажите логин (например, `admin`).
    - Придумайте и введите пароль.
3. После настройки вы попадете на **панель управления Docker**, где сможете управлять контейнерами, образами, сетями и другими ресурсами.

---

## Пример рабочего адреса

После установки Portainer доступен по адресу:

```
https://localhost:9443/#!/2/docker/dashboard
```

Этот адрес ведет вас прямо на **панель управления Docker**.

---

## Советы и примечания

- Если вы работаете на удаленном сервере, замените `localhost` на IP-адрес вашего сервера.
- Если ваш браузер предупреждает о небезопасном подключении, это нормально — Portainer использует самоподписанный сертификат. Просто добавьте исключение.
- Для использования HTTP вместо HTTPS добавьте проброс порта `9000`:
    
    ```bash
    docker run -d -p 9000:9000 --name portainer --restart=always \
    -v /var/run/docker.sock:/var/run/docker.sock \
    -v portainer_data:/data portainer/portainer:latest
    ```
    
    И откройте:
    
    ```
    http://localhost:9000
    ```
    

---

Теперь вы знаете, как быстро установить и запустить Portainer с помощью одной команды. Управляйте вашими контейнерами удобно через веб-интерфейс! 😊
