В CSS существуют различные **тип отображения элементов** (display). Ключевые из них: **inline**, **block**, **inline-block** и **flex**. Давайте разберём их по порядку.

---

****1. Inline (Инлайн)****

Элементы с типом отображения `inline` располагаются в одну строку и не занимают всю ширину родительского контейнера.

**Особенности:**

- Элементы отображаются **в строку**, а не с новой строки.
- Нельзя задавать свойства размеров (`width`, `height`).
- Отступы (`margin` и `padding`) работают только по горизонтали (сверху и снизу — игнорируются).

**Пример:**

```html
<span style="display: inline; background: yellow;">Элемент 1</span>
<span style="display: inline; background: lightblue;">Элемент 2</span>
```

**Результат**: Элементы находятся в одной строке.

---

****2. Block (Блочный элемент)****

Элементы с типом отображения `block` автоматически занимают всю ширину родительского контейнера.

**Особенности:**

- Элементы **начинаются с новой строки**.
- Можно задавать размеры (`width`, `height`).
- Отступы (`margin`, `padding`) работают во всех направлениях.

**Пример:**

```html
<div style="display: block; background: yellow;">Элемент 1</div>
<div style="display: block; background: lightblue;">Элемент 2</div>
```

**Результат**: Элементы располагаются вертикально друг под другом.

---

****3. Inline-block (Инлайн-блок)****

Элементы с типом отображения `inline-block` сочетают свойства `inline` и `block`:

- Отображаются **в строку**.
- При этом поддерживают размеры (`width`, `height`).

**Особенности:**

- Отступы (`margin` и `padding`) работают полностью.
- Можно комбинировать с другими элементами `inline` в строке.

**Пример:**

```html
<div style="display: inline-block; width: 100px; height: 50px; background: yellow;">Элемент 1</div>
<div style="display: inline-block; width: 100px; height: 50px; background: lightblue;">Элемент 2</div>
```

**Результат**: Элементы находятся в одной строке, но их можно масштабировать по ширине и высоте.

---

****4. Flex (Гибкий контейнер)****

Элементы с типом отображения `flex` позволяют создавать сложные макеты с гибким выравниванием.

**Особенности:**

- Родительский контейнер (`display: flex`) управляет расположением дочерних элементов.
- Поддерживается выравнивание, изменение порядка, распределение пространства между элементами.

**Пример:**

```html
<div style="display: flex; gap: 10px; background: lightgray;">
  <div style="width: 100px; height: 50px; background: yellow;">Элемент 1</div>
  <div style="width: 100px; height: 50px; background: lightblue;">Элемент 2</div>
  <div style="width: 100px; height: 50px; background: lightgreen;">Элемент 3</div>
</div>
```

**Результат**: Элементы располагаются в строку, равномерно распределяя расстояние между собой.

---

**Сравнение типов отображения:**

|Тип|В строку/с новой строки|Изменение размеров (`width`, `height`)|Подходит для сложных макетов|
|---|---|---|---|
|**inline**|В строку|Нет|Нет|
|**block**|С новой строки|Да|Нет|
|**inline-block**|В строку|Да|Нет|
|**flex**|Гибкий макет|Да|Да|

---

**Когда использовать?**

- **Inline**: для текста и небольших элементов, таких как `<span>`, ссылки `<a>`.
- **Block**: для контейнеров, секций, заголовков (например, `<div>`, `<h1>`).
- **Inline-block**: для кнопок, изображений, или элементов, которые должны быть в строке, но управляться размерами.
- **Flex**: для сложных макетов с гибким позиционированием и распределением элементов.

Используйте тип отображения в зависимости от задач, чтобы добиться оптимального результата.
