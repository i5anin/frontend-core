**GET-запрос** — это один из методов [HTTP](./HTTP), который используется для запроса данных с сервера. В GET-запросах клиент (например, браузер) отправляет запрос на сервер для получения определённой информации, и сервер отвечает, возвращая запрашиваемые данные.

Особенности GET-запроса:
1. **Запрос данных**. [GET](./GET) используется только для получения данных с сервера, без изменения состояния на сервере (например, без создания или обновления данных).
2. **Параметры в [URL](./URL)**. В [GET](./GET)-запросах данные передаются через URL-строку, используя параметры запроса (всё, что идёт после знака `?` в [URL](./URL)). Например:
   ```
   https://example.com/search?query=название
   ```
3. **Идемпотентность**. [GET](./GET)-запросы можно повторять сколько угодно раз без изменения состояния сервера.
4. **Ограничение на длину [URL](./URL)**. Некоторые серверы или браузеры могут ограничивать длину [URL](./URL)-строки, что может ограничить количество данных, передаваемых через [GET](./GET)-запрос.
5. **Кэширование**. Ответы на [GET](./GET)-запросы могут быть закэшированы, что позволяет повторно использовать результаты запроса без обращения к серверу.

[GET](./GET)-запросы широко используются для навигации по страницам веб-сайтов, поиска информации и получения данных в [REST API](./REST API).
