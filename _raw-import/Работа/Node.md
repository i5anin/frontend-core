**Node.js** — это среда выполнения [JavaScript](./JavaScript) на сервере, которая позволяет запускать JavaScript-код вне браузера. [Node.js](./Node.js) основан на движке V8 (от Google Chrome), который преобразует [JavaScript](./JavaScript) в машинный код, что делает его быстрым и эффективным. Node.js широко используется для создания серверных приложений, [API](./API) и микросервисов благодаря своим мощным возможностям работы с асинхронным кодом и событиями.

**Основные особенности Node.js:**
- **Асинхронная модель:** Node.js использует неблокирующую, асинхронную модель ввода-вывода, что делает его подходящим для приложений, обрабатывающих множество операций одновременно, таких как серверы реального времени.
- **Однопоточность:** Несмотря на то, что Node.js работает в одном потоке, он может обрабатывать множество запросов одновременно благодаря асинхронности.
- **Модульная система:** Node.js поддерживает модульную структуру через систему CommonJS (используя `require` и `module.exports`), что позволяет легко структурировать код.

**Установка Node.js:**
1. Скачайте и установите Node.js с [официального сайта](https://nodejs.org/).
2. После установки проверьте версию с помощью команды:
   ```bash
   node -v
   ```

**Пример 1: Простой HTTP-сервер на Node.js**
Создадим простой HTTP-сервер, который будет обрабатывать запросы и отправлять ответы.

1. Создайте файл `server.js`:

   ```javascript
   const http = require('http');

   // Создаем сервер
   const server = http.createServer((req, res) => {
     res.statusCode = 200;
     res.setHeader('Content-Type', 'text/plain');
     res.end('Привет, мир!\n');
   });

   // Сервер будет слушать на порту 3000
   server.listen(3000, '127.0.0.1', () => {
     console.log('Сервер запущен на http://127.0.0.1:3000/');
   });
   ```

2. Запустите сервер командой:
   ```bash
   node server.js
   ```

3. Перейдите в браузере по адресу `http://127.0.0.1:3000/`, и вы увидите сообщение "Привет, мир!".

**Пример 2: Чтение файла с использованием модуля `fs`**
Node.js имеет встроенные модули для работы с файлами, и один из них — это `fs` (файловая система).

1. Создайте файл `readfile.js`:
   ```javascript
   const fs = require('fs');

   // Чтение файла
   fs.readFile('example.txt', 'utf8', (err, data) => {
     if (err) {
       console.error('Ошибка при чтении файла:', err);
       return;
     }
     console.log('Содержимое файла:', data);
   });
   ```

2. Создайте файл `example.txt` с каким-либо содержимым, например:
   ```
   Это текст из файла example.txt.
   ```

3. Запустите скрипт:
   ```bash
   node readfile.js
   ```

Скрипт выведет содержимое файла `example.txt` в консоль.

**Пример 3: Простое приложение на Express.js**
**Express.js** — это минималистичный фреймворк для создания серверных приложений на Node.js. Он упрощает создание маршрутов, обработку запросов и многое другое.

1. Установите Express через npm:
   ```bash
   npm install express
   ```

2. Создайте файл `app.js`:
   ```javascript
   const express = require('express');
   const app = express();

   // Обработка GET-запроса на корневой маршрут
   app.get('/', (req, res) => {
     res.send('Привет, Express!');
   });

   // Запуск сервера на порту 3000
   app.listen(3000, () => {
     console.log('Сервер запущен на http://127.0.0.1:3000/');
   });
   ```

3. Запустите сервер:
   ```bash
   node app.js
   ```

4. Перейдите в браузере по адресу `http://127.0.0.1:3000/`, и вы увидите сообщение "Привет, Express!".

**Пример 4: Асинхронная работа с `setTimeout` и `setInterval`**
Node.js предоставляет возможности для работы с таймерами, как и в браузере.

1. Создайте файл `timer.js`:
   ```javascript
   console.log('Начало работы программы');

   setTimeout(() => {
     console.log('Прошло 2 секунды');
   }, 2000);

   let count = 0;
   const intervalId = setInterval(() => {
     console.log(`Прошло ${++count} секунд`);
     if (count === 5) {
       clearInterval(intervalId);  // Останавливаем интервал после 5 секунд
     }
   }, 1000);

   console.log('Конец программы');
   ```

2. Запустите файл:
   ```bash
   node timer.js
   ```

**Вывод:**
```
Начало работы программы
Конец программы
Прошло 1 секунд
Прошло 2 секунды
Прошло 2 секунды
Прошло 3 секунд
Прошло 4 секунд
Прошло 5 секунд
```

Здесь видно, что программа не блокируется во время выполнения асинхронных задач (например, `setTimeout` и `setInterval`), и продолжает работать.

**Пример 5: Работа с Promises**
В Node.js также поддерживаются промисы, что позволяет удобно работать с асинхронным кодом.

1. Создайте файл `promise.js`:
   ```javascript
   const fs = require('fs').promises;

   fs.readFile('example.txt', 'utf8')
     .then(data => {
       console.log('Содержимое файла:', data);
     })
     .catch(err => {
       console.error('Ошибка при чтении файла:', err);
     });
   ```

2. Запустите файл:
   ```bash
   node promise.js
   ```

Этот код использует промисы для работы с файловой системой вместо коллбеков, что упрощает чтение и обработку ошибок.

**Пример 6: Модули и экспорт в Node.js**
Модули — это способ разделения кода на отдельные файлы. Модули можно экспортировать и импортировать в другие файлы.

1. Создайте файл `math.js`:
   ```javascript
   function add(a, b) {
     return a + b;
   }

   function subtract(a, b) {
     return a - b;
   }

   module.exports = { add, subtract };
   ```

2. Теперь создайте файл `app.js`, который импортирует модуль:
   ```javascript
   const math = require('./math');

   console.log('Сумма:', math.add(5, 3));         // 8
   console.log('Разность:', math.subtract(5, 3)); // 2
   ```

3. Запустите файл:
   ```bash
   node app.js
   ```

Это пример того, как можно разделять код на модули и переиспользовать его в разных частях программы.

**Итог:**
- **Node.js** — это мощная серверная среда для выполнения JavaScript на стороне сервера.
- Он отлично подходит для создания масштабируемых веб-приложений, API и микросервисов благодаря асинхронной модели и неблокирующему вводу-выводу.
- Примеры использования Node.js включают создание HTTP-серверов, работу с файлами, использование фреймворков, таких как Express, и работу с асинхронными операциями через промисы.
