**Тернарный оператор** — это условный [оператор](#), который позволяет выполнять условные выражения в одну строку. 
+ Имеет три операнда. 
+ Более краткая запись конструкции `if-else` в одну строку.
+ Он имеет следующий синтаксис:

```javascript
условие ? выражение_если_истина : выражение_если_ложь
```

**Примеры использования тернарного оператора**

1. **Простой пример:**
```javascript
let age = 18;
let message = age >= 18 ?
	"Вы совершеннолетний" :
	"Вы несовершеннолетний";
console.log(message);
// Вывод: Вы совершеннолетний
```

2. **Вложенный тернарный оператор:**
```javascript
let score = 75;
let result = score >= 90 ?
	"Отлично" :
	score >= 70 ?
	"Хорошо" :
	"Удовлетворительно";
console.log(result);
// Вывод: Хорошо
```

3. **Использование с присваиванием:**
```javascript
    let isLoggedIn = true;
    let userStatus = isLoggedIn ? 
    "Вы вошли в систему" : 
    "Пожалуйста, войдите";
    console.log(userStatus); 
    // Вывод: Вы вошли в систему
```

4. **Использование в функциях:**
```javascript
function getDiscount(isMember) {
	return isMember ?
		"Вам предоставляется скидка" :
		"Скидка не предоставляется";
}

console.log(getDiscount(true)); 
// Вывод: Вам предоставляется скидка
console.log(getDiscount(false)); 
// Вывод: Скидка не предоставляется
```

**Преимущества тернарного оператора**

- **Компактность**: Тернарный оператор позволяет писать более компактный код по сравнению с [../../if-else](#).
- **Читаемость**: В некоторых случаях тернарный оператор может сделать код более читаемым, особенно если условие простое.

**Недостатки тернарного оператора**

- **Сложность**: Вложенные тернарные [Операторы](./Операторы) могут сделать код сложным для чтения и понимания.
- **Ограничения**: Тернарный оператор не подходит для сложных условий и многострочных выражений.

**Когда использовать тернарный оператор**

- **Простые условия**: Когда условие простое и результат можно выразить в одну строку.
- **Компактный код**: Когда вам нужно сделать код более компактным и читаемым.

**Когда не использовать тернарный оператор**

- **Сложные условия**: Если условие сложное или требует многострочного выражения, лучше использовать [../../if-else](#).
- **Вложенные условия**: Вложенные тернарные операторы могут сделать код сложным для понимания.

**Пример с `if-else` для сравнения**

```javascript
let age = 18;
let message;

if (age >= 18) {
    message = "Вы совершеннолетний";
} else {
    message = "Вы несовершеннолетний";
}

console.log(message); // Вывод: Вы совершеннолетний
```

В этом примере `if-else` делает код более читаемым и понятным, особенно если условие сложное или требует многострочного выражения.
