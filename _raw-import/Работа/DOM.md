[DOM](./DOM) (Document Object Model) — это объектная модель документа, которая представляет HTML или XML документ в виде структуры дерева. Каждый элемент документа (теги, текст, атрибуты и т.д.) становится узлом этого дерева, с которым можно взаимодействовать с помощью программ, обычно через JavaScript.

Основные особенности DOM:
- DOM позволяет динамически изменять содержимое веб-страницы, добавлять или удалять элементы, изменять их стили и атрибуты.
- В DOM каждый элемент HTML (теги, текст, комментарии и т.д.) представлен как объект, что делает его доступным для программного управления.
- Взаимодействие с DOM осуществляется через стандартные методы и свойства, такие как `getElementById`, `querySelector`, `innerHTML`, и т.д.

Пример структуры DOM для простой HTML-страницы:
```html
<!DOCTYPE html>
<html>
  <head>
    <title>Пример страницы</title>
  </head>
  <body>
    <h1>Заголовок</h1>
    <p>Это абзац текста.</p>
  </body>
</html>
```

Этот HTML-документ будет представлен в виде DOM-дерева примерно так:

```
Document
 └── html
     ├── head
     │   └── title
     │       └── "Пример страницы"
     └── body
         ├── h1
         │   └── "Заголовок"
         └── p
             └── "Это абзац текста."
```

С помощью JavaScript можно управлять элементами этого дерева:
```javascript
// Изменить текст заголовка
document.querySelector('h1').textContent = 'Новый заголовок';

// Добавить новый абзац
let newParagraph = document.createElement('p');
newParagraph.textContent = 'Новый абзац текста.';
document.body.appendChild(newParagraph);
```
