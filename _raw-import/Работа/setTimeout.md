## Примеры использования setTimeout в [JavaScript](./JavaScript):

**1. Простая задержка:**

```js
console.log("Этот текст выведется первым"); 

setTimeout(function() { 
	console.log("Этот текст выведется через 3 секунды"); 
}, 3000); // 3000 миллисекунд = 3 секунды 

console.log("Этот текст выведется вторым");
```
    

В этом примере функция [setTimeout](./setTimeout) запускает анонимную функцию с задержкой 3 секунды.  
Порядок вывода в консоль будет следующим:

1. Этот текст выведется первым
    
2. Этот текст выведется вторым
    
3. Этот текст выведется через 3 секунды
    

**2. Передача аргументов в функцию:**

```js
function greet(name) { 
	console.log("Привет, " + name + "!"); 
} 

setTimeout(greet, 2000, "Анна");
```
    

Здесь мы передаем функцию greet в [setTimeout](./setTimeout) и указываем имя "Анна" в качестве аргумента.  
Через 2 секунды функция `greet` будет вызвана с аргументом `"Анна"`.

**3. Использование стрелочной функции:**

```js
setTimeout(() => {
  console.log("Этот код выполнится через 5 секунд");
}, 5000);
```
    

В этом примере вместо анонимной функции мы используем стрелочную функцию для краткости.

**4. Очистка таймера:**

```js
const timeoutId = setTimeout(() => {
  console.log("Этот текст не будет выведен");
}, 1000);

clearTimeout(timeoutId);
``` 

Здесь мы сохраняем идентификатор таймера, возвращаемый [setTimeout](./setTimeout), в переменной `timeoutId`.  
Затем мы используем clearTimeout с этим идентификатором, чтобы отменить выполнение функции.

**Обратите внимание:** [setTimeout](./setTimeout) не гарантирует точное время выполнения функции.  
Она ставит функцию в очередь на выполнение через заданный интервал времени, но фактическое время выполнения может зависеть от других процессов, выполняемых браузером или сервером.
