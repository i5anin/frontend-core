**URL** (Uniform Resource Locator) — это уникальный адрес, который используется для идентификации ресурсов в Интернете, таких как веб-страницы, файлы, изображения и т.д. Он указывает, где находится ресурс, и как к нему можно получить доступ.

Структура URL:
1. **Протокол** — указывает, какой протокол использовать для доступа к ресурсу (например, [HTTP](./HTTP), `https`, `ftp`):
   ```
   https://
   ```

2. **Доменное имя или IP-адрес** — указывает на сервер, где расположен ресурс:
   ```
   example.com
   ```

3. **Путь к ресурсу** — указывает конкретный файл или страницу на сервере:
   ```
   /articles/12345
   ```

4. **Параметры запроса (опционально)** — данные, передаваемые серверу в виде ключ-значение для получения конкретной информации:
   ```
   ?search=example
   ```

5. **Якорь (опционально)** — указывает на конкретное место внутри веб-страницы:
   ```
   #section2
   ```

Пример полного URL:
```
https://example.com/articles/12345?search=example#section2
```

В данном примере:
- `https://` — протокол,
- `example.com` — доменное имя,
- `/articles/12345` — путь к статье,
- `?search=example` — параметры запроса,
- `#section2` — якорь, указывающий на определённый раздел страницы.

URL помогает браузерам или другим программам находить нужные ресурсы в сети.
