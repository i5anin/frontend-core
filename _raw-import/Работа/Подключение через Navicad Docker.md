Подключение к базе данных, запущенной в контейнере [Docker](./Docker), через Navicat потребует настройки правильных параметров подключения. Вот пошаговая инструкция:

**1. **Убедитесь, что контейнер работает****

Проверьте, запущен ли контейнер с базой данных:

```bash
docker ps
```

Убедитесь, что в списке запущенных контейнеров отображается ваша база данных (например, MySQL, PostgreSQL).

---

**2. **Узнайте порт и IP-адрес****

- Если порт не был явно указан при запуске контейнера, проверьте его с помощью команды:
    
    ```bash
    docker inspect <container_id>
    ```
    
    Найдите секцию `Ports` и убедитесь, что порт хоста привязан к порту базы данных контейнера.
    

Например, для MySQL это может быть `3306:3306`.

- Если вы используете Docker на локальной машине, IP-адресом будет `127.0.0.1`. Если контейнер работает на удалённой машине, используйте её IP-адрес.

---

**3. **Проверьте параметры базы данных****

- Убедитесь, что:
    - В базе данных есть пользователь, доступный для подключения извне.
    - Параметр `bind-address` в конфигурации базы данных настроен на `0.0.0.0`, чтобы принимать внешние подключения.

---

**4. **Подключение через Navicat****

1. Откройте Navicat.
    
2. Нажмите на **Connection** > выберите тип вашей базы данных (например, MySQL, PostgreSQL).
    
3. Заполните параметры:
    
    - **Host**: `127.0.0.1` или IP-адрес сервера.
    - **Port**: внешний порт, на который маппится порт базы данных (например, `3306` для MySQL).
    - **Username**: имя пользователя базы данных.
    - **Password**: пароль для пользователя.
    - **Database**: имя базы данных (можно оставить пустым для подключения ко всему серверу).
4. Нажмите **Test Connection**, чтобы проверить соединение.
    

---

**5. **Тестирование и устранение проблем****

Если подключение не удаётся:

- Убедитесь, что порт открыт в файрволе на сервере (если используется удалённый сервер).
    
- Проверьте логи контейнера:
    
    ```bash
    docker logs <container_id>
    ```
    
- Убедитесь, что пользователь базы данных имеет права для внешнего подключения. Например, в MySQL:
    
    ```sql
    GRANT ALL PRIVILEGES ON *.* TO 'user'@'%' IDENTIFIED BY 'password';
    FLUSH PRIVILEGES;
    ```
    

После выполнения этих шагов вы должны успешно подключиться к базе данных через Navicat.
