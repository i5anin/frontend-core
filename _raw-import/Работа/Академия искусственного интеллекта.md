Для изучения разработки сложных проектов по анализу больших данных с использованием искусственного интеллекта на русском языке, рекомендуется обратить внимание на следующие YouTube-каналы:

1. **Академия искусственного интеллекта**  
    Канал предоставляет материалы по различным аспектам ИИ, включая языковые модели и их применение. 
    
2. **ShvedkovPRO нейросети**  
    Илья Шведков делится новостями, трендами и лайфхаками в области нейросетей и искусственного интеллекта. 
    
3. **Data School**  
    Кевин Маркем предлагает понятные видеоуроки по анализу данных и машинному обучению, что полезно для понимания основ работы с большими данными.
    
4. **Deep Learning School**  
    Канал содержит лекции по глубокому обучению, включая темы, связанные с анализом больших данных. 
    
5. **Computer Science Center**  
    Видеозаписи лекций и докладов по машинному обучению, анализу данных и другим связанным темам. 
    

Эти каналы предлагают широкий спектр материалов, от основ до продвинутых тем, что поможет в освоении разработки проектов по анализу больших данных с использованием ИИ.
