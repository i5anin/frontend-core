`npm` (Node Package Manager) — это менеджер пакетов для JavaScript, который позволяет устанавливать, обновлять и управлять зависимостями вашего проекта. Он является стандартным инструментом для работы с библиотеками и фреймворками, используемыми в приложениях на Node.js и фронтенде.

**Основные команды npm**

1. **Установка пакета**:
   ```bash
   npm install <package-name>
   ```
   Устанавливает пакет в директорию `node_modules` вашего проекта и добавляет его в файл `package.json`.

2. **Установка пакета как зависимости разработки**:
   ```bash
   npm install <package-name> --save-dev
   ```
   Устанавливает пакет, который нужен только во время разработки (например, тестовые библиотеки).

3. **Удаление пакета**:
   ```bash
   npm uninstall <package-name>
   ```
   Удаляет пакет из директории `node_modules` и `package.json`.

4. **Обновление пакета**:
   ```bash
   npm update <package-name>
   ```
   Обновляет пакет до последней версии, соответствующей указанным в `package.json` ограничениям.

5. **Просмотр устаревших пакетов**:
   ```bash
   npm outdated
   ```
   Показывает список пакетов, которые устарели, и их доступные обновления. Выводит следующую информацию:
   - Текущая версия (`Current`).
   - Версия, которая установлена в `package.json` (`Wanted`).
   - Последняя доступная версия (`Latest`).

6. **Просмотр установленных пакетов**:
   ```bash
   npm list
   ```
   Показывает дерево установленных пакетов в текущем проекте.

7. **Список глобально установленных пакетов**:
   ```bash
   npm list -g --depth=0
   ```
   Отображает все глобально установленные пакеты без их зависимостей.

8. **Инициализация нового проекта**:
   ```bash
   npm init
   ```
   Запускает интерактивный процесс создания файла `package.json`. Используйте `npm init -y`, чтобы пропустить вопросы и создать файл с настройками по умолчанию.

9. **Установка всех зависимостей**:
   ```bash
   npm install
   ```
   Устанавливает все зависимости, перечисленные в `package.json`.

10. **Запуск скрипта из `package.json`**:
    ```bash
    npm run <script-name>
    ```
    Запускает скрипт, определенный в разделе `scripts` вашего `package.json`.

**Пример использования команды `npm outdated`**

Если вы хотите проверить, какие пакеты в вашем проекте устарели, выполните:

```bash
npm outdated
```

Пример вывода может выглядеть следующим образом:

```
Package      Current  Wanted  Latest  Location
lodash       4.17.15  4.17.21  4.17.21  my-project
express      4.17.1   4.17.2   4.18.0   my-project
```

В этом примере:
- `lodash` текущая версия `4.17.15`, последняя версия, доступная для установки, — `4.17.21`.
- `express` текущая версия `4.17.1`, но доступна версия `4.18.0`.

**Заключение**

`npm` — мощный инструмент для управления зависимостями в проектах JavaScript. Используя команды, такие как `npm outdated`, вы можете поддерживать свои пакеты в актуальном состоянии и обеспечивать стабильность и безопасность вашего приложения.
