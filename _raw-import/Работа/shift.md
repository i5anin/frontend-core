**`shift()`** — это метод массивов в [JavaScript](./JavaScript), который удаляет **первый элемент** массива. Он изменяет исходный массив и возвращает удалённый элемент. Если массив пуст, метод возвращает `undefined`.

**Синтаксис:**

```javascript
array.shift()
```

- Метод **не принимает аргументов**.
- Возвращает первый элемент массива или `undefined`, если массив пуст.

**Пример использования:**

```javascript
let fruits = ['яблоко', 'банан', 'апельсин'];
let firstFruit = fruits.shift();

console.log(fruits);      // ['банан', 'апельсин']
console.log(firstFruit);  // 'яблоко'
```

В этом примере первый элемент массива `'яблоко'` был удалён, а метод `shift()` вернул его. Массив `fruits` изменился — теперь в нём только два элемента.

**Пример с пустым массивом:**

```javascript
let emptyArray = [];
let result = emptyArray.shift();

console.log(result);  // undefined
```

Если вызвать `shift()` для пустого массива, метод вернёт `undefined`, так как удалять нечего.

**Основные моменты:**
- **`shift()`** удаляет первый элемент массива.
- Возвращает удалённый элемент.
- Изменяет исходный массив.
- Если массив пуст, возвращает `undefined`.
