Вот краткий, но систематизированный обзор по легендарной книге **«Design Patterns: Elements of Reusable Object-Oriented Software»**, написанной «бандой четырёх» (Gang of Four — GoF): **Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides**.

---

## 📚 Общее описание

**Название:**  
_Design Patterns: Elements of Reusable Object-Oriented Software_

**Авторы:**  
Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides  
(также известны как GoF — Gang of Four)

**Год издания:**  
1994

**Язык оригинала:**  
Английский

**Применение:**  
Разработка ПО с применением **объектно-ориентированного подхода** (особенно на языках: C++, Java, C#, Python, PHP, Ruby).

---

## 🧱 Цель книги

1. **Формализовать** лучшие практики проектирования на основе опыта.
    
2. Предложить **общий словарь шаблонов** между разработчиками.
    
3. Повысить **переиспользуемость и поддерживаемость кода**.
    

---

## 🧩 Классификация паттернов

Все 23 паттерна в книге делятся на **три группы**:

|Категория|Назначение|
|---|---|
|**Порождающие (Creational)**|Управляют созданием объектов|
|**Структурные (Structural)**|Определяют состав иерархий классов и объектов|
|**Поведенческие (Behavioral)**|Отвечают за взаимодействие между объектами|

---

**🔨 Порождающие шаблоны (Creational)**

|Шаблон|Назначение|
|---|---|
|Singleton|Единственный экземпляр|
|Factory Method|Создание объектов через фабричный метод|
|Abstract Factory|Создание семейств объектов|
|Builder|Пошаговая сборка объекта|
|Prototype|Клонирование объектов|

---

**🏗️ Структурные шаблоны (Structural)**

|Шаблон|Назначение|
|---|---|
|Adapter|Преобразование интерфейсов|
|Bridge|Разделение абстракции и реализации|
|Composite|Деревья объектов (иерархии)|
|Decorator|Расширение функциональности|
|Facade|Упрощённый интерфейс к подсистеме|
|Flyweight|Разделяемые объекты (экономия памяти)|
|Proxy|Заместитель объекта с дополнительным поведением|

---

**🔁 Поведенческие шаблоны (Behavioral)**

|Шаблон|Назначение|
|---|---|
|Chain of Responsibility|Цепочка обработчиков|
|Command|Объект-команда|
|Interpreter|Интерпретатор языка|
|Iterator|Перебор элементов|
|Mediator|Посредник для связи объектов|
|Memento|Сохранение состояния|
|Observer|Подписка/извещение|
|State|Поведение в зависимости от состояния|
|Strategy|Выбор поведения на лету|
|Template Method|Шаблонный метод с шагами|
|Visitor|Расширение поведения без изменения классов|

## 🧠 Ключевые идеи

- **Разделение ответственности**: каждый паттерн решает конкретную задачу.
    
- **Инкапсуляция изменений**: паттерны позволяют менять поведение без изменения существующего кода.
    
- **Принципы SOLID** используются как основа проектирования.

## 📌 Примеры (на JavaScript)

**Пример паттерна Singleton:**

```js
class Singleton {
  constructor() {
    if (Singleton.instance) {
      return Singleton.instance
    }
    Singleton.instance = this
    this.data = Math.random()
  }

  getData() {
    return this.data
  }
}

const a = new Singleton()
const b = new Singleton()

console.log(a === b) // true
```

## 💡 Почему эта книга важна

- До сих пор считается **стандартом** в проектировании программного обеспечения.
    
- Формирует **инженерное мышление** и помогает писать поддерживаемый, расширяемый код.
    
- Заложила основу для **архитектурных подходов**: MVC, MVVM, DDD и др.
    

---

## 📘 Советы по изучению

1. Изучай паттерны **по мере появления проблемы**, а не все сразу.
    
2. Используй **визуализации и примеры на своём языке программирования**.
    
3. Применяй паттерны в своих проектах — **на практике** они усваиваются лучше.
    
4. Подчёркивай принципы: **инверсия зависимостей**, **открытость/закрытость**, **разделение интерфейсов**.
