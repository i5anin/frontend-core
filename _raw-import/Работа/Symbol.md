`Symbol` — это встроенный примитивный тип данных в JavaScript, который был введён в ES6. Он используется для создания уникальных идентификаторов. Каждый `Symbol` уникален, даже если они создаются с одним и тем же описанием. Это полезно для создания уникальных свойств объекта, чтобы избежать конфликта с другими свойствами или случайного их переопределения.

**Создание символов**

Символы создаются с помощью функции `Symbol()`:

```javascript
const symbol1 = Symbol();
const symbol2 = Symbol("description"); // описание помогает при отладке, но не влияет на уникальность
```

Каждый вызов `Symbol()` создает уникальный символ:

```javascript
const symbolA = Symbol("id");
const symbolB = Symbol("id");

console.log(symbolA === symbolB); // false
```

**Использование символов в объектах**

Символы могут использоваться как уникальные ключи в объектах:

```javascript
const uniqueKey = Symbol("uniqueKey");

const user = {
  name: "Alice",
  [uniqueKey]: "Это значение символа"
};

console.log(user[uniqueKey]); // "Это значение символа"
```

Свойства, добавленные через символы, не будут отображаться при итерации через `for...in` или при использовании `Object.keys()`, что делает их полезными для создания скрытых или «приватных» свойств.

**Встроенные символы**

JavaScript также имеет набор встроенных символов, которые можно использовать для изменения поведения объектов:

1. **`Symbol.iterator`** — используется для создания итераторов.
2. **`Symbol.toStringTag`** — изменяет результат `Object.prototype.toString`.
3. **`Symbol.hasInstance`** — настраивает поведение оператора `instanceof`.
4. **`Symbol.toPrimitive`** — настраивает преобразование объекта к примитиву.

Пример использования `Symbol.iterator`:

```javascript
const iterableObj = {
  *[Symbol.iterator]() {
    yield 1;
    yield 2;
    yield 3;
  }
};

for (const value of iterableObj) {
  console.log(value); // 1, 2, 3
}
```

**Глобальный реестр символов**

Для создания символов, которые могут быть доступны в глобальном масштабе, используется `Symbol.for()` и `Symbol.keyFor()`:

```javascript
const globalSymbol = Symbol.for("sharedKey");
const sameGlobalSymbol = Symbol.for("sharedKey");

console.log(globalSymbol === sameGlobalSymbol); // true
```

`Symbol.keyFor()` возвращает описание символа, зарегистрированного в глобальном реестре:

```javascript
console.log(Symbol.keyFor(globalSymbol)); // "sharedKey"
```

**Зачем нужны символы?**

Символы полезны для:

1. **Создания уникальных ключей** в объектах, которые не будут случайно переопределены.
2. **Скрытых свойств**, которые не отображаются при обычной итерации.
3. **Переопределения стандартного поведения объектов** через встроенные символы.

`Symbol` помогает разработчикам создавать более защищённые и предсказуемые структуры данных, особенно в крупных проектах и библиотеках.
