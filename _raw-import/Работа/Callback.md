**Callback** (или колбэк) в [JavaScript](./JavaScript) — это функция, которая передается другой функции в качестве аргумента и вызывается после завершения операции в этой функции.

**Пример использования:**

1. **Простой пример с функцией обратного вызова**:

```javascript
function greeting(name, callback) {
  console.log(`Привет, ${name}`);
  callback();
}

function sayGoodbye() {
  console.log('До свидания!');
}

greeting('Анна', sayGoodbye);

// Вывод:
// Привет, Анна
// До свидания!
```

В данном примере `sayGoodbye` передается как callback и вызывается внутри функции `greeting` после выполнения основного действия (вывода приветствия).

2. **[Callback](./Callback) с асинхронными операциями**:

Колбэки часто используются для обработки асинхронных операций, таких как запросы к серверу.

```javascript
function fetchData(callback) {
  setTimeout(() => {
    console.log('Данные получены');
    callback();
  }, 1000);
}

function processData() {
  console.log('Обработка данных');
}

fetchData(processData);

// Вывод:
// Данные получены
// Обработка данных
```

**Важные моменты:**
- **[Callback](./Callback)** помогает избежать блокировки выполнения программы, особенно при работе с асинхронными операциями.
- Колбэки можно передавать как именованные функции или анонимные (функции без имени).

```javascript
fetchData(function() {
  console.log('Анонимная функция как callback');
});
```

Это мощный механизм для управления последовательностью выполнения операций в [JavaScript](./JavaScript).
