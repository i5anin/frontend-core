Свойства[../Vue/Vue.js](#) можно разделить на несколько категорий: свойства экземпляра [../Vue/Vue.js](#), вычисляемые свойства, и наблюдатели. Вот основные свойства, которые используются в [../Vue/Vue.js](#):

**1. **Реактивные свойства экземпляра [../Vue/Vue.js](#)****
   Эти свойства определяются в объекте данных компонента:

   - **`data`** – Определяет реактивные данные для компонента.
     ```javascript
     data() {
       return {
         message: 'Привет, Vue!'
       };
     }
     ```

   - **[props](./props)** – Позволяет передавать данные в компонент от родителя.
     ```javascript
     props: ['title']
     ```

   - **[computed](./computed)** – Определяет вычисляемые свойства, которые автоматически обновляются при изменении зависимых данных.
     ```javascript
     computed: {
       reversedMessage() {
         return this.message.split('').reverse().join('');
       }
     }
     ```

   - **[../Vue/vue new/methods](#)** – Объект, содержащий функции, которые можно вызывать внутри компонента.
     ```javascript
     methods: {
       greet() {
         return 'Привет!';
       }
     }
     ```

   - **[watch](./watch)** – Позволяет наблюдать за изменениями реактивных данных и выполнять действия при их изменении.
     ```javascript
     watch: {
       message(newValue, oldValue) {
         console.log(`Сообщение изменилось с ${oldValue} на ${newValue}`);
       }
     }
     ```

**2. **Системные свойства [../Vue/Vue.js](#)****

   - **[el](#)** – Указывает элемент, к которому привязан экземпляр Vue (обычно используется при создании нового экземпляра).
     ```javascript
     el: '#app'
     ```

   - **[template](#)** – Определяет шаблон компонента.
     ```javascript
     template: '<div>{{ message }}</div>'
     ```

   - **[render](#)** – Позволяет указать, как должен рендериться компонент с использованием JavaScript.
     ```javascript
     render(h) {
       return h('div', this.message);
     }
     ```

   - **[../mounted](#)** – Жизненный цикл компонента, когда он уже добавлен в [DOM](./DOM).
     ```javascript
     mounted() {
       console.log('Компонент смонтирован');
     }
     ```

   - **[Объект data (vue)](./Объект data (vue))()** – Возвращает объект с реактивными данными.

**3. **Пользовательские и встроенные директивы****

   - **[v-model](./v-model)** – Связывает данные с элементом формы.
     ```html
     <input v-model="message">
     ```

   - **[v-if, v-else-if, v-else](./v-if, v-else-if, v-else)** – Управляют условным отображением элементов.
     ```html
     <p v-if="isVisible">Элемент виден</p>
     ```

   - **[v-for](./v-for)** – Используется для перебора массивов или объектов.
     ```html
     <li v-for="item in items">{{ item }}</li>
     ```

Эти свойства дают гибкость при управлении данными и поведением приложения на Vue.js.
