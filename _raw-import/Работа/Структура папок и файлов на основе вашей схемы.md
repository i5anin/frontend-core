Расположение: `client/src/pages`

**Структура:**

```plaintext
/pages
```

****2. Modules (Модули)****

Расположение: `client/src/modules`

**Структура:**

```plaintext
/modules
  ├── table                       // Модуль таблицы
  │   ├── TableAPI.js             // API-запросы для таблицы
  │   ├── TableStore.js           // Состояние таблицы (Pinia/Vuex)
  │   ├── components              // Компоненты таблицы
  │   │   ├── Table.vue           // Таблица (основной компонент)
  │   │   ├── TableSearch.vue     // Поиск
  │   │   ├── TableDatePicker.vue // Дата пикер
  │   │   └── TablePagination.vue // Пагинация
  │   └── TableLogic.js           // Логика таблицы
  ├── nomenclature                // Модуль номенклатуры
  │   ├── NomenclatureAPI.js      // API-запросы для номенклатуры
  │   ├── NomenclatureStore.js    // Состояние номенклатуры
  │   ├── components              // Компоненты номенклатуры
  │   │   ├── NomenclatureTable.vue    // Таблица номенклатуры
  │   │   ├── NomenclatureFilters.vue  // Фильтры
  │   │   └── NomenclatureDetails.vue  // Детали
  │   └── NomenclatureLogic.js    // Логика номенклатуры
  ├── serverAssembly              // Модуль сборки сервер-сайд
  │   ├── ServerAssemblyAPI.js    // API-запросы для сборки
  │   ├── ServerAssemblyStore.js  // Состояние сборки
  │   └── ServerAssemblyLogic.js  // Логика сборки
  └── card                        // Модуль карточки
      ├── CardAPI.js              // API-запросы для карточки
      ├── components              // Компоненты карточки
      │   ├── CardEditable.vue    // Редактируемая часть
      │   ├── CardReadonly.vue    // Не редактируемая часть
      │   └── CardComments.vue    // Комментарии
      └── CardLogic.js            // Логика карточки
```

**Описание ключевых принципов:**

1. **Pages (Страницы):**
    
    - Содержат минимальную бизнес-логику.
    - В основном, соединяют модули и компоненты.
2. **Modules (Модули):**
    
    - Управляют бизнес-логикой.
    - Содержат API, хранилище состояния и переиспользуемые компоненты.
3. **Components (Компоненты):**
    
    - Минимальная логика (в основном, отображение).
    - Переиспользуемые UI-элементы.
4. **UI:**
    
    - Структура, ответственная за глобальные стили и внешний вид.
