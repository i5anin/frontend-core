В [JavaScript](./JavaScript) конструкции **`if`** и **`else`** используются для выполнения кода в зависимости от определенных условий. Они помогают контролировать поток выполнения программы, проверяя условия и выполняя различные блоки кода в зависимости от истинности (true) или ложности (false) этих условий.

**Синтаксис `if`:**

```javascript
if (условие) {
  // код, который выполнится, если условие истинно (true)
}
```

**Синтаксис `if-else`:**

```javascript
if (условие) {
  // код, который выполнится, если условие истинно (true)
} else {
  // код, который выполнится, если условие ложно (false)
}
```

**Синтаксис `if-else if-else`:**

```javascript
if (условие1) {
  // код, который выполнится, если условие1 истинно (true)
} else if (условие2) {
  // код, который выполнится, если условие2 истинно (true)
} else {
  // код, который выполнится, если ни одно из условий не истинно
}
```

**Примеры:**

**1. Простой `if`:**
```javascript
let age = 18;

if (age >= 18) {
  console.log('Вы совершеннолетний');
}
// Вывод: Вы совершеннолетний
```

**2. `if-else`:**
```javascript
let age = 16;

if (age >= 18) {
  console.log('Вы совершеннолетний');
} else {
  console.log('Вы несовершеннолетний');
}
// Вывод: Вы несовершеннолетний
```

**3. `if-else if-else`:**
```javascript
let age = 20;

if (age < 13) {
  console.log('Ребенок');
} else if (age >= 13 && age < 18) {
  console.log('Подросток');
} else {
  console.log('Взрослый');
}
// Вывод: Взрослый
```

**[../JavaScript/Операторы/Тернарный оператор](#) (`?:`):**

JavaScript также поддерживает тернарный оператор, который является короткой формой для `if-else`. Он используется для простых условий, когда нужно вернуть одно из двух значений на основе условия.

Синтаксис:
```javascript
условие ? выражение1 : выражение2
```

Пример:
```javascript
let age = 20;
let message = age >= 18 ? 'Совершеннолетний' : 'Несовершеннолетний';
console.log(message);
// Вывод: Совершеннолетний
```

**Использование `if` с логическими операторами:**

1. **[Логическое И](#) (`&&`)**:
   Проверяет, что оба условия истинны.
   ```javascript
   let age = 25;
   if (age > 18 && age < 30) {
     console.log('Молодой человек');
   }
   // Вывод: Молодой человек
   ```

2. **[Логическое ИЛИ](#) (`||`)**:
   Проверяет, что хотя бы одно из условий истинно.
   ```javascript
   let age = 15;
   if (age < 13 || age > 65) {
     console.log('Вы либо ребенок, либо пожилой человек');
   }
   // Вывод: ничего, так как оба условия ложны
   ```

3. **[Логическое НЕ](#) (`!`)**:
   Инвертирует значение условия.
   ```javascript
   let isActive = false;
   if (!isActive) {
     console.log('Пользователь не активен');
   }
   // Вывод: Пользователь не активен
   ```

**Итог:**
- **`if`** — выполняет блок кода, если условие истинно.
- **`else`** — выполняет альтернативный блок кода, если условие ложно.
- **`else if`** — используется для проверки нескольких условий.
- **Тернарный оператор** (`?:`) — это короткая форма для `if-else`, которая используется для простых условий.

Эти конструкции позволяют легко управлять логикой программы в зависимости от различных условий.
