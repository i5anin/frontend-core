****Запросы на извлечение данных****

- **SELECT** [Основное с примерами#1. **SELECT**](./Основное с примерами#1.-**select**) 
    - `SELECT * FROM employees;`
    - `SELECT name, position FROM employees;`
    - `SELECT * FROM employees WHERE department = 'Sales';`

****Запросы на добавление данных****

- **INSERT INTO** [Основное с примерами#2. **INSERT INTO**](./Основное с примерами#2.-**insert-into**) 
    - `INSERT INTO employees (name, position, department, salary) VALUES ('John Doe', 'Developer', 'IT', 60000);`

****Запросы на изменение данных****

- **UPDATE**
    - `UPDATE employees SET salary = 65000 WHERE id = 1;`
    - `UPDATE employees SET position = 'Senior Sales Representative' WHERE department = 'Sales';`

****Запросы на удаление данных****

- **DELETE**
    - `DELETE FROM employees WHERE id = 1;`
    - `DELETE FROM employees WHERE department = 'HR';`

****Запросы на создание объектов****

- **CREATE TABLE**
    - `CREATE TABLE employees (id SERIAL PRIMARY KEY, name VARCHAR(100) NOT NULL, position VARCHAR(100), department VARCHAR(100), salary DECIMAL(10, 2));`

****Запросы на изменение структуры объектов****

- **ALTER TABLE**
    - `ALTER TABLE employees ADD hire_date DATE;`
    - `ALTER TABLE employees ALTER COLUMN salary TYPE INTEGER;`

****Запросы на удаление объектов****

- **DROP TABLE**
    - `DROP TABLE employees;`

****Запросы на объединение таблиц****

- **JOIN**
    - `SELECT employees.name, departments.department_name FROM employees INNER JOIN departments ON employees.department_id = departments.id;`
    - `SELECT employees.name, departments.department_name FROM employees LEFT JOIN departments ON employees.department_id = departments.id;`

****Запросы на группировку и фильтрацию****

- **GROUP BY**
    
    - `SELECT department, COUNT(*) AS employee_count FROM employees GROUP BY department;`
    - `SELECT department, AVG(salary) AS avg_salary FROM employees GROUP BY department;`
- **HAVING**
    
    - `SELECT department, COUNT(*) AS employee_count FROM employees GROUP BY department HAVING COUNT(*) > 10;`

****Запросы на сортировку данных****

- **ORDER BY**
    - `SELECT * FROM employees ORDER BY salary DESC;`
    - `SELECT * FROM employees ORDER BY name ASC;`
