Примеры ссылок в Markdown:

1. **Обычная ссылка**:
```markdown
[Текст ссылки](https://example.com)
```
**Результат**: [Текст ссылки](https://example.com)

2. **Ссылка с подсказкой при наведении**:
```markdown
[Текст ссылки с подсказкой](https://example.com "Описание при наведении")
```
**Результат**: [Текст ссылки с подсказкой](https://example.com "Описание при наведении")

3. **Голая URL**:
```markdown
https://example.com
```
**Результат**: https://example.com

4. **Ссылка на заголовок внутри документа**:
```markdown
[К разделу](#раздел)
```
**Результат**: [К разделу](#раздел)

5. **Ссылка с использованием референса**:
```markdown
[Текст ссылки][ссылка1]

[ссылка1]: https://example.com
```
**Результат**: [Текст ссылки][ссылка1]
