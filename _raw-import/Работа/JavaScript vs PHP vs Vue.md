# JavaScript vs PHP vs Vue

---

## Суть каждого

| | JavaScript | PHP | Vue |
|---|---|---|---|
| **Тип** | Язык | Язык | Фреймворк (на JS) |
| **Где работает** | Браузер / Node.js | Сервер | Браузер |
| **Для чего** | Логика на клиенте, DOM | Генерация HTML, API, БД | Реактивный UI, SPA |
| **Типизация** | Динамическая | Динамическая | Динамическая |

---

## JavaScript

```js
document.getElementById('app').textContent = 'Hello'
```

- Язык браузера — единственный способ запустить код на клиенте
- Через Node.js работает и на сервере
- Основа для всех JS-фреймворков (Vue, React, Angular)

---

## PHP

```php
<?php echo "Hello, World!"; ?>
```

- Выполняется на сервере, отдаёт готовый HTML
- Встроенная работа с MySQL, сессиями, куками
- Актуален для легаси-проектов и WordPress

---

## Vue

```vue
<template>
  <p>{{ message }}</p>
</template>

<script setup>
const message = 'Hello, Vue!'
</script>
```

- Реактивность: данные изменились → UI обновился автоматически
- Компоненты: UI разбит на переиспользуемые блоки
- Работает поверх JS, не заменяет его

---

## Когда что использовать

| Задача | Инструмент |
|---|---|
| Интерактивность на странице | JavaScript |
| Серверная логика, работа с БД | PHP (или Node.js/NestJS) |
| Сложный реактивный интерфейс, SPA | Vue |
| Полный стек | Vue (фронт) + PHP или Node (бэк) |
