Чтобы отключить перенос строк в таблице, можно использовать свойство [CSS](./CSS) `white-space: nowrap`. Это свойство предотвращает перенос текста на новую строку. Вот пример, как можно применить его к таблице или ячейкам таблицы:

```css
table {
  white-space: nowrap;
}

td {
  white-space: nowrap;
}
```

Если нужно применить это только к определённым столбцам или ячейкам таблицы, можно использовать классы:

```css
.no-wrap {
  white-space: nowrap;
}
```

И добавить этот класс в HTML-код таблицы:

```html
<td class="no-wrap">Текст без переноса</td>
```

Это гарантирует, что текст в ячейках будет отображаться в одну строку, и не будет переноситься на новую строку, даже если текст превышает ширину ячейки.
