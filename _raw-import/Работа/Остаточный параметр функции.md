**Объяснение:**

Остаточные параметры (rest parameters) в [JavaScript](./JavaScript) позволяют передавать неопределенное количество аргументов в функцию в виде массива. Они введены в ECMAScript 6 (ES6) и представляют собой способ собрать все оставшиеся аргументы функции в один массив.


```js
function sum(...numbers) {
    return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(1, 2, 3, 4)); // Вывод: 10
console.log(sum(5, 10, 15)); // Вывод: 30
```
