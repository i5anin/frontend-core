Вот структура **Feature-Sliced Design (FSD)**, начиная с **первого уровня и далее по уровням вложенности**, максимально подробно, актуально на 2025 год.

---

## 🧩 Уровень 1: Корневые слои (Layers)

Это основные слои архитектуры. Все, что выше — использует то, что ниже, но не наоборот (strict dependency rule):

```
src/
├── app/           # Инициализация приложения, провайдеры
├── processes/     # Сквозные бизнес-процессы (use-case level)
├── pages/         # Страницы маршрутов
├── widgets/       # Виджеты — готовые блоки страниц
├── features/      # Фичи — единичные действия пользователя
├── entities/      # Бизнес-сущности (состояние, поведение)
├── shared/        # Переиспользуемые утилиты, UI, хелперы и API
```

---

## 📂 Уровень 2: Слои → Слайсы (Slices)

Каждая директория внутри слоя — **слайс**, выделенный по смыслу. Например:

```
features/
├── add-to-cart/
├── login-user/
├── toggle-theme/

entities/
├── user/
├── cart/
├── product/
```

---

## 📁 Уровень 3: Слайс → Модули (Segments)

Каждый слайс включает в себя строго определенные сегменты:

```
cart/
├── model/         # Состояние (store, effects)
├── ui/            # Компоненты
├── lib/           # Местные хелперы
├── api/           # Запросы, DTO
├── config/        # Константы, настройки
├── types/         # Типы (вне API)
├── index.js       # Публичный API слайса
```

---

## 📄 Уровень 4: Внутри сегментов

Например:

```
model/
├── useCart.js          # Локальный стор или hook
├── cartSlice.js        # Redux/Pinia slice
├── effects.js          # Побочные эффекты (например, загрузка с сервера)

ui/
├── CartList.vue
├── CartItem.vue

api/
├── cart.api.js
├── cart.dto.js

lib/
├── calcTotal.js

config/
├── constants.js

types/
├── cart.types.js
```

---

## 🔁 Уровень 5: Связи между слоями (dependency flow)

```
shared  →  entities  →  features  →  widgets  →  pages  →  processes  →  app
```

- `shared` ничего не импортирует сверху.
    
- `entities` могут использовать `shared`, но не `features` и выше.
    
- `features` используют `entities` и `shared`.
    
- `widgets` объединяют `features`, `entities`, `shared`.
    
- `pages` собирают `widgets`, `features`, `entities`.
    
- `processes` могут объединять несколько страниц, фич, логики.
    
- `app` инициализирует всё (router, store, i18n, providers).
    

---

## 🧱 Уровень 6: Вспомогательные директории

В корне `src/` также может быть:

```
src/
├── app/              # Входная точка, глобальные провайдеры
├── shared/           # Переиспользуемое
│   ├── ui/           # Глобальные компоненты (Button, Input)
│   ├── lib/          # Утилиты (date, math)
│   ├── config/       # Настройки (env, роутинг)
│   ├── api/          # Общие API-интерфейсы
│   ├── i18n/         # Интернационализация
│   ├── theme/        # Переменные стилей
│   └── styles/       # Глобальные стили
```

---

## ✅ Уровень 7: Public API каждого слайса

Каждый слайс (например `cart`) экспортирует публичный интерфейс через `index.js`:

```js
// entities/cart/index.js
export * from './model'
export * from './ui'
export * from './lib'
```

Это упрощает использование и инкапсулирует структуру.

---

## 📦 Уровень 8: Feature-модули для конкретных юзкейсов

В `processes/` объединяются разные фичи для завершения бизнес-сценария:

```
processes/
├── checkout/
│   ├── index.js
│   ├── model/
│   ├── lib/
│   └── ui/
```

Это слой бизнес-процессов. Здесь можно объединять `features`, `entities`, `widgets`.

---

## 🧭 Уровень 9: Pages и Routing

```
pages/
├── CartPage/
│   ├── index.vue
│   └── model.js     # Логика только этой страницы
```

Каждая страница соответствует маршруту и собирает виджеты, фичи, сущности в готовый экран.

---

## 📐 Уровень 10: Entry Point (`app/`)

```
app/
├── index.js         # main.js для Vue
├── providers/       # Обертки над store/router
├── router/          # Маршруты
├── store/           # Инициализация глобального стора
├── styles/          # Глобальные подключения стилей
└── config/          # Глобальные конфиги
```

---

## Вывод

Ты получил **полную многоуровневую структуру Feature-Sliced Design**:

- Слои → Слайсы → Сегменты → Файлы
    
- Публичные API каждого слайса
    
- Строгая зависимость между слоями
    
- Масштабируемость, читаемость, изоляция ответственности
    

Если нужно: могу сгенерировать шаблон проекта, скрипт автогенерации структуры или адаптировать под твой стек (Vue 3 + Pinia + Router + API). Готов продолжать.
