SSR (Server-Side Rendering) — это метод рендеринга веб-страниц на сервере, а не на клиенте. При SSR сервер генерирует готовую [HTML](./HTML)-страницу и отправляет её в браузер пользователя, что позволяет ускорить отображение контента, улучшить SEO и повысить производительность на устройствах с низкими ресурсами.

**Как работает SSR:**
1. Браузер отправляет запрос на сервер.
2. Сервер рендерит страницу, выполняя необходимый [JavaScript](./JavaScript) и генерируя [HTML](./HTML)-код.
3. Готовый [HTML](./HTML) отправляется в браузер, который отображает страницу.
4. После этого клиентская часть ([JavaScript](./JavaScript)) может "оживить" приложение, добавив интерактивность.

**Преимущества SSR:**
- **Улучшенное SEO**: Поскольку поисковые боты получают готовую HTML-страницу, они лучше индексируют сайт.
- **Быстрая первая отрисовка**: Пользователь видит контент быстрее, так как сервер отправляет готовый HTML-код, а не ждет загрузки и выполнения клиентских скриптов.
- **Лучшая поддержка для медленных устройств**: SSR снижает нагрузку на клиентскую сторону, так как основные вычисления выполняются на сервере.

**Недостатки SSR:**
- **Нагрузка на сервер**: Генерация HTML на сервере требует больше ресурсов и увеличивает время обработки запросов.
- **Сложность разработки**: Нужно учитывать синхронизацию состояния между серверной и клиентской частью.

**Пример SSR с использованием [../Vue/Vue.js](#) и [Nuxt.js](./Nuxt.js):**
`Nuxt.js` — это фреймворк для [../Vue/Vue.js](#), который поддерживает SSR "из коробки".

**Установка Nuxt.js:**
```bash
npx create-nuxt-app my-app
```

**Пример страницы с SSR:**
```javascript
<template>
  <div>
    <h1>{{ title }}</h1>
  </div>
</template>

<script>
export default {
  asyncData() {
    return {
      title: 'Серверный рендеринг с Nuxt.js'
    }
  }
}
</script>
```

Здесь `asyncData` загружает данные перед рендерингом на сервере, и готовая страница отправляется пользователю.

**Пример SSR с использованием [Next.js](#) для [React.js](./React.js):**
[Next.js](#) — это фреймворк для React, поддерживающий SSR.

**Установка Next.js:**
```bash
npx create-next-app my-app
```

**Пример страницы с SSR:**
```javascript
import React from 'react';

const Home = ({ data }) => (
  <div>
    <h1>{data.title}</h1>
  </div>
);

export async function getServerSideProps() {
  const res = await fetch('https://api.example.com/data');
  const data = await res.json();

  return { props: { data } };
}

export default Home;
```

`getServerSideProps` выполняется на сервере перед рендерингом страницы, что обеспечивает SSR.

SSR широко используется в современных веб-приложениях для улучшения производительности и SEO, особенно при использовании фреймворков, таких как Nuxt.js для Vue и Next.js для React.
