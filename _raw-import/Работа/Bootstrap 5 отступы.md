  > [!NOTE]
  >### Полный список классов `padding`:
  >
  >- **`p-{n}`** — общий отступ со всех сторон. 
  >- **`pt-{n}`** — отступ сверху (top).
  >- **`pb-{n}`** — отступ снизу (bottom).
  >- **`ps-{n}`** — отступ слева (start в LTR).
  >- **`pe-{n}`** — отступ справа (end в LTR).


  >[!DANGER]
  >В [Bootstrap](./Bootstrap) 5 произошли изменения в системе классов отступов, чтобы поддерживать разные направления текста 
  >- LTR — слева направо и RTL — справа налево. 
  >- Классы отступов, которые раньше использовались как 
  >	- `ml` (margin-left) и 
  >	- `mr` (margin-right), 
  >- **перестали поддерживаться**
  >- были заменены на более универсальные: 
  >	- `ms` (margin-start) и 
  >	- `me` (margin-end).

  >[!WARNING]
 >- **`ms-{n}`** — для задания отступа от начала (start). В LTR это будет слева, а в RTL — справа.
 >- **`me-{n}`** — для задания отступа от конца (end). В LTR это будет справа, а в RTL — слева.

**Как переводятся классы отступов:**

- **`ms-{n}`** — отступ от начала (start), который слева для LTR (left-to-right) и справа для RTL (right-to-left).
- **`me-{n}`** — отступ от конца (end), который справа для LTR и слева для RTL.

**Классы отступов:**

| Класс    | Значение отступа    | Описание                    |
|----------|---------------------|-----------------------------|
| `ms-0`   | `margin-left: 0`     | Нет отступа от начала        |
| `ms-1`   | `margin-left: 0.25rem` | Малый отступ от начала       |
| `ms-2`   | `margin-left: 0.5rem`  | Средний отступ от начала     |
| `ms-3`   | `margin-left: 1rem`    | Больший отступ от начала     |
| `ms-4`   | `margin-left: 1.5rem`  | Очень большой отступ от начала |
| `ms-5`   | `margin-left: 3rem`    | Максимальный отступ от начала |

Аналогично с классами для конца (`me`):

| Класс    | Значение отступа    | Описание                    |
|----------|---------------------|-----------------------------|
| `me-0`   | `margin-right: 0`    | Нет отступа от конца         |
| `me-1`   | `margin-right: 0.25rem` | Малый отступ от конца        |
| `me-2`   | `margin-right: 0.5rem`  | Средний отступ от конца      |
| `me-3`   | `margin-right: 1rem`    | Больший отступ от конца      |
| `me-4`   | `margin-right: 1.5rem`  | Очень большой отступ от конца |
| `me-5`   | `margin-right: 3rem`    | Максимальный отступ от конца |

**Примеры использования:**

1. **Отступ слева (в LTR) или справа (в RTL)**:
   
   ```html
   <div class="ms-3">
   Контент с отступом от начала на 1rem
   </div>
   ```

2. **Отступ справа (в LTR) или слева (в RTL)**:
   
   ```html
   <div class="me-2">
   Контент с отступом от конца на 0.5rem
   </div>
   ```

**Зачем это сделано?**

Подход с `ms` (margin-start) и `me` (margin-end) делает верстку более универсальной и упрощает адаптацию под разные языки. Для текста слева направо (LTR), такие как английский или русский, `ms` будет означать отступ слева. Для текста справа налево (RTL), например, арабского, `ms` будет означать отступ справа. Это позволяет сделать разметку более гибкой и готовой к различным языковым направлениям.

---
Для отступов внутри элементов (padding) в Bootstrap 5 используется аналогичная система классов, как и для внешних отступов (margin), но с префиксом `p` вместо `m`.

**Синтаксис классов для `padding`:**

- **`ps-{n}`** — отступ от начала (start). В LTR это будет слева, в RTL — справа.
- **`pe-{n}`** — отступ от конца (end). В LTR это будет справа, в RTL — слева.
- **`pt-{n}`** — отступ сверху (top).
- **`pb-{n}`** — отступ снизу (bottom).
- **`p-{n}`** — общий отступ со всех сторон.

**Значения `{n}` в классах:**

- `0` — нет отступа (`padding: 0`).
- `1` — отступ на 0.25rem.
- `2` — отступ на 0.5rem.
- `3` — отступ на 1rem.
- `4` — отступ на 1.5rem.
- `5` — отступ на 3rem.

**Примеры использования:**

1. **Отступ слева (или справа для RTL)**:

   ```html
   <div class="ps-3">
   Контент с padding от начала на 1rem
   </div>
   ```

2. **Отступ справа (или слева для RTL)**:

   ```html
   <div class="pe-2">
   Контент с padding от конца на 0.5rem
   </div>
   ```

3. **Отступ сверху**:

   ```html
   <div class="pt-4">
   Контент с padding сверху на 1.5rem
   </div>
   ```

4. **Отступ снизу**:

   ```html
   <div class="pb-5">
   Контент с padding снизу на 3rem
   </div>
   ```

5. **Общий отступ со всех сторон**:

   ```html
   <div class="p-3">
   Контент с padding по 1rem со всех сторон
   </div>
   ```



**Зачем это нужно?**

Как и с `margin`, использование `ps` и `pe` для отступов (padding) делает код гибким для различных языков. Например, при смене языка с LTR на RTL отступы автоматически перестраиваются без необходимости изменять разметку. Это удобно для создания интернационализированных проектов.

---
Для того чтобы сделать отступ снизу в Bootstrap 5, можно использовать класс `pb-{n}`, где `{n}` — это размер отступа в рамках системы Bootstrap. 

Значения `{n}`:

- `pb-0` — нет отступа.
- `pb-1` — отступ снизу на 0.25rem.
- `pb-2` — отступ снизу на 0.5rem.
- `pb-3` — отступ снизу на 1rem.
- `pb-4` — отступ снизу на 1.5rem.
- `pb-5` — отступ снизу на 3rem.

**Пример использования:**

```html
<div class="pb-3">
  Контент с отступом снизу на 1rem
</div>
```

В этом примере отступ снизу будет составлять 1rem.
