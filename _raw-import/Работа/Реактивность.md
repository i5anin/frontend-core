**Реактивность в [../../../Vue/Vue.js](#)** — это основная концепция, которая позволяет автоматически обновлять пользовательский интерфейс (UI) при изменении данных. [../../../Vue/Vue.js](#) использует систему наблюдения за данными, которая отслеживает изменения и обновляет [DOM](./DOM) (Document Object Model) только там, где это необходимо, минимизируя количество изменений и улучшая производительность.

**Как работает реактивность в [../../../Vue/Vue.js](#)?**

Когда объект данных становится реактивным, Vue "заворачивает" его в прокси (с помощью Proxy в Vue 3) или использует дескрипторы свойств (в Vue 2), чтобы отслеживать изменения в этих данных. Когда данные изменяются, Vue автоматически обновляет все связанные с ними компоненты, не требуя от разработчика вручную манипулировать [DOM](./DOM).

**Основные элементы реактивности:**

1. **[Объект data (vue)](../../../Изучение/Объект data (vue))** — это реактивные данные, которые находятся внутри компонента и могут быть использованы в шаблоне. Любые изменения этих данных автоматически обновляют UI.

2. **Вычисляемые свойства ([computed](./computed))** — это свойства, которые автоматически пересчитываются, когда их зависимости изменяются. Они кэшируются, то есть не пересчитываются, если зависимости не изменились.

3. **Следящие ([watch](./watch))** — это методы, которые выполняются при изменении определенных данных. Они полезны, когда необходимо выполнять действия при изменении реактивных данных (например, асинхронные вызовы).

**Пример реактивности:**

**Пример 1: Реактивные данные через [Объект data (vue)](../../../Изучение/Объект data (vue))**

```html
<template>
  <div>
    <p>{{ message }}</p>
    <button @click="changeMessage">Изменить сообщение</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: 'Привет, мир!'
    };
  },
  methods: {
    changeMessage() {
      this.message = 'Сообщение изменено!';
    }
  }
};
</script>
```

Здесь объект `message` является реактивным. Когда мы изменяем его значение с помощью метода `changeMessage`, Vue автоматически обновляет [DOM](./DOM) и отображает новое значение.

**Пример 2: Вычисляемые свойства ([computed](./computed))**

```html
<template>
  <div>
    <p>Длина сообщения: {{ messageLength }}</p>
    <input v-model="message" placeholder="Введите сообщение" />
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: ''
    };
  },
  computed: {
    messageLength() {
      return this.message.length;
    }
  }
};
</script>
```

Здесь `messageLength` — это вычисляемое свойство, которое зависит от `message`. Каждый раз, когда пользователь вводит новый текст, Vue автоматически пересчитывает длину строки, и [DOM](./DOM) обновляется.

**Пример 3: Следящие свойства ([watch](./watch))**

```html
<template>
  <div>
    <input v-model="name" placeholder="Введите имя" />
    <p>{{ greeting }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      name: '',
      greeting: ''
    };
  },
  watch: {
    name(newValue) {
      this.greeting = `Привет, ${newValue}`;
    }
  }
};
</script>
```

В этом примере мы используем следящее свойство `watch`, чтобы отслеживать изменения переменной `name`. Когда пользователь вводит новое имя, функция `watch` автоматически вызывается, обновляя приветствие.

**Реактивность в Vue 3 с [reactive](./reactive) и [ref](./ref)**

В Vue 3 добавлены новые API для работы с реактивными данными: [reactive](./reactive) и [ref](./ref).

**[reactive](./reactive) для объектов**

Метод [reactive](./reactive) делает объект полностью реактивным.

```html
<template>
  <div>
    <p>Имя: {{ state.name }}</p>
    <input v-model="state.name" placeholder="Введите имя" />
  </div>
</template>

<script>
import { reactive } from 'vue';

export default {
  setup() {
    const state = reactive({
      name: 'Анна'
    });

    return { state };
  }
};
</script>
```

Здесь объект [state](#) становится реактивным благодаря методу [reactive](./reactive). Любое изменение в `state.name` автоматически обновляет [DOM](./DOM).

**[ref](./ref) для примитивов**

Метод [ref](./ref) используется для создания реактивных данных, которые хранят примитивные значения, такие как числа, строки или булевы значения.

```html
<template>
  <div>
    <p>{{ count }}</p>
    <button @click="increment">Увеличить</button>
  </div>
</template>

<script>
import { ref } from 'vue';

export default {
  setup() {
    const count = ref(0);

    const increment = () => {
      count.value++;
    };

    return { count, increment };
  }
};
</script>
```

Здесь переменная `count` становится реактивной благодаря [ref](./ref), и её изменение приводит к обновлению шаблона.

**Преимущества реактивности в [../../../Vue/Vue.js](#)**

1. **Автоматическое обновление интерфейса:** При изменении данных Vue автоматически обновляет [DOM](./DOM), избавляя разработчика от необходимости вручную отслеживать изменения и обновлять интерфейс.
2. **Минимальные изменения в [DOM](./DOM):** Vue оптимизирует процесс обновления интерфейса, минимизируя количество изменений в [DOM](./DOM), что улучшает производительность.
3. **Простота и удобство:** Реактивные данные упрощают логику приложений, делая код более читаемым и поддерживаемым.

**Итог:**
- **Реактивность** — это ключевая концепция [../../../Vue/Vue.js](#), которая позволяет автоматически обновлять интерфейс при изменении данных.
- &lt;u&gt;В Vue 2 реактивность достигается через объект [Объект data (vue)](../../../Изучение/Объект data (vue)), вычисляемые свойства ([computed](./computed)) и следящие свойства ([watch](./watch)).&lt;/u>
- В Vue 3 добавлены новые API ([reactive](./reactive) и [ref](./ref)) для более гибкой работы с реактивными данными.
- Эта система упрощает создание динамических интерфейсов, избавляя от необходимости вручную обновлять [DOM](./DOM).
