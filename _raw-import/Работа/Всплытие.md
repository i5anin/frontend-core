**Всплытие событий** (или **event bubbling**) — это механизм обработки событий в [JavaScript](./JavaScript), при котором событие, возникающее на вложенном элементе, сначала обрабатывается этим элементом, а затем передается (всплывает) на вышестоящие элементы, вплоть до корневого элемента (`document`).

**Как это работает:**

Когда событие, например, клик, происходит на элементе, оно сначала запускается на самом элементе (целевом элементе), а затем "всплывает" по цепочке родительских элементов до самого верхнего уровня [DOM](./DOM) (обычно до `document`).

**Пример:**

```html
<div id="parent" style="padding: 20px; background-color: lightgray;">
  Родитель
  <button id="child" style="margin: 20px;">Кнопка</button>
</div>

<script>
  document.getElementById('parent').addEventListener('click', function() {
    console.log('Клик по родителю');
  });

  document.getElementById('child').addEventListener('click', function() {
    console.log('Клик по кнопке');
  });
</script>
```

**Ожидаемый результат:**
Если пользователь кликает по кнопке:
1. Сначала обработается событие на кнопке, и в консоли появится: `Клик по кнопке`.
2. Затем событие "всплывет" и обработается на родителе (`div`), и в консоли появится: `Клик по родителю`.

**Всплытие событий на практике:**
Всплытие полезно, когда нужно отлавливать события на уровне родителя, а не на каждом дочернем элементе. Например, можно отлавливать клики на большом контейнере, в котором находятся несколько кнопок, а не на каждой кнопке отдельно.

**Прекращение всплытия:**
Если вам нужно предотвратить всплытие события к его родителям, можно использовать метод **`event.stopPropagation()`**.

Пример:
```html
<div id="parent" style="padding: 20px; background-color: lightgray;">
  Родитель
  <button id="child" style="margin: 20px;">Кнопка</button>
</div>

<script>
  document.getElementById('parent').addEventListener('click', function() {
    console.log('Клик по родителю');
  });

  document.getElementById('child').addEventListener('click', function(event) {
    event.stopPropagation();  // Останавливаем всплытие события
    console.log('Клик по кнопке');
  });
</script>
```

В этом случае, при клике на кнопку, в консоли появится только сообщение: `Клик по кнопке`. Сообщение от родителя больше не будет выводиться, так как всплытие события было остановлено с помощью `stopPropagation()`.

**Погружение (capturing phase):**
Кроме всплытия, существует и другая фаза обработки событий — **погружение** (или **capturing phase**). В отличие от всплытия, при погружении событие сначала проходит через родительские элементы, начиная с корня (`document`), и доходит до целевого элемента.

Чтобы использовать фазу погружения, нужно передать в `addEventListener` третий параметр `true`.

Пример:
```javascript
document.getElementById('parent').addEventListener('click', function() {
  console.log('Клик по родителю (погружение)');
}, true);

document.getElementById('child').addEventListener('click', function() {
  console.log('Клик по кнопке');
}, true);
```

**Итог:**
- **Всплытие событий** — это процесс, при котором событие сначала обрабатывается на целевом элементе, а затем передается его родителям вплоть до корневого элемента.
- Чтобы остановить всплытие, можно использовать метод `stopPropagation()`.
- JavaScript также поддерживает фазу погружения, когда событие сначала обрабатывается родительскими элементами и только потом целевым элементом.
