**`ref`** в Vue 3 — это функция, которая позволяет создавать **реактивные** данные. С помощью `ref` можно отслеживать изменения значения переменной, и при каждом изменении интерфейс автоматически обновляется.

**Основные характеристики `ref`:**
1. **[Реактивность](./Реактивность)**:
   Данные, обёрнутые в `ref`, становятся реактивными. Это значит, что если значение изменится, все компоненты, которые используют это значение, автоматически обновятся.

2. **[object](./object) `.value`**:
   Чтобы работать с данными, обёрнутыми в `ref`, нужно использовать специальное свойство `.value`.

**Пример использования `ref`:**

```javascript
import { ref } from 'vue';

export default {
  setup() {
    const count = ref(0); // Создаем реактивную переменную

    function increment() {
      count.value++; // Меняем значение через .value
    }

    return { count, increment };
  }
};
```

**Как это работает в шаблоне:**

```vue
<template>
  <div>
    <p>Счётчик: {{ count }}</p>
    <button @click="increment">Увеличить</button>
  </div>
</template>

<script setup>
import { ref } from 'vue';

const count = ref(0);

function increment() {
  count.value++;
}
</script>
```

**Описание:**
- **`ref(0)`** создаёт реактивное значение, в данном случае — это переменная `count`, которая содержит число 0.
- Чтобы получить значение, используем `count.value`. При каждом изменении `count.value`, Vue автоматически перерендерит [DOM](./DOM).

**Когда использовать `ref`:**
- Когда нужно отслеживать изменение **примитивных** типов данных (например, чисел, строк, булевых значений).
- Для работы с **неконструкторными** переменными в реактивной среде Vue.

Таким образом, `ref` — это основной способ создания реактивных данных в Vue 3 для примитивных значений.
