В SQL оператор **`ILIKE`** используется для выполнения поиска без учёта регистра в строковых данных. Он работает аналогично оператору **`LIKE`**, но игнорирует регистр символов, что полезно при поиске строк, где неважно, используются ли прописные или строчные буквы.

**Особенности ILIKE**
- **`ILIKE`** поддерживается в основном в **PostgreSQL** (другие СУБД могут не поддерживать его).
- Работает как обычный **`LIKE`**, но выполняет нечувствительный к регистру поиск.

**Синтаксис**
```sql
SELECT column_name 
FROM table_name 
WHERE column_name ILIKE 'pattern';
```

- **`pattern`** может включать следующие символы:
  - **`%`** — заменяет любое количество символов (включая 0 символов).
  - **`_`** — заменяет один символ.

**Примеры использования `ILIKE`**

**Пример 1: Поиск строк, игнорируя регистр**
```sql
SELECT name 
FROM clients 
WHERE name ILIKE '%константа%';
```
- Найдёт все строки в столбце `name`, содержащие слово "константа" в любом регистре, например, "Константа", "константа", "КОНСТАНТА".

**Пример 2: Поиск с несколькими символами**
```sql
SELECT product_name 
FROM products 
WHERE product_name ILIKE 'продукт%';
```
- Найдёт все продукты, названия которых начинаются со слова "продукт" независимо от регистра, например, "Продукт1", "продуктX", "ПРОДУКТ123".

**Пример 3: Поиск с одним заменяющим символом**
```sql
SELECT username 
FROM users 
WHERE username ILIKE '_admin';
```
- Найдёт всех пользователей, чьи имена заканчиваются на "admin" и начинаются с любого одного символа, например, "Aadmin", "Xadmin", "1admin".

**Пример 4: Поиск в середине строки**
```sql
SELECT email 
FROM employees 
WHERE email ILIKE '%@example.com';
```
- Найдёт всех сотрудников, чьи email-адреса находятся на домене `example.com`, игнорируя регистр, например, `User@Example.com`, `admin@example.com`.

**Примечание**
- `ILIKE` часто используется, когда требуется нечувствительный к регистру поиск, и он позволяет писать запросы, которые будут работать независимо от регистра букв в базе данных.
