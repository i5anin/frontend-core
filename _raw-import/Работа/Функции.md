**Функции** в [JavaScript](./JavaScript) — это блоки кода, которые могут быть вызваны (или "выполнены") по требованию. Функции помогают организовать код, сделать его переиспользуемым и поддерживаемым.

**Создание функции**

В JavaScript функции могут быть объявлены разными способами:

**1. Функциональное объявление (Function Declaration)**
Это стандартный способ создания функции, который позволяет вызывать функцию до её определения в коде.

```javascript
function имяФункции(параметры) {
  // Тело функции
  return результат; // (необязательно)
}
```

Пример:
```javascript
function sayHello() {
  console.log('Привет, мир!');
}

sayHello();  // Вызов функции
```

**2. Функциональное выражение (Function Expression)**
Функция может быть присвоена переменной. Функции, объявленные таким образом, нельзя вызывать до их объявления.

```javascript
const имяФункции = function(параметры) {
  // Тело функции
};
```

Пример:
```javascript
const greet = function(name) {
  console.log('Привет, ' + name);
};

greet('Анна');  // Привет, Анна
```

**3. Стрелочные функции (Arrow Functions)**
Это краткая запись для функциональных выражений, которая появилась в ES6. У стрелочных функций упрощенный синтаксис, и они не имеют собственного контекста `this`.

```javascript
const имяФункции = (параметры) => {
  // Тело функции
};
```

Пример:
```javascript
const sum = (a, b) => {
  return a + b;
};

console.log(sum(5, 3));  // 8
```

Если тело функции состоит из одного выражения, можно опустить фигурные скобки и оператор `return`:
```javascript
const multiply = (a, b) => a * b;
console.log(multiply(5, 3));  // 15
```

**Параметры и аргументы функций**

Функции могут принимать **параметры**, которые передаются при вызове функции как **аргументы**.

Пример:
```javascript
function greet(name) {
  console.log('Привет, ' + name);
}

greet('Иван');  // Привет, Иван
```

**Возврат значения**

Функция может возвращать значение с помощью оператора `return`. Если `return` не используется, функция возвращает `undefined` по умолчанию.

Пример:
```javascript
function add(a, b) {
  return a + b;
}

let result = add(2, 3);
console.log(result);  // 5
```

**Значения параметров по умолчанию**

Функции могут иметь значения параметров по умолчанию. Если аргумент не передан, используется значение по умолчанию.

Пример:
```javascript
function greet(name = 'Гость') {
  console.log('Привет, ' + name);
}

greet();        // Привет, Гость
greet('Анна');  // Привет, Анна
```

**Функции как аргументы (коллбэки)**

Функции можно передавать в другие функции в качестве аргументов. Такие функции называются **коллбэками**.

Пример:
```javascript
function processUserInput(callback) {
  const name = prompt('Введите ваше имя:');
  callback(name);
}

function greet(name) {
  console.log('Привет, ' + name);
}

processUserInput(greet);
```

**Анонимные функции**

Функции, которые не имеют имени, называются **анонимными функциями**. Их часто используют как аргументы для других функций.

Пример:
```javascript
setTimeout(function() {
  console.log('Это анонимная функция, выполняется через 2 секунды');
}, 2000);
```

**Рекурсия**

Функция может вызывать саму себя. Этот процесс называется **рекурсией**. Рекурсия часто используется для решения задач, которые могут быть разделены на меньшие подзадачи.

Пример:
```javascript
function factorial(n) {
  if (n === 1) {
    return 1;
  }
  return n * factorial(n - 1);
}

console.log(factorial(5));  // 120
```

**[Замыкание](./Замыкание)**

**Замыкание** — это функция, которая "запоминает" своё окружение, даже если она была вызвана вне контекста, где была объявлена.

Пример:
```javascript
function outerFunction(outerVariable) {
  return function innerFunction(innerVariable) {
    console.log('Outer variable: ' + outerVariable);
    console.log('Inner variable: ' + innerVariable);
  };
}

const newFunction = outerFunction('внешнее');
newFunction('внутреннее');

// Вывод:
// Outer variable: внешнее
// Inner variable: внутреннее
```

**Итог:**
- **Функции** — это основной строительный блок в JavaScript, который позволяет организовывать код, делать его переиспользуемым и модульным.
- Существует несколько способов объявления функций: функциональные объявления, функциональные выражения и стрелочные функции.
- Функции могут принимать параметры, возвращать значения и быть переданы как аргументы в другие функции.
- JavaScript также поддерживает продвинутые концепции функций, такие как рекурсия, [Замыкание](./Замыкание) и функции высшего порядка.
