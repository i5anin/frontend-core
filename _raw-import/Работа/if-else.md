`if-else` — это базовая конструкция управления потоком в [JavaScript](./JavaScript), которая позволяет выполнять разные блоки кода в зависимости от условий. Вот как она выглядит:

```javascript
if (условие) {
  // Код выполняется, если условие истинно
} else {
  // Код выполняется, если условие ложно
}
```

**Пример использования**

```javascript
const age = 18;

if (age >= 18) {
  console.log("Вам разрешено голосовать.");
} else {
  console.log("Вы еще слишком молоды для голосования.");
}
```

**if-else if**

Для проверки нескольких условий можно использовать конструкцию `else if`:

```javascript
const score = 85;

if (score >= 90) {
  console.log("Отлично!");
} else if (score >= 75) {
  console.log("Хорошо!");
} else if (score >= 50) {
  console.log("Удовлетворительно");
} else {
  console.log("Плохо");
}
```

**Тернарный оператор**

Для коротких условий можно использовать тернарный оператор, который является аналогом `if-else`:

```javascript
const age = 20;
const message = age >= 18 ? "Совершеннолетний" : "Несовершеннолетний";
console.log(message);
```

**Рекомендуемый стиль (для чистого кода)**

1. Используйте четкие и понятные условия.
2. Избегайте вложенных `if` там, где это возможно.
3. Для коротких условий используйте тернарный оператор, но не усложняйте его.
4. Помните, что более сложные условия лучше выносить в отдельные функции для повышения читаемости.
