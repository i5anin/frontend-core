XML (eXtensible Markup Language) — это расширяемый язык разметки, используемый для структурирования, хранения и передачи данных. Он предназначен для того, чтобы быть как читаемым для человека, так и машиной. В отличие от [HTML](./HTML), [XML](./XML) не имеет заранее определённого набора тегов, а позволяет разработчикам создавать свои собственные теги для представления данных.

Основные характеристики XML:

- **Структура**: данные организованы в виде иерархии с корневым элементом и вложенными элементами.
- **Расширяемость**: можно создавать свои теги, что позволяет [XML](./XML) быть гибким в различных приложениях.
- **Читаемость для человека**: данные представлены в понятном виде с четкой структурой.
- **Обязательная правильность**: каждый открывающий тег должен иметь закрывающий, и структура документа должна быть строго соблюдена.

Пример XML-документа:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<bookstore>
  <book>
    <title>Программирование на Python</title>
    <author>Иван Иванов</author>
    <year>2023</year>
    <price>29.99</price>
  </book>
  <book>
    <title>Веб-разработка с использованием PHP</title>
    <author>Мария Петрова</author>
    <year>2022</year>
    <price>19.99</price>
  </book>
</bookstore>
```

В этом примере `bookstore` — корневой элемент, содержащий несколько элементов `book`, каждый из которых имеет дочерние элементы `title`, `author`, `year` и `price`.

[XML](./XML) часто используется для обмена данными между различными системами, например, в веб-сервисах и конфигурационных файлах.
