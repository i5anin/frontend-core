**Вложенные функции** (или **[Функции](./Функции) внутри функций**) в [JavaScript](./JavaScript) — это функции, которые определяются и объявляются внутри другой функции. Вложенные [Функции](./Функции) имеют доступ к [Переменные](./var, let, const) и [параметры](#) внешней функции, в которой они определены. Это позволяет организовывать код и управлять [Область видимости](./Область видимости) переменных.

**Пример вложенной функции:**

```javascript
function outerFunction() {
  let outerVariable = 'Я снаружи';

  function innerFunction() {
    let innerVariable = 'Я внутри';
    console.log(outerVariable);  // 'Я снаружи'
    console.log(innerVariable);  // 'Я внутри'
  }

  innerFunction();
}

outerFunction();
```

В этом примере функция **`innerFunction`** определена внутри функции **`outerFunction`**. Она имеет доступ к переменной `outerVariable`, которая объявлена в `outerFunction`. Однако, переменная `innerVariable`, объявленная внутри `innerFunction`, доступна только внутри неё.

**Основные моменты вложенных функций:**

1. **Область видимости**:
   Вложенные функции имеют доступ ко всем переменным и параметрам внешней функции, в которой они были объявлены. Однако внешняя функция не имеет доступа к переменным, объявленным внутри вложенной функции.

   Пример:
   ```javascript
   function outer() {
     let outerVar = 'Внешняя переменная';

     function inner() {
       console.log(outerVar);  // Доступ к переменной внешней функции
     }

     inner();
   }

   outer();
   ```

2. **[Замыкание](./Замыкание)**:
   Когда вложенная функция продолжает использовать переменные внешней функции даже после того, как внешняя функция завершила выполнение, это называется замыканием. Замыкания позволяют вложенным функциям "запомнить" контекст, в котором они были созданы.

   Пример [Замыкание](./Замыкание):
   ```javascript
   function outerFunction() {
     let counter = 0;

     return function innerFunction() {
       counter++;
       console.log(counter);
     };
   }

   const increment = outerFunction();
   increment();  // 1
   increment();  // 2
   increment();  // 3
   ```

   Здесь функция `innerFunction` возвращается из `outerFunction` и сохраняет доступ к переменной `counter`, даже после завершения выполнения `outerFunction`.

3. **Инкапсуляция**:
   Вложенные функции помогают инкапсулировать логику, ограничивая область видимости внутренних функций, чтобы они не были доступны за пределами внешней функции.

   Пример:
   ```javascript
   function createCounter() {
     let count = 0;

     function increment() {
       count++;
       return count;
     }

     return increment;
   }

   const counter = createCounter();
   console.log(counter());  // 1
   console.log(counter());  // 2
   ```

4. **Модулирование и организация кода**:
   Вложенные функции помогают логически разделять части кода, улучшая его читаемость и повторное использование.

**Заключение:**

**Вложенные функции** позволяют создавать функции внутри других функций, давая доступ к переменным внешней функции и помогая организовывать код. Они также связаны с концепцией замыканий, которая является важной частью работы с функциями в [JavaScript](./JavaScript).
