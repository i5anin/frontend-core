**`watch`** в [../Vue/Vue.js](#) — это функция, которая позволяет отслеживать изменения реактивных данных или вычисляемых свойств и выполнять определенные действия в ответ на эти изменения. Это полезно, когда вам нужно реагировать на изменение значения, например, делать запросы на сервер, обновлять данные или выполнять другую логику.

**Основное использование `watch`**

Функция `watch` позволяет отслеживать:
1. **Реактивные переменные**, созданные в [Объект data (vue)](./Объект data (vue)) или с помощью [reactive](./reactive) и [ref](./ref) (в Vue 3).
2. **Вычисляемые свойства** ([computed](./computed)).
3. **Массивы или объекты**, для отслеживания изменений в их значениях.

**Пример использования `watch` в Vue 2:**

```html
<template>
  <div>
    <input v-model="name" placeholder="Введите имя" />
    <p>Ваше имя: {{ name }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      name: ''
    };
  },
  watch: {
    name(newValue, oldValue) {
      console.log(`Имя изменилось с "${oldValue}" на "${newValue}"`);
    }
  }
};
</script>
```

В этом примере Vue будет отслеживать изменение переменной `name`. Когда значение изменяется, вызывается функция `watch`, которая принимает два аргумента: новое значение (`newValue`) и старое значение (`oldValue`).

**Пример использования `watch` в Vue 3 с Composition API:**

В Vue 3 с Composition API `watch` можно использовать внутри функции `setup`.

```html
<template>
  <div>
    <input v-model="count" type="number" />
    <p>Счётчик: {{ count }}</p>
  </div>
</template>

<script>
import { ref, watch } from 'vue';

export default {
  setup() {
    const count = ref(0);

    watch(count, (newValue, oldValue) => {
      console.log(`Счётчик изменился с ${oldValue} на ${newValue}`);
    });

    return {
      count
    };
  }
};
</script>
```

Здесь используется `watch` для отслеживания реактивной переменной `count`, созданной с помощью `ref`. Функция `watch` реагирует на любое изменение значения переменной.

**Параметры функции `watch`:**
- Первый параметр — это переменная, которую нужно отслеживать. Это может быть реактивное свойство, объект, массив или вычисляемое свойство.
- Второй параметр — это функция-обработчик, которая вызывается каждый раз при изменении отслеживаемого значения. Она принимает два аргумента: новое значение и старое значение.
  
**Опции для `watch`:**

**1. **deep** (глубокое отслеживание):**
Когда вы хотите отслеживать изменения внутри вложенных объектов или массивов, вы можете включить глубокое отслеживание с помощью опции `deep: true`.

Пример:
```html
<template>
  <div>
    <p>{{ person.name }}</p>
    <input v-model="person.name" placeholder="Введите имя" />
  </div>
</template>

<script>
export default {
  data() {
    return {
      person: {
        name: 'Иван',
        age: 30
      }
    };
  },
  watch: {
    person: {
      handler(newValue) {
        console.log('Изменен объект person:', newValue);
      },
      deep: true
    }
  }
};
</script>
```

Здесь `watch` отслеживает изменения не только самого объекта `person`, но и его внутренних свойств, таких как `name` или `age`.

**2. **immediate** (немедленный вызов):**
Опция `immediate` используется, если нужно немедленно вызвать `watch` при инициализации компонента, даже если значение не изменилось.

Пример:
```html
<script>
export default {
  data() {
    return {
      name: ''
    };
  },
  watch: {
    name: {
      handler(newValue) {
        console.log('Имя изменилось:', newValue);
      },
      immediate: true
    }
  }
};
</script>
```

В этом примере функция `watch` будет вызвана сразу при загрузке компонента, даже если `name` не изменялось.

**Пример с отслеживанием нескольких переменных:**

Можно использовать `watch` для отслеживания сразу нескольких переменных, например, через массив или объект.

```html
<script>
import { ref, watch } from 'vue';

export default {
  setup() {
    const count = ref(0);
    const name = ref('Иван');

    watch([count, name], ([newCount, newName], [oldCount, oldName]) => {
      console.log(`Счётчик: с ${oldCount} на ${newCount}`);
      console.log(`Имя: с ${oldName} на ${newName}`);
    });

    return {
      count,
      name
    };
  }
};
</script>
```

**Применение `watch`:**
1. **Запросы на сервер:** Часто `watch` используется для выполнения API-запросов при изменении состояния данных.
2. **Валидация данных:** Вы можете валидировать данные при вводе пользователем, отслеживая изменение этих данных.
3. **Обновление или сохранение состояния:** `watch` полезен, когда необходимо сохранять или обновлять какие-то данные, если изменяется определённая переменная.

**Отличия [watch](./watch) от [computed](./computed):**
- **[computed](./computed)** — используется для вычисления значения на основе зависимостей. Эти вычисления кэшируются и выполняются только при изменении зависимых данных.
- **[watch](./watch)** — используется для выполнения каких-либо действий (например, побочных эффектов) при изменении данных, но не для вычисления значений.

**Итог:**
- **[watch](./watch)** в [../Vue/Vue.js](#) — это инструмент для отслеживания изменений реактивных данных и выполнения определённых действий в ответ на эти изменения.
- Он особенно полезен для сложных сценариев, когда нужно выполнять действия при изменении данных (например, [асинхронные запросы](#), валидация или глубокие изменения [object](./object)ов).
