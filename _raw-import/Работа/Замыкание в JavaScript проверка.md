[Замыкание](./Замыкание) в JavaScript2

На изображении представлен пример использования замыканий в функции `sum`.

---

**Код из изображения:**

```javascript
const a = 5;

function sum() {
    return (b) => a + b;
}

const firstValue = sum();

console.log(1, firstValue(10)); // 15
console.log(2, firstValue(15)); // 20
console.log(3, firstValue(20)); // 25
```

---

**Как это работает:**

1. **Глобальная переменная `a`.**
    
    - В коде объявлена переменная `a = 5`, которая находится в глобальной области видимости.
2. **Функция `sum`.**
    
    - Функция возвращает вложенную стрелочную функцию `(b) => a + b`, которая использует переменную `a` из внешнего лексического окружения (глобального).
3. **Замыкание.**
    
    - Когда вызывается `sum()`, создается новая функция `(b) => a + b`, которая "замыкает" переменную `a`.
4. **Вызовы `firstValue`.**
    
    - Переменная `firstValue` хранит результат вызова `sum()`, то есть ссылку на замыкание.
    - Каждый вызов `firstValue(b)` использует значение `a = 5` из замыкания.

---

**Разбор вывода:**

1. `firstValue(10)`:
    
    - `a = 5`, `b = 10`.
    - Результат: `5 + 10 = 15`.
2. `firstValue(15)`:
    
    - `a = 5`, `b = 15`.
    - Результат: `5 + 15 = 20`.
3. `firstValue(20)`:
    
    - `a = 5`, `b = 20`.
    - Результат: `5 + 20 = 25`.

**Итоговый вывод:**

```
1 15
2 20
3 25
```

---

**Замыкание в данном примере:**

Функция `sum` создает замыкание, которое запоминает доступ к глобальной переменной `a`. Это демонстрирует, как переменные из внешнего окружения могут быть "замкнуты" внутри возвращенной функции.

Если значение переменной `a` изменить, оно отразится в последующих вызовах `firstValue`:

```javascript
a = 10;
console.log(firstValue(10)); // 20 (10 + 10)
```
