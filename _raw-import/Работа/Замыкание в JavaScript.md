**[Замыкание](./Замыкание) (closure)** — это функция, которая "захватывает" переменные из своего внешнего лексического окружения. Это позволяет функции запоминать и использовать значения переменных, которые были доступны в момент её создания, даже если эта функция вызывается из другой области видимости.

---

**Как это работает:**

Когда функция создаётся, она запоминает своё лексическое окружение, то есть те переменные, которые были доступны в области, где она была объявлена. Если эта функция возвращается и используется за пределами своей области, то она всё равно имеет доступ к переменным из того окружения, в котором была создана.

---

**Пример замыкания:**

```javascript
function createCounter() {
    let count = 0; // Переменная из внешнего окружения

    return function () {
        count++; // Доступ к переменной из внешнего окружения
        return count;
    };
}

const counter = createCounter();

console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

**Что здесь происходит:**

1. Функция `createCounter` создаёт локальную переменную `count` и возвращает вложенную функцию.
2. Эта вложенная функция запоминает своё лексическое окружение, включая переменную `count`.
3. Даже после завершения выполнения `createCounter`, переменная `count` сохраняется, так как на неё ссылается возвращённая функция.

---

**Пример с несколькими замыканиями:**

```javascript
function createAdder(x) {
    return function (y) {
        return x + y; // x берётся из внешнего окружения
    };
}

const add5 = createAdder(5); // x = 5
const add10 = createAdder(10); // x = 10

console.log(add5(3)); // 8
console.log(add10(3)); // 13
```

**Замыкания и циклы**

Частая ошибка при использовании замыканий в циклах связана с переменными `var`:

```javascript
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 1000);
}
// Вывод: 3, 3, 3
```

Здесь `i` находится в глобальной области видимости и одно значение `i` используется во всех вызовах. Чтобы это исправить, можно использовать `let`, так как оно создаёт новое блочное окружение для каждой итерации:

```javascript
for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 1000);
}
// Вывод: 0, 1, 2
```

---

**Важные моменты:**

1. **Закрытые переменные.** Замыкание сохраняет доступ к переменным, даже если внешняя функция завершила выполнение.
2. **Память.** Замыкания могут удерживать ссылки на переменные, что приводит к удержанию памяти. Поэтому важно учитывать, когда замыкания больше не нужны.
3. **Области видимости.** Замыкания делают возможным доступ к переменным из внешних областей.

---

**Практическое использование:**

1. **Инкапсуляция данных.** Замыкания позволяют создавать приватные переменные:
    
    ```javascript
    function Counter() {
        let count = 0;
    
        return {
            increment() {
                count++;
                return count;
            },
            decrement() {
                count--;
                return count;
            },
        };
    }
    
    const counter = Counter();
    console.log(counter.increment()); // 1
    console.log(counter.decrement()); // 0
    ```
    
2. **Функции обратного вызова (callbacks).** Замыкания часто используются в обработчиках событий, таймерах и промисах.
    

---

**Замыкания** — это мощный инструмент в JavaScript, который делает возможным управление данными и областью видимости, позволяя писать чистый и эффективный код.
