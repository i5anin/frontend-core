Да, для упаковки **Node.js** приложений в исполняемые файлы `.exe` есть несколько библиотек и инструментов, помимо `pkg`. Вот некоторые из них:

**1. **nexe****

**nexe** — это инструмент для упаковки Node.js приложений в один исполняемый файл. Он позволяет собирать проекты в двоичные файлы для разных операционных систем, включая Windows.

**Установка:**

1. Установи **nexe**:
    
    ```bash
    npm install -g nexe
    ```
    
2. Используй команду для создания исполняемого файла из JavaScript кода:
    
    ```bash
    nexe app.js --output app.exe
    ```
    

**Преимущества:**

- Поддерживает много платформ (Windows, Linux, macOS).
    
- Легко настраивается.
    
- Возможность встроить дополнительные файлы в сборку.
    

**2. **electron****

Если тебе нужно создать приложение с графическим интерфейсом, ты можешь использовать **Electron**. Он позволяет создавать кросс-платформенные настольные приложения с использованием HTML, CSS и JavaScript, и упаковывать их в исполняемые файлы, включая `.exe` для Windows.

**Установка:**

1. Установи **Electron**:
    
    ```bash
    npm install electron --save-dev
    ```
    
2. Создай файл **main.js** с кодом для запуска приложения.
    
3. Упакуй приложение с помощью **electron-builder** или **electron-packager**:
    
    ```bash
    npm install electron-builder --save-dev
    ```
    
4. Затем можешь собрать исполняемый файл:
    
    ```bash
    electron-builder --win --x64
    ```
    

**Преимущества:**

- Идеально подходит для создания настольных приложений с UI.
    
- Работает как с фронтенд-кодом (HTML, CSS, JS), так и с бэкендом (Node.js).
    

**3. **EncloseJS****

**EncloseJS** — это еще один инструмент для упаковки Node.js приложений в исполняемые файлы. Он компилирует JavaScript код и собирает его в один исполняемый файл. Однако этот инструмент не поддерживает все версии Node.js и может быть сложнее в настройке.

**Установка:**

1. Установи **EncloseJS**:
    
    ```bash
    npm install -g enclose
    ```
    
2. Скомпилируй приложение:
    
    ```bash
    enclose app.js
    ```
    

**Преимущества:**

- Подходит для более сложных проектов.
    
- Компилирует код в более оптимизированный вид.
    

**4. **pkg (повторно)****

Я упоминал этот инструмент ранее, но стоит отметить, что **pkg** является одним из самых популярных решений для упаковки Node.js приложений в `.exe`. Он не требует дополнительных зависимостей и позволяет собрать приложение с поддержкой большинства функций Node.js.

**Установка и использование:**

1. Установи **pkg**:
    
    ```bash
    npm install -g pkg
    ```
    
2. Скомпилируй проект в `.exe`:
    
    ```bash
    pkg app.js --target win
    ```
    

**Заключение:**

Если тебе нужно просто упаковать Node.js приложение без графического интерфейса, **pkg** или **nexe** — отличные варианты. Если приложение должно иметь графический интерфейс, то лучше выбрать **Electron**.

- **pkg** и **nexe** — проще в настройке, подходят для командных приложений.
    
- **Electron** — если тебе нужно приложение с UI.
    
- **EncloseJS** — для более сложных проектов, но требует дополнительной настройки.
    

Каждый из этих инструментов имеет свои преимущества в зависимости от типа проекта и потребностей.
