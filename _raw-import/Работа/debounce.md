Вот пример функции `debounce`, написанной с использованием библиотеки [../JavaScript/Библиотеки/Lodash](#).

[../JavaScript/Библиотеки/Lodash](#) — это популярная [JavaScript](./JavaScript) библиотека, которая предоставляет удобные утилиты для работы с массивами, объектами, строками и другими типами данных.

Ниже приведен пример использования `_.debounce` из библиотеки [../JavaScript/Библиотеки/Lodash](#):

```javascript
// Подключаем lodash
const _ = require('lodash');

// Функция, которую мы хотим ограничить вызовами
function handleInput() {
  console.log('Запрос отправлен к [API](./API)');
}

// Используем debounce, чтобы ограничить вызовы функции handleInput
// Функция будет вызвана через 300 миллисекунд после последнего вызова
const debouncedHandleInput = _.debounce(handleInput, 300);

// Предположим, что пользователь вводит данные в текстовое поле, и мы хотим обработать каждый ввод
document.getElementById('inputField').addEventListener('input', debouncedHandleInput);
```

В этом примере `debouncedHandleInput` будет вызвана через 300 миллисекунд после того, как пользователь закончит вводить данные в поле. Если в течение этих 300 миллисекунд будет сделан еще один ввод, таймер сбросится, и функция будет вызвана снова спустя 300 миллисекунд после последнего ввода. 

[../JavaScript/Библиотеки/Lodash](#) — это удобная библиотека для работы с такими задачами, и её функция [debounce](./debounce) помогает улучшить производительность и пользовательский опыт, особенно при интеграции с [API](./API) и другими частыми вызовами.
