**`push()`** — это метод массивов в [JavaScript](./JavaScript), который используется для добавления одного или нескольких элементов в конец массива. Возвращает новую длину массива после добавления элементов.

**Синтаксис:**

```javascript
array.push(element1, element2, ..., elementN)
```

- **`element1, element2, ..., elementN`** — элементы, которые нужно добавить в массив.
- Метод изменяет исходный массив и возвращает его новую длину.

**Пример использования:**

```javascript
let fruits = ['яблоко', 'банан'];
let newLength = fruits.push('апельсин');

console.log(fruits);       // ['яблоко', 'банан', 'апельсин']
console.log(newLength);    // 3
```

Здесь в массив `fruits` добавлен новый элемент `'апельсин'`, и метод `push()` вернул новую длину массива (3).

**Пример с добавлением нескольких элементов:**

```javascript
let numbers = [1, 2, 3];
numbers.push(4, 5, 6);

console.log(numbers);  // [1, 2, 3, 4, 5, 6]
```

В этом примере добавлено сразу три элемента (`4, 5, 6`) в конец массива.

**Основные моменты:**
- Метод `push()` изменяет исходный массив, добавляя элементы в его конец.
- Метод возвращает новую длину массива.
