## **1️⃣ Общие рекомендации**

- **Используйте английский язык**
- **Не сокращайте слова без необходимости** (`userName`, а не `usrNm`)
- **Названия должны отражать суть переменной**

---

## **2️⃣ Названия для переменных**

****✅ Данные (сущности)****

|Что хранит?|Пример имени|
|---|---|
|Имя пользователя|`userName`|
|Список пользователей|`usersList`|
|Информация о заказе|`orderInfo`|
|Дата создания|`createdAt`|
|Цена товара|`productPrice`|
|Текущий статус|`currentStatus`|

---

## **3️⃣ Названия для булевых переменных (флаги)**

📌 **Начинаются с:** `is`, `has`, `should`, `can`, `must`

|Что проверяет?|Пример имени|
|---|---|
|Данные загружаются?|`isLoading`|
|Ошибка произошла?|`hasError`|
|Доступ разрешен?|`canAccess`|
|Показывать кнопку?|`shouldShowButton`|
|Пользователь админ?|`isAdmin`|

---

## **4️⃣ Названия для функций**

📌 **Глагол + существительное**

|Действие|Пример имени|
|---|---|
|Получить данные|`fetchUsers()`|
|Загрузить заказы|`loadOrders()`|
|Обновить профиль|`updateProfile()`|
|Удалить элемент|`deleteItem()`|
|Проверить доступ|`checkAccess()`|
|Отправить сообщение|`sendMessage()`|
|Обработать клик|`handleClick()`|

---

## **5️⃣ Названия для массивов и списков**

📌 **Во множественном числе**

|Что хранит?|Пример имени|
|---|---|
|Список пользователей|`usersList`|
|Массив заказов|`orders`|
|Таблица данных|`tableData`|

---

## **6️⃣ Названия для объектов**

📌 **В единственном числе**

|Что хранит?|Пример имени|
|---|---|
|Данные о пользователе|`userData`|
|Информация о товаре|`productInfo`|
|Настройки приложения|`appConfig`|

---

## **7️⃣ Названия для констант**

📌 **SCREAMING_SNAKE_CASE**

|Что хранит?|Пример имени|
|---|---|
|Максимальное количество попыток|`MAX_RETRIES`|
|URL API|`API_BASE_URL`|
|Таймаут запроса|`REQUEST_TIMEOUT`|

---

## **8️⃣ Vue.js: специальные случаи**

****Пропсы (Props)****

📌 **Используем существительные (camelCase)**

```js
props: { userName: String, productId: Number }
```

📌 **В шаблоне (kebab-case)**

```html
<UserCard user-name="John Doe" />
```

****События (`emit`)****

📌 **Глагол в прошедшем времени**

```js
emit('userUpdated')
emit('orderPlaced')
```

****Pinia Store****

📌 **Название стора**

```js
const useUserStore = defineStore('user', { ... })
```

📌 **Геттеры (`computed`)**

```js
const fullName = computed(() => user.firstName + ' ' + user.lastName)
```

📌 **Методы (`actions`)**

```js
const fetchUsers = async () => { ... }
```

---

## **📌 Итог**

- **Данные →** существительные (`userName`, `orderInfo`)
- **Булевые флаги →** `is`, `has`, `should`, `can` (`isLoading`, `hasError`)
- **Функции →** `глагол + существительное` (`fetchUsers`, `updateProfile`)
- **Массивы →** во множественном числе (`usersList`, `orders`)
- **Объекты →** в единственном числе (`userData`, `productInfo`)
- **Константы →** `SCREAMING_SNAKE_CASE` (`MAX_RETRIES`, `API_BASE_URL`)
