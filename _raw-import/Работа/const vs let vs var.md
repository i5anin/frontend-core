В JavaScript ключевое отличие между **`const`** и **`let`** при объявлении **объекта** заключается **не в самом объекте**, а **в возможности переназначить переменную**, ссылающуюся на этот объект.

---

**🔹 1. `const`: объект-константа**

```js
const user = { name: 'Сергей' }
```

- ✅ **Можно менять внутренние свойства объекта**:
    
    ```js
    user.name = 'Андрей'  // работает
    ```
    
- ❌ **Нельзя переназначить саму переменную**:
    
    ```js
    user = { name: 'Игорь' }  // TypeError
    ```
    

---

**🔸 2. `let`: объект, объявленный через `let`**

```js
let user = { name: 'Сергей' }
```

- ✅ **Можно менять внутренние свойства объекта**
    
- ✅ **Можно переназначить сам объект**:
    
    ```js
    user = { name: 'Андрей' }  // работает
    ```
    

---

**💡 Итого:**

|Критерий|`const`|`let`|
|---|---|---|
|Можно изменять свойства|✅|✅|
|Можно переназначить переменную|❌ (ошибка)|✅|

---

**🧠 Заключение:**

- Используй `const`, если переменная **не должна быть переназначена**.
    
- Используй `let`, если объект **может быть полностью заменён** на другой.
