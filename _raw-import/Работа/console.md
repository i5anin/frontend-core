В [JavaScript](./JavaScript) `console.log` — это самый распространённый метод для вывода информации в консоль. Однако, существует несколько других методов в объекте `console`, которые позволяют выводить данные по-разному или для разных целей. Вот основные из них:

**1. **`console.log()`****
   - Используется для вывода обычной информации.
   - Выводит любые данные в консоль: текст, числа, объекты, массивы и так далее.
   - Пример:
     ```javascript
     console.log('Привет, мир!'); // Привет, мир!
     console.log(123);            // 123
     console.log({ name: 'Анна', age: 25 }); // { name: 'Анна', age: 25 }
     ```

**2. **`console.error()`****
   - Используется для вывода ошибок.
   - Сообщения ошибок могут выделяться красным цветом в консоли браузера.
   - Пример:
     ```javascript
     console.error('Что-то пошло не так!');
     ```

**3. **`console.warn()`****
   - Используется для вывода предупреждений.
   - Сообщения предупреждений могут выделяться жёлтым цветом в консоли браузера.
   - Пример:
     ```javascript
     console.warn('Это предупреждение!');
     ```

**4. **`console.info()`****
   - Используется для вывода информационных сообщений.
   - В большинстве браузеров работает так же, как `console.log`, но может быть предназначен для другой категории сообщений.
   - Пример:
     ```javascript
     console.info('Это информационное сообщение.');
     ```

**5. **`console.debug()`****
   - Используется для вывода отладочной информации.
   - Часто по умолчанию скрывается в консоли браузера, если не включён уровень "Debug".
   - Пример:
     ```javascript
     console.debug('Отладочная информация.');
     ```

**6. **`console.table()`****
   - Выводит данные в табличном формате.
   - Очень полезно для вывода массивов объектов или таблиц данных, так как визуально удобно просматривать структуру.
   - Пример:
     ```javascript
     let users = [
       { name: 'Анна', age: 25 },
       { name: 'Олег', age: 30 }
     ];
     console.table(users);
     ```

**7. **`console.time()` и `console.timeEnd()`****
   - Используются для измерения времени выполнения кода.
   - Начинает таймер с помощью `console.time('метка')` и завершает его с помощью `console.timeEnd('метка')`, выводя время, прошедшее между вызовами.
   - Пример:
     ```javascript
     console.time('Задача');
     // Код, который нужно замерить
     for (let i = 0; i < 100000; i++) {}
     console.timeEnd('Задача'); // Выведет время выполнения в миллисекундах
     ```

**8. **`console.group()` и `console.groupEnd()`****
   - Используются для создания групп сообщений в консоли.
   - Позволяет структурировать вывод в консоли, создавая "деревья" логов.
   - Пример:
     ```javascript
     console.group('Пользователи');
     console.log('Анна');
     console.log('Олег');
     console.groupEnd();
     ```

**9. **`console.assert()`****
   - Выводит сообщение в консоль, если выражение, переданное первым аргументом, является ложным.
   - Пример:
     ```javascript
     let x = 5;
     console.assert(x > 10, 'Ошибка: x не больше 10'); // Выведет сообщение, так как условие ложно
     ```

**10. **`console.clear()`****
   - Очищает консоль.
   - Полезно, если нужно убрать весь предыдущий вывод и начать с чистой консоли.
   - Пример:
     ```javascript
     console.clear();
     ```

**11. **`console.trace()`****
   - Выводит стек вызовов (trace) до этой точки в коде, показывая путь, по которому код был выполнен.
   - Полезно для отладки, чтобы понять, как выполнение программы дошло до этого места.
   - Пример:
     ```javascript
     function a() {
       b();
     }
     function b() {
       console.trace('Trace вызова');
     }
     a(); // Выведет путь вызова: a -> b -> trace
     ```

**Использование в зависимости от задачи:**
- **`console.log()`** — для обычного вывода.
- **`console.error()`** — для отображения ошибок.
- **`console.warn()`** — для предупреждений.
- **`console.info()`** — для информационных сообщений.
- **`console.debug()`** — для отладочных сообщений.
- **`console.table()`** — для форматированного вывода таблиц.
- **`console.time()` / `console.timeEnd()`** — для замеров времени.
- **`console.group()` / `console.groupEnd()`** — для организации логов в группы.
- **`console.assert()`** — для проверки утверждений.
- **`console.trace()`** — для отслеживания стека вызовов.

Каждый метод используется в зависимости от того, какой тип информации или отладки тебе нужен.
