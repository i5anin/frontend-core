В [JavaScript](./JavaScript) существует несколько типов данных, которые делятся на **примитивные** и **ссылочные** типы. Эти типы данных используются для хранения различной информации в переменных.

**Примитивные типы данных**

Примитивные типы данных хранятся непосредственно в переменных, и их значение передается по копии. Примитивные типы данных неизменяемы (immutable), то есть их значение не может быть изменено после создания.

# 1. **`string`** (строка)
   - Используется для хранения текстовой информации.
   - Строки заключаются в одинарные, двойные или обратные кавычки.
   - Примеры:
     ```javascript
     let str1 = "Привет";
     let str2 = 'Мир';
     let str3 = `Шаблонная строка с переменной ${str1}`;
     ```

# 2. **`number`** (число)
   - Используется для хранения как целых чисел, так и чисел с плавающей точкой (десятичных дробей).
   - JavaScript не различает целые числа и числа с плавающей запятой — они все относятся к типу `number`.
   - Специальные значения: `Infinity`, `-Infinity`, `NaN`.
   - Примеры:
     ```javascript
     let num1 = 10;
     let num2 = 3.14;
     let num3 = Infinity;
     let num4 = NaN;  // "Not a Number", появляется при некорректных математических операциях
     ```

# 3. **`boolean`** (булево значение)
   - Имеет два возможных значения: `true` (истина) или `false` (ложь).
   - Используется для логических операций и условий.
   - Пример:
     ```javascript
     let isActive = true;
     let isComplete = false;
     ```

# 4. **`null`**
   - Специальное значение, которое обозначает "ничего" или "пустое значение".
   - Является намеренным указанием на то, что переменная не содержит никакого значения.
   - Пример:
     ```javascript
     let user = null;  
     // переменная user не содержит никакого значения
     ```

# 5. **`undefined`**
   - Указывает, что переменной не присвоено значение.
   - Пример:
     ```javascript
     let x;  // переменной не присвоено значение
     console.log(x);  // undefined
     ```

# 6. **`symbol`** (символ)
   - Тип данных, представляющий уникальные идентификаторы.
   - Символы всегда уникальны, даже если имеют одинаковые описания.
   - Пример:
     ```javascript
     let sym1 = Symbol('id');
     let sym2 = Symbol('id');
     console.log(sym1 === sym2);  // false, символы всегда уникальны
     ```

# 7.  **`bigint`** (большие числа)
   - Используется для работы с числами, которые выходят за пределы безопасных значений типа `number` (например, больше, чем `2^53 - 1`).
   - Пример:
     ```javascript
     let bigNum = 1234567890123456789012345678901234567890n;
     ```


**Ссылочные типы данных ([object](./object))**

В отличие от примитивов, **ссылочные типы данных** (или объекты) хранятся по ссылке. Это означает, что при присваивании переменной объекта передается не его копия, а ссылка на объект.

1. **[object](./object) (object)**
   - Основной тип для работы с коллекциями данных и более сложными структурами.
   - Объекты могут содержать множество пар "ключ-значение".
   - Пример:
     ```javascript
     let user = {
       name: 'Анна',
       age: 25
     };
     console.log(user.name);  // 'Анна'
     ```

2. **[Массив](./Массив) (`array`)**
   - Массивы — это разновидность объектов, которые хранят упорядоченные коллекции значений.
   - Индексация начинается с нуля.
   - Пример:
     ```javascript
     let fruits = ['яблоко', 'банан', 'апельсин'];
     console.log(fruits[1]);  // 'банан'
     ```

3. **[Функции](./Функции) (`function`)**
   - Функции в JavaScript также являются объектами.
   - Функция — это блок кода, который можно вызвать по имени.
   - Пример:
     ```javascript
     function greet(name) {
       console.log(`Привет, ${name}!`);
     }
     greet('Анна');  // 'Привет, Анна!'
     ```

4. **Дата (`Date`)**
   - Объект для работы с датами и временем.
   - Пример:
     ```javascript
     let today = new Date();
     console.log(today);  // текущая дата и время
     ```

5. **[Регулярные выражения](./Регулярные выражения) (`RegExp`)**
   - Используются для работы с шаблонами поиска и замены текста.
   - Пример:
     ```javascript
     let pattern = /привет/i;
     console.log(pattern.test('Привет, мир!'));  // true
     ```

6. **[../../../JavaScript/Методы/map](#) и [Set](./Set)**
   - **[../../../JavaScript/Методы/map](#)** — коллекция пар ключ-значение, где ключи могут быть любого типа.
   - **[Set](./Set)** — коллекция уникальных значений.
   - Пример с `Map`:
     ```javascript
     let map = new Map();
     map.set('ключ', 'значение');
     console.log(map.get('ключ'));  // 'значение'
     ```

**Оператор typeof**

Оператор `typeof` используется для определения типа данных переменной.

Примеры:

```javascript
console.log(typeof 'Привет');  // string
console.log(typeof 42);  // number
console.log(typeof true);  // boolean
console.log(typeof undefined);  // undefined
console.log(typeof null);  // object (это известный баг языка)
console.log(typeof { name: 'Анна' });  // object
console.log(typeof function() {});  // function
```

**Заключение**

В JavaScript существует два основных типа данных:
- **Примитивные типы**: 
	1. `string`, 
	2. `number`, 
	2. `boolean`, 
	2. `null`, 
	2. `undefined`, 
	2. `symbol`, 
	2. `bigint`.
- **Ссылочные типы (объекты)**: `object`, включая массивы, функции, карты и множество других встроенных объектов.

Каждый тип данных имеет свои особенности и используется в различных ситуациях при разработке на JavaScript.

# *  **`NaN`** (Not-a-Number)
это специальное значение в JavaScript, которое обозначает "не число". Оно возникает, когда результат операции не может быть представлен как допустимое число.

```js
let result = 0 / 0;
console.log(result);  // NaN
```

Хотя **`NaN`** связан с типом данных **`number`**, он сам не является отдельным типом данных — это просто специальное значение, которое является частью типа **`number`**.
