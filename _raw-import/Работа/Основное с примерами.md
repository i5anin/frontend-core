**1. **SELECT****

Используется для извлечения данных из базы данных.

```sql
-- Извлечение всех данных из таблицы "employees" 
SELECT * FROM employees;  -- Извлечение только имени и должности сотрудников 
SELECT name, position FROM employees;  -- Извлечение данных с фильтрацией 
SELECT * FROM employees WHERE department = 'Sales';
```

**2. **INSERT INTO****

Добавляет новые записи в таблицу.

```sql
-- Добавление нового сотрудника в таблицу "employees" 
INSERT INTO employees (name, position, department, salary)  
VALUES ('John Doe', 'Developer', 'IT', 60000);`
```

**3. **UPDATE****

Изменяет существующие записи в таблице.


```sql
-- Обновление зарплаты сотрудника с ID = 1 
UPDATE employees 
SET salary = 65000 
WHERE id = 1; 

-- Обновление должности всех сотрудников в департаменте 'Sales' 
UPDATE employees 
SET position = 'Senior Sales Representative' 
WHERE department = 'Sales';
```


**4. **DELETE****

Удаляет записи из таблицы.

```sql
-- Удаление сотрудника с ID = 1 
DELETE FROM employees  
WHERE id = 1;  

-- Удаление всех сотрудников из департамента 'HR' 
DELETE FROM employees  
WHERE department = 'HR';`
```

**5. **CREATE TABLE****

Создает новую таблицу в базе данных.

```sql
-- Создание таблицы "employees"
CREATE TABLE employees (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    position VARCHAR(100),
    department VARCHAR(100),
    salary DECIMAL(10, 2)
);

```

**6. **ALTER TABLE****

Изменяет структуру существующей таблицы.

```sql
-- Добавление нового столбца "hire_date" в таблицу "employees"
ALTER TABLE employees 
ADD hire_date DATE;

-- Изменение типа данных столбца "salary"
ALTER TABLE employees 
ALTER COLUMN salary TYPE INTEGER;

```

**7. **DROP TABLE****

Удаляет таблицу и все ее данные из базы данных.

```sql
-- Удаление таблицы "employees"
DROP TABLE employees;
```

**8. **JOIN****

Объединяет строки из двух или более таблиц на основе связанного столбца.

```sql
-- Внутреннее объединение таблиц "employees" и "departments"
SELECT employees.name, departments.department_name
FROM employees
INNER JOIN departments ON employees.department_id = departments.id;

-- Левое объединение таблиц "employees" и "departments"
SELECT employees.name, departments.department_name
FROM employees
LEFT JOIN departments ON employees.department_id = departments.id;

```

**9. **GROUP BY****

Группирует строки, которые имеют одинаковые значения в указанных столбцах.

```sql
-- Подсчет количества сотрудников в каждом департаменте
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department;

-- Нахождение средней зарплаты в каждом департаменте
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;

```

**10. **HAVING****

Фильтрует записи после применения `GROUP BY`.

```sql
-- Подсчет количества сотрудников в каждом департаменте, только для департаментов с более чем 10 сотрудниками
SELECT department, COUNT(*) AS employee_count
FROM employees
GROUP BY department
HAVING COUNT(*) > 10;

```

**11. **ORDER BY****

Сортирует результаты запроса по одному или нескольким столбцам.

```sql
-- Сортировка сотрудников по зарплате в порядке убывания
SELECT * FROM employees
ORDER BY salary DESC;

-- Сортировка сотрудников по имени в порядке возрастания
SELECT * FROM employees
ORDER BY name ASC;

```

Эти команды составляют основу SQL и используются для выполнения различных операций с базами данных.
