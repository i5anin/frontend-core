[# min-height](https://developer.mozilla.org/en-US/docs/Web/CSS/min-height)

[CSS](./CSS)

The **`min-height`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) property sets the minimum height of an element. It prevents the [used value](https://developer.mozilla.org/en-US/docs/Web/CSS/used_value) of the [`height`](https://developer.mozilla.org/en-US/docs/Web/CSS/height) property from becoming smaller than the value specified for `min-height`.
