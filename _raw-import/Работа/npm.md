`npm` (Node Package Manager) — это менеджер пакетов для JavaScript и среда выполнения для Node.js. Он используется для управления зависимостями, библиотеками и утилитами, которые можно установить и использовать в проектах на JavaScript и Node.js.

**Основные возможности `npm`:**
- **Установка пакетов**: npm позволяет легко устанавливать и управлять сторонними библиотеками и модулями.
- **Управление зависимостями**: npm хранит зависимости проекта в файле `package.json`.
- **Публикация модулей**: npm позволяет разработчикам публиковать свои собственные модули для использования другими разработчиками.

**Основные команды `npm`:**

1. **Инициализация проекта**:
   ```bash
   npm init
   ```
   Эта команда создает файл `package.json`, который содержит информацию о проекте и его зависимостях.

2. **Установка пакета**:
   ```bash
   npm install <package-name>
   ```
   Например, чтобы установить Express:
   ```bash
   npm install express
   ```

3. **Глобальная установка пакета**:
   ```bash
   npm install -g <package-name>
   ```
   Глобально установленные пакеты доступны для всех проектов на компьютере.

4. **Удаление пакета**:
   ```bash
   npm uninstall <package-name>
   ```

5. **Обновление пакета**:
   ```bash
   npm update <package-name>
   ```

6. **Запуск скриптов**:
   В `package.json` можно описывать скрипты для удобного запуска команд, например:
   ```json
   "scripts": {
     "start": "node app.js",
     "test": "mocha"
   }
   ```
   Запускать их можно командой:
   ```bash
   npm run start
   ```

**Пример файла `package.json`:**
```json
{
  "name": "my-app",
  "version": "1.0.0",
  "description": "Пример проекта",
  "main": "app.js",
  "scripts": {
    "start": "node app.js",
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "dependencies": {
    "express": "^4.17.1"
  },
  "devDependencies": {
    "nodemon": "^2.0.12"
  },
  "author": "Your Name",
  "license": "ISC"
}
```

`npm` является неотъемлемой частью экосистемы Node.js и JavaScript и широко используется для управления проектами, библиотеками и их зависимостями.
