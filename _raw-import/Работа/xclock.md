`xclock` — это простое графическое приложение, которое отображает аналоговые или цифровые часы в окне. Оно используется в основном для тестирования X11-серверов и графического интерфейса в [Linux](#)-системах. Если `xclock` успешно отображается на экране, это означает, что X11-соединение настроено правильно, и другие графические приложения также смогут работать через этот X-сервер.

Для его установки в [Arch Linux](./Arch Linux) можно использовать команду:

```bash
pacman -S xorg-xclock
```

После установки просто выполните команду:

```bash
xclock
```

Если настройки [X11-сервера](./X11-сервера) на [Windows](./Windows) выполнены корректно, то на экране должно появиться окно с часами.
