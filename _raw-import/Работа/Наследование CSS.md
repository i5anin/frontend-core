Наследование [CSS](./CSS) — это процесс передачи определённых свойств от родительских элементов к дочерним. Однако в [CSS](./CSS) не все свойства автоматически наследуются, и для управления наследованием существуют определённые механизмы.

---

****Свойства, которые наследуются автоматически****

Некоторые [CSS](./CSS)-свойства **наследуются автоматически**, такие как:

- **Текстовые свойства**:
    - `color`
    - `font-family`
    - `font-size`
    - `font-style`
    - `font-variant`
    - `font-weight`
    - `letter-spacing`
    - `line-height`
    - `visibility`
    - `white-space`
    - `word-spacing`

Для этих свойств дочерние элементы получают значение от родителя, если не указано другое.

Пример:

```html
<div style="color: red;">
  <p>Этот текст будет красным.</p>
</div>
```

---

****Свойства, которые не наследуются автоматически****

Большинство CSS-свойств **не наследуются** по умолчанию, например

Переменные в CSS (называются **кастомные свойства**) объявляются с использованием синтаксиса, где имя переменной начинается с двойного дефиса (`--`). Переменные объявляются внутри селекторов (обычно в `:root` для глобальной доступности) и используются с помощью функции `var()`.

---

**Объявление переменных**

1. **Глобальные переменные** (обычно в `:root`):

```css
:root {
  --primary-color: #3498db;
  --secondary-color: #2ecc71;
  --font-size: 16px;
}
```

2. **Локальные переменные** (в пределах конкретного элемента):

```css
.card {
  --card-bg: #ffffff;
  --card-border: 1px solid #ddd;
}
```

---

**Использование переменных**

Чтобы использовать переменную, применяется функция `var()`:

```css
.button {
  background-color: var(--primary-color);
  color: var(--secondary-color);
  font-size: var(--font-size);
}
```

---

**Значение по умолчанию**

Можно задать значение по умолчанию, если переменная не определена:

```css
.title {
  color: var(--heading-color, black); /* Если --heading-color не задана, используется black */
}
```

---

**Пример с HTML:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <style>
    :root {
      --main-bg-color: #f4f4f4;
      --main-text-color: #333;
      --accent-color: #007bff;
    }

    body {
      background-color: var(--main-bg-color);
      color: var(--main-text-color);
    }

    a {
      color: var(--accent-color);
      text-decoration: none;
    }

    a:hover {
      color: var(--main-text-color);
    }
  </style>
  <title>CSS Variables</title>
</head>
<body>
  <h1>Использование CSS-переменных</h1>
  <a href="#">Ссылка</a>
</body>
</html>
```

---

**Динамическое изменение переменных с JavaScript**

CSS-переменные можно изменять динамически с помощью JavaScript:

```javascript
// Изменение значения переменной в :root
document.documentElement.style.setProperty('--main-bg-color', '#222');
document.documentElement.style.setProperty('--main-text-color', '#fff');
```

---

**Преимущества использования CSS-переменных:**

1. **Повторное использование**: Один раз объявив переменную, её можно использовать во многих местах.
2. **Удобство редактирования**: Изменение значения переменной сразу обновляет все элементы, где она применяется.
3. **Динамичность**: Можно легко менять значения переменных с помощью JavaScript.

CSS-переменные — это мощный инструмент для упрощения работы с дизайном и создания тем.
