# Vue — роадмап

> Путь от нуля до уверенного Middle. Без воды — только то, что реально нужно в проектах.

---

## Уровень 1 — Основы

- [ ] Реактивность: `ref`, `reactive`, `computed`, `watch`
- [ ] Шаблоны: интерполяция, `v-bind`, `v-on`, `v-if`, `v-for`, `v-model`
- [ ] Компоненты: props, emits, slots
- [ ] Жизненный цикл: `onMounted`, `onUnmounted`, `onUpdated`
- [ ] Composition API vs Options API — понять разницу

> [!tip]
> Начинать с Composition API — это текущий стандарт Vue 3.

---

## Уровень 2 — Архитектура

- [ ] Vue Router: маршруты, `<router-view>`, `<router-link>`, `useRoute`, `useRouter`
- [ ] Вложенные маршруты и навигационные guards
- [ ] Pinia: `defineStore`, state, getters, actions
- [ ] Компоненты высшего порядка и переиспользование логики через `composables`
- [ ] `provide` / `inject` — межкомпонентная коммуникация

---

## Уровень 3 — Инструменты

- [ ] Vite: структура проекта, HMR, сборка
- [ ] TypeScript в Vue: `defineProps<T>()`, `defineEmits<T>()`, типизированные composables
- [ ] UI-библиотека: PrimeVue **или** Element Plus (выбрать одну)
- [ ] Axios / fetch: запросы к API, интерцепторы, обработка ошибок
- [ ] ESLint + Prettier: настройка под Vue

---

## Уровень 4 — Продвинутое

- [ ] FSD (Feature-Sliced Design) — архитектура для средних и крупных проектов
- [ ] Кастомные директивы (`v-directive`)
- [ ] Телепорты (`<Teleport>`) и динамические компоненты (`<component :is>`)
- [ ] Ленивая загрузка компонентов (`defineAsyncComponent`)
- [ ] Виртуальный скроллинг для больших списков
- [ ] SSR / Nuxt 3 — базовое понимание

---

## Уровень 5 — Качество

- [ ] Тестирование: Vitest + Vue Test Utils
- [ ] Оптимизация: `v-memo`, `shallowRef`, анализ бандла
- [ ] Vue DevTools — профилирование и отладка
