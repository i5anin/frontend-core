На изображении описан принцип **специфичности CSS-правил**, который определяет приоритет применения стилей, если для одного элемента задано несколько правил.

---

**Что такое специфичность [CSS](./CSS)?**

**Специфичность** — это механизм, который CSS использует для определения того, какие стили должны быть применены к элементу, если для него задано несколько правил.

---

**Формула специфичности**

Специфичность вычисляется как комбинация чисел, где каждая группа селекторов добавляет к общей специфичности своё значение.

**Распределение веса:**

1. **Инлайн-стили**: 1000
    - Пример: `<div style="color: red;">`
2. **ID**: 100
    - Пример: `#myId { color: red; }`
3. **Классы, атрибуты, псевдоклассы**: 10
    - Пример: `.myClass { color: red; }`, `[type="text"] { color: red; }`, `:hover { color: red; }`
4. **Теги и псевдоэлементы**: 1
    - Пример: `div { color: red; }`, `::after { color: red; }`

---

**Пример специфичности**

```css
/* Специфичность: 1 */
div {
  color: blue;
}

/* Специфичность: 10 */
.myClass {
  color: green;
}

/* Специфичность: 100 */
#myId {
  color: red;
}

/* Инлайн-стиль: 1000 */
<div id="myId" class="myClass" style="color: black;">Текст</div>
```

**Применённый стиль:**

- `style="color: black;"` (Инлайн-стиль: 1000) имеет наивысший приоритет, и текст будет чёрным.

---

**Заметки о специфичности:**

1. **Сочетание селекторов увеличивает специфичность.** Например:
    
    ```css
    div.myClass { color: orange; } /* Специфичность: 11 (1 тег + 10 класс) */
    ```
    
2. **Каскадность.** Если специфичность одинаковая, побеждает правило, написанное **после**.
    
3. **`!important`**:
    
    - `!important` имеет высший приоритет, даже выше инлайн-стилей, но не увеличивает специфичность.
    - Пример:
        
        ```css
        div { color: red !important; }
        ```
        

---

**Практический пример:**

```css
/* Теги (1) */
h1 {
  color: blue;
}

/* Классы (10) */
.title {
  color: green;
}

/* ID (100) */
#main-title {
  color: red;
}
```

```html
<h1 id="main-title" class="title">Пример текста</h1>
```

**Результат**: Текст будет красным, так как стиль с `ID` имеет наивысшую специфичность.

---

**Почему это важно?**

Понимание специфичности позволяет:

- Избежать конфликтов между стилями.
- Упростить отладку, находя, какое правило перекрывает другое.
- Написать более предсказуемый CSS-код.
