Структура файлов в папке `src` проекта находится в `frontend`:
```
assets
src
├─components
|   └─tools
|       ├─api
|       ├─components
|       └─store

```

Описание структуры:
-   `assets` - папка с ресурсами проекта, такими как стили, шрифты, изображения и скрипты;
-   `components` - папка с компонентами проекта, каждый компонент находится в отдельной папке с файлами `.js` и `.scss`;
-   `pages` - папка с отдельными страницами проекта, каждая страница находится в отдельной папке с файлами `.js` и `.scss`;
-   `services` - папка с файлами для работы с сервисами и API;
-   `utils` - папка с утилитами и вспомогательными функциями;
-   `App.js` - главный файл приложения, который содержит роутер и главный компонент;
-   `App.scss` - главный файл стилей приложения;
-   `index.js` - файл, который рендерит главный компонент приложения;
-   `index.html` - главный файл [HTML](./HTML) страницы.
