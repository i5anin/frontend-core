```javascript
const weakMap = new WeakMap();

let obj = { name: 'Anna' };

weakMap.set(obj, 'Привет, Анна!');
console.log(weakMap.get(obj));  // "Привет, Анна!"

// Удаляем объект, после чего ссылка на него из WeakMap пропадет
obj = null;

// WeakMap автоматически очищается от объектов без ссылок
``` 

**Особенности `WeakMap`:**

- Ключами могут быть только объекты.
- Нет методов для получения всех ключей или значений, как в обычном [Map структура данных](./Map структура данных).
- Автоматически удаляет записи, если на объект нет других ссылок (поддерживает "сборщик мусора").
