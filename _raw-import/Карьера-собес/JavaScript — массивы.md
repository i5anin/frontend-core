# JavaScript — методы массивов

> Шпаргалка для собеса. Сгруппировано по смыслу, не по алфавиту.

---

## ➕ Мутируют исходный массив

> Меняют оригинал на месте — осторожно в React/Vue.

**push(x)** — Добавить в **конец**
`[🍎, 🍋].push(🍇)` → `[🍎, 🍋, 🍇]`

---

**pop()** — Удалить из **конца**
`[🍎, 🍋, 🍇].pop()` → `[🍎, 🍋]`

---

**unshift(x)** — Добавить в **начало**
`[🍋, 🍇].unshift(🍎)` → `[🍎, 🍋, 🍇]`

---

**shift()** — Удалить из **начала**
`[🍎, 🍋, 🍇].shift()` → `[🍋, 🍇]`

---

**reverse()** — Развернуть массив
`[🍎, 🍋, 🍇].reverse()` → `[🍇, 🍋, 🍎]`

---

**fill(x, start, end)** — Заполнить значением с позиции start до end
`[🍎, 🍋, 🍇].fill(⭐, 1)` → `[🍎, ⭐, ⭐]`

---

**splice(start, n, ...x)** — Удалить n элементов с позиции start, вставить x
`[🍎, 🍋, 🍇].splice(1, 1, 🔥)` → `[🍎, 🔥, 🍇]`

---

**sort(fn)** — Сортировать
`[🍇, 🍎, 🍋].sort()` → `[🍎, 🍋, 🍇]`

---

## 🔁 Возвращают новый массив

> Оригинал не трогают — безопасно.

**map(fn)** — Преобразовать каждый элемент
`[🍎, 🍋, 🍇].map(x => 🍓)` → `[🍓, 🍓, 🍓]`

---

**filter(fn)** — Оставить только подходящие
`[🍎, 🍋, 🍎].filter(x => x === 🍎)` → `[🍎, 🍎]`

---

**concat(arr)** — Склеить массивы
`[🍎, 🍋].concat([🍇, 🍓])` → `[🍎, 🍋, 🍇, 🍓]`

---

**slice(start, end)** — Вырезать кусок (end не включается)
`[🍎, 🍋, 🍇, 🍓].slice(0, 2)` → `[🍎, 🍋]`

---

**flat(depth)** — Распрямить вложенный массив
`[🍎, [🍋, 🍇]].flat()` → `[🍎, 🍋, 🍇]`

---

**flatMap(fn)** — map + flat за один проход
`[🍎, 🍋].flatMap(x => [x, 🔥])` → `[🍎, 🔥, 🍋, 🔥]`

---

## 🔍 Поиск

**find(fn)** — Первый **элемент** по условию
`[🍎, 🍋, 🍇].find(x => x === 🍋)` → `🍋`

---

**findIndex(fn)** — Индекс первого по условию
`[🍎, 🍋, 🍇].findIndex(x => x === 🍋)` → `1`

---

**indexOf(x)** — Индекс первого точного совпадения
`[🍎, 🍋, 🍇].indexOf(🍋)` → `1`

---

**lastIndexOf(x)** — Индекс последнего совпадения
`[🍎, 🍋, 🍎].lastIndexOf(🍎)` → `2`

---

**at(i)** — Элемент по индексу, `-1` = с конца
`[🍎, 🍋, 🍇].at(-1)` → `🍇`

---

**includes(x)** — Есть ли элемент в массиве
`[🍎, 🍋, 🍇].includes(🍋)` → `true`

---

## ✅ Проверка условий

**some(fn)** — Хотя бы **один** подходит?
`[🍎, 🍋, 🍇].some(x => x === 🍇)` → `true`

---

**every(fn)** — **Все** подходят?
`[🍎, 🍎, 🍎].every(x => x === 🍎)` → `true`

---

## 🧮 Свёртка

**reduce(fn, init)** — Аккумулятор слева направо
`[🍎, 🍋, 🍇].reduce((acc, x) => acc + x, 🧺)` → `🧺🍎🍋🍇`

---

**reduceRight(fn, init)** — То же, но справа налево
`[🍎, 🍋, 🍇].reduceRight((acc, x) => acc + x, 🧺)` → `🧺🍇🍋🍎`

---

## 🔗 Преобразование в другой тип

**join(sep)** — Массив в строку через разделитель
`[🍎, 🍋, 🍇].join(' | ')` → `"🍎 | 🍋 | 🍇"`

---

**toString()** — Массив в строку через запятую
`[🍎, 🍋, 🍇].toString()` → `"🍎,🍋,🍇"`

---

**Array.from(x)** — Итерируемое в массив
`Array.from('abc')` → `['a', 'b', 'c']`

---

**Array.isArray(x)** — Проверить: это массив?
`Array.isArray([🍎])` → `true`

---

## 🚶 Обход (без возврата)

**forEach(fn)** — Перебрать элементы, ничего не вернуть
`[🍎, 🍋, 🍇].forEach(x => console.log(x))`

---

**entries()** — Итератор пар [индекс, значение]
`[🍎, 🍋].entries()` → `[0, 🍎]` `[1, 🍋]`

---

**keys()** — Итератор индексов
`[🍎, 🍋, 🍇].keys()` → `0, 1, 2`

---

**values()** — Итератор значений
`[🍎, 🍋, 🍇].values()` → `🍎, 🍋, 🍇`

---

## Запомни главное

> [!tip] Мутирует vs Новый массив
> **Мутируют:** `push` `pop` `shift` `unshift` `splice` `reverse` `sort` `fill`
>
> **Новый массив:** `map` `filter` `concat` `slice` `flat` `flatMap`
>
> **Значение:** `find` `findIndex` `indexOf` `includes` `some` `every` `reduce`

> [!warning] На собесе часто спрашивают
> - Разница `find` vs `filter` — find возвращает **элемент**, filter — **массив**
> - Разница `slice` vs `splice` — slice не мутирует, splice мутирует
> - Разница `some` vs `every` — OR vs AND
> - Как работает `reduce` — с аккумулятором
