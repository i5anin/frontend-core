# 🧠 Метод заучивания терминов

> Программисты не любят расплывчатые формулировки. Нужна **точность**.
> Знаешь, как работает, но не помнишь определение — это вопрос тренировки.

---

## 🎯 Зачем точные термины

> [!tip] Контекст
> В технической среде термин = инструмент. Точное слово убирает двусмысленность и делает объяснение ясным для:
> - тимлида
> - проджект-менеджера
> - интервьюера

---

## 🧩 Метод 1: Разбивка на блоки

Любое определение делится на 2–3 смысловых куска.

**Пример:** `async/await`
- **Блок 1** — *синтаксический сахар над промисами*
- **Блок 2** — *позволяет писать асинхронный код в синхронном стиле*

> Так легче воспроизводить — мозг помнит куски, а не сплошной текст.

---

## 🦴 Метод 2: Скелет объяснения

Шаблон для любого термина:

```
1. Определение:    X — это ...
2. Как работает:   ...
3. Где используется: ...
4. Пример кода:    ...
```

**Пример** для `async/await`:

| Блок | Содержание |
|---|---|
| Определение | Синтаксический сахар над промисами |
| Как работает | `async` делает функцию асинхронной, `await` ждёт результат промиса |
| Где используется | API-запросы, таймеры, обработка больших данных |
| Пример | `async function getData() { await fetch(url) }` |

---

## 💻 Метод 3: Запомнить пример кода

Даже если забыл определение — напиши код, объясни на лету:

```js
async function getData() {
  const res = await fetch(url)
  return res.json()
}
```

> Из кода можно вытянуть определение обратно.

---

## 🔁 Метод 4: Тренировка формулировок

1. Открываешь карточку
2. Произносишь определение **вслух** своими словами
3. Сравниваешь с эталоном
4. Корректируешь
5. Повторяешь через интервалы (1ч → 1д → 3д → 7д → 14д)

> [!warning] Главное
> **Не зубрить.** Понимать смысл и применение каждого термина.
