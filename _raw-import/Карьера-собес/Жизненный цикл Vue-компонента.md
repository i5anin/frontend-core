**Жизненный цикл Vue-компонента**

**Жизненный цикл** [Vue](#)-компонента — это последовательность этапов, через которые проходит компонент, начиная с его создания и заканчивая удалением. [Vue](#) предоставляет специальные хуки, которые позволяют разработчику выполнять код на каждом этапе жизненного цикла компонента.

---

**Основные этапы жизненного цикла:**

1. **Создание (Creation)**:
    
    - **Подготовка компонента**, настройка реактивности и начальных данных.
    - Происходят вызовы `beforeCreate` и `created`.
2. **Монтирование (Mounting)**:
    
    - Разметка компонента вставляется в DOM.
    - Происходят вызовы `beforeMount` и `mounted`.
3. **Обновление (Updating)**:
    
    - Вызывается, если реактивные данные изменяются, и компонент ререндерится.
    - Происходят вызовы `beforeUpdate` и `updated`.
4. **Удаление (Unmounting)**:
    
    - Компонент удаляется из DOM.
    - Происходят вызовы `beforeUnmount` и `unmounted`.

---

**Полный список хуков жизненного цикла:**

**1. **Хуки создания компонента****

- **`beforeCreate`**
    
    - Вызывается сразу после инициализации экземпляра компонента.
    - На этом этапе реактивность ещё не настроена.
    - Пример:
        
        ```javascript
        beforeCreate() {
          console.log('Компонент создаётся, но данные ещё не доступны.');
        }
        ```
        
- **`created`**
    
    - Вызывается после настройки реактивности.
    - Доступны `data`, `computed`, `methods`, но компонент ещё не вставлен в DOM.
    - Пример:
        
        ```javascript
        created() {
          console.log('Компонент создан, данные доступны:', this.data);
        }
        ```
        

---

**2. **Хуки монтирования компонента****

- **`beforeMount`**
    
    - Вызывается перед вставкой компонента в DOM.
    - Виртуальный DOM уже создан, но реальный DOM ещё не обновлён.
    - Пример:
        
        ```javascript
        beforeMount() {
          console.log('Перед монтированием компонента в DOM');
        }
        ```
        
- **`mounted`**
    
    - Вызывается после вставки компонента в DOM.
    - Полезен для выполнения действий, зависящих от присутствия элемента в DOM (например, инициализация сторонних библиотек).
    - Пример:
        
        ```javascript
        mounted() {
          console.log('Компонент смонтирован в DOM');
        }
        ```
        

---

**3. **Хуки обновления компонента****

- **`beforeUpdate`**
    
    - Вызывается перед обновлением DOM после изменения данных.
    - Позволяет выполнить действия до применения изменений.
    - Пример:
        
        ```javascript
        beforeUpdate() {
          console.log('Перед обновлением DOM');
        }
        ```
        
- **`updated`**
    
    - Вызывается после того, как изменения внесены в DOM.
    - На этом этапе компонент полностью обновлён.
    - Пример:
        
        ```javascript
        updated() {
          console.log('Компонент обновлён');
        }
        ```
        

---

**4. **Хуки удаления компонента****

- **`beforeUnmount`**
    
    - Вызывается перед удалением компонента из DOM.
    - Используется для выполнения операций очистки (например, остановки таймеров, удаления обработчиков событий).
    - Пример:
        
        ```javascript
        beforeUnmount() {
          console.log('Перед удалением компонента из DOM');
        }
        ```
        
- **`unmounted`**
    
    - Вызывается после того, как компонент удалён из DOM.
    - Пример:
        
        ```javascript
        unmounted() {
          console.log('Компонент удалён из DOM');
        }
        ```
        

---

**Схема жизненного цикла**

```plaintext
           Создание          Монтирование        Обновление           Удаление
          ┌───────────┐     ┌───────────┐      ┌────────────┐       ┌──────────┐
          │ beforeCreate │ → │ beforeMount │ → │ beforeUpdate │ →    │ beforeUnmount │
          │   created   │    │   mounted   │    │   updated   │      │  unmounted   │
          └───────────┘     └───────────┘      └────────────┘       └──────────┘
```

---

**Пример использования хуков:**

```javascript
<template>
  <div>
    <h1>{{ message }}</h1>
    <button @click="updateMessage">Изменить сообщение</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: 'Привет, Vue!'
    };
  },
  beforeCreate() {
    console.log('beforeCreate: Компонент создаётся');
  },
  created() {
    console.log('created: Компонент создан');
  },
  beforeMount() {
    console.log('beforeMount: Перед монтированием');
  },
  mounted() {
    console.log('mounted: Компонент смонтирован');
  },
  beforeUpdate() {
    console.log('beforeUpdate: Перед обновлением');
  },
  updated() {
    console.log('updated: Компонент обновлён');
  },
  beforeUnmount() {
    console.log('beforeUnmount: Перед удалением');
  },
  unmounted() {
    console.log('unmounted: Компонент удалён');
  },
  methods: {
    updateMessage() {
      this.message = 'Сообщение обновлено!';
    }
  }
};
</script>
```

---

**Практическое применение:**

1. **`mounted`**: Подключение сторонних библиотек, например, графиков.
2. **`beforeUnmount`**: Удаление обработчиков событий.
3. **`updated`**: Отслеживание завершения обновлений.

Эти хуки позволяют точно контролировать поведение компонентов на каждом этапе их жизненного цикла.
