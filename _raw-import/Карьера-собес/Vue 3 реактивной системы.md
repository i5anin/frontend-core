В [Vue 3](#) переменная становится **реактивной** благодаря использованию **реактивной системы**, которая основана на JavaScript-прокси (`Proxy`). Это позволяет Vue автоматически отслеживать изменения данных и обновлять пользовательский интерфейс (DOM).

Давайте разберём, как именно переменная становится реактивной и как это работает.

---

****1. Как переменная становится реактивной?****

Vue предоставляет специальные функции: **`reactive`** и **`ref`**, чтобы сделать переменные реактивными:

1. **`reactive`**:
    
    - Превращает объект или массив в реактивный.
    - Отслеживает изменения всех его свойств.
    
    Пример:
    
    ```javascript
    import { reactive } from 'vue';
    
    const state = reactive({ count: 0 });
    
    state.count++; // Vue автоматически отслеживает изменение
    ```
    
2. **`ref`**:
    
    - Используется для создания реактивности примитивных данных (числа, строки, булевые значения).
    - Для доступа к значению используется `.value`.
    
    Пример:
    
    ```javascript
    import { ref } from 'vue';
    
    const count = ref(0);
    
    count.value++; // Vue отслеживает изменение .value
    ```
    

---

****2. Реактивность: внутри или вне функции?****

- Реактивные данные чаще всего создаются **внутри `setup`** функции (Composition API).
- Это нужно, чтобы правильно передавать данные компоненту и автоматически отслеживать их изменения.

Пример внутри `setup`:

```javascript
export default {
  setup() {
    const count = ref(0); // Создаём реактивную переменную

    const increment = () => {
      count.value++; // Обновляем реактивное значение
    };

    return { count, increment }; // Возвращаем реактивные данные в шаблон
  }
};
```

**Пример использования в шаблоне:**

```html
<template>
  <div>
    <p>Счётчик: {{ count }}</p>
    <button @click="increment">Увеличить</button>
  </div>
</template>
```

---

****3. Как Vue делает данные реактивными?****

****a. Прокси (Proxy)**:**

Vue использует `Proxy` для обёртки объектов или массивов, чтобы "перехватывать" операции чтения и записи данных.

Пример использования `Proxy` (упрощённая реактивность):

```javascript
const handler = {
  get(target, key) {
    console.log(`Чтение ${key}`);
    return target[key];
  },
  set(target, key, value) {
    console.log(`Изменение ${key} на ${value}`);
    target[key] = value;
    return true;
  },
};

const obj = new Proxy({ count: 0 }, handler);

console.log(obj.count); // Чтение count
obj.count = 5; // Изменение count на 5
```

Vue делает похожую обёртку для `reactive` объектов, чтобы отслеживать изменения.

****b. Реактивные эффекты (Reactive Effects)**:**

Vue связывает реактивные данные с компонентом или функцией, которые должны обновляться при изменении данных.

Пример:

```javascript
import { reactive, effect } from 'vue';

const state = reactive({ count: 0 });

effect(() => {
  console.log(`Счётчик: ${state.count}`); // Автоматически вызывается при изменении
});

state.count++; // Лог: Счётчик: 1
state.count++; // Лог: Счётчик: 2
```

---

****4. Реактивность вне `setup`****

Если реактивные данные создаются **вне `setup`**, они всё равно остаются реактивными. Однако такие данные лучше обрабатывать через глобальное хранилище (например, Pinia).

Пример:

```javascript
import { reactive } from 'vue';

const state = reactive({ count: 0 }); // Реактивный объект вне компонента

export default {
  setup() {
    const increment = () => {
      state.count++;
    };

    return { state, increment };
  }
};
```

---

****5. Разница между реактивностью и обычными переменными****

**Обычная переменная:**

```javascript
let count = 0;

function increment() {
  count++;
  console.log(count); // Нужно явно отслеживать изменения
}

increment(); // Лог: 1
increment(); // Лог: 2
```

**Реактивная переменная:**

```javascript
import { ref } from 'vue';

const count = ref(0);

function increment() {
  count.value++;
  // Vue автоматически обновляет интерфейс при изменении count
}
```

**Главное отличие**: Vue отслеживает изменения реактивных данных автоматически, поэтому интерфейс обновляется без необходимости вручную вызывать методы.

---

****6. Использование `watch` и `computed` для реактивности****

- **`watch`**: Для выполнения действий при изменении данных.
    
    ```javascript
    import { ref, watch } from 'vue';
    
    const count = ref(0);
    
    watch(count, (newVal, oldVal) => {
      console.log(`Изменение: с ${oldVal} на ${newVal}`);
    });
    
    count.value++;
    ```
    
- **`computed`**: Для создания вычисляемых свойств, которые зависят от реактивных данных.
    
    ```javascript
    import { ref, computed } from 'vue';
    
    const count = ref(2);
    
    const doubleCount = computed(() => count.value * 2); // Реактивное вычисляемое свойство
    
    console.log(doubleCount.value); // 4
    count.value++;
    console.log(doubleCount.value); // 6
    ```
    

---

****Заключение****

Переменная становится реактивной в Vue, если она обёрнута с помощью:

1. **`reactive`** (для объектов и массивов).
2. **`ref`** (для примитивов).

Эта реактивность реализуется через прокси (`Proxy`), что позволяет Vue автоматически отслеживать изменения данных и обновлять интерфейс. Реактивные данные чаще всего создаются **внутри функции `setup`**, но они могут быть определены и вне неё.
