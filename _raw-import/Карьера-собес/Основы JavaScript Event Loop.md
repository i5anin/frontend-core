[JavaScript](../Работа/JavaScript) [Event Loop](#)

**Код:**

```javascript
console.log(1);
setTimeout(() => console.log(2));
new Promise((resolve) => {
    console.log(3);
    resolve();
});
Promise.resolve().then(() => console.log(4));
console.log(5);
```

---

**Результат выполнения:**

```
1
3
5
4
2
```

---

**Объяснение:**

**1. **Основы JavaScript Event Loop****

- Весь код делится на **синхронный** и **асинхронный**.
- **Синхронный код** выполняется сразу в основном потоке.
- **Асинхронный код** откладывается в очередь событий (Event Queue) и выполняется после выполнения всего синхронного кода.

---

**2. **Порядок выполнения****

1. **`console.log(1)`**
    
    - Синхронный код. Выводит `1` в консоль.
2. **`setTimeout`**
    
    - Асинхронный код. Коллбэк откладывается в очередь (Event Queue). Его выполнение произойдёт позже.
3. **`new Promise`**
    
    - Конструктор промиса выполняется **синхронно**.
    - `console.log(3)` выполняется сразу, выводя `3`.
    - `resolve()` переводит промис в состояние «resolved».
4. **`Promise.resolve().then`**
    
    - Обработчик `.then` откладывается в **микрозадачи** (Microtask Queue). Микрозадачи выполняются после выполнения всех синхронных операций, но до выполнения задач из Event Queue.
5. **`console.log(5)`**
    
    - Синхронный код. Выполняется сразу, выводя `5`.

---

**3. **Асинхронный код****

- После завершения синхронного кода:
    1. Выполняются **микрозадачи**.
        
        - Коллбэк `.then` из `Promise.resolve()` выполняется, выводя `4`.
    2. Выполняются задачи из **очереди событий**.
        
        - Коллбэк `setTimeout` выполняется, выводя `2`.

---

**Итоговый порядок:**

1. `1` — синхронный код.
2. `3` — синхронный код из промиса.
3. `5` — синхронный код.
4. `4` — микрозадача.
5. `2` — асинхронная задача из Event Queue.
