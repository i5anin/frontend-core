**Инлайн-стили** — это стиль, который применяется непосредственно к элементу с использованием атрибута `style`. Они задаются в виде строки, содержащей свойства [CSS](../Работа/CSS) и их значения. Инлайн-стили имеют самый высокий приоритет среди источников стилей (кроме `!important`).

---

**Синтаксис**

```html
<tag style="property: value; property: value;">Content</tag>
```

**Пример**

```html
<div style="color: red; font-size: 20px; background-color: yellow;">
  Это текст с инлайн-стилями.
</div>
```

---

**Особенности инлайн-стилей**

1. **Высокий приоритет**: Инлайн-стили перекрывают стили из внешних или внутренних таблиц стилей, если не используются `!important`.
2. **Применяются к конкретному элементу**: Инлайн-стили влияют только на элемент, к которому они применены.
3. **Неудобны для масштабирования**: Использование инлайн-стилей усложняет поддержку и переопределение стилей в больших проектах.

---

**Использование в JavaScript**

Инлайн-стили можно добавлять или изменять через JavaScript с помощью свойства `style`.

**Пример:**

```html
<div id="myDiv">Пример текста</div>

<script>
  const element = document.getElementById('myDiv');
  element.style.color = 'blue'; // Задаём цвет текста
  element.style.fontSize = '24px'; // Задаём размер шрифта
</script>
```

---

**Преимущества инлайн-стилей**

- Быстрый способ стилизации небольших или динамически созданных элементов.
- Полезны, когда нужно применить уникальный стиль для одного элемента.

---

**Недостатки инлайн-стилей**

1. **Плохая читаемость**: Увеличивается количество стилей прямо в разметке, что делает код сложным для чтения.
2. **Отсутствие повторного использования**: Один и тот же стиль приходится прописывать для каждого элемента отдельно.
3. **Сложности с изменением**: Чтобы изменить стиль, нужно найти и исправить все инлайн-стили вручную.

---

**Когда использовать инлайн-стили**

- Для динамических изменений с помощью JavaScript.
- Для быстрого прототипирования или тестирования.
- Для случаев, когда стиль применяется только к одному элементу и не будет использоваться повторно.

---

**Альтернатива инлайн-стилям**

Для более структурированного подхода рекомендуется использовать:

1. **Внешние таблицы стилей** (с помощью файла CSS).
2. **Классы** для переиспользуемых стилей:
    
    ```html
    <style>
      .highlight {
        color: red;
        font-size: 20px;
      }
    </style>
    <div class="highlight">Это текст с классом</div>
    ```
    

Инлайн-стили остаются полезным инструментом, но их стоит применять осознанно и не злоупотреблять ими.
