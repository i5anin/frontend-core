# 📘 TypeScript — карточки для Quizlet

> Цель: 100 карточек по TypeScript для собеса.

---

## 📦 Базовый набор (15 карточек)

```
TypeScript---Типизированное надмножество JavaScript, компилируемое в JavaScript;
interface---Декларация контракта структуры объекта или класса в TypeScript;
type alias---Псевдоним для типа, может описывать примитивы, объекты, юнионы и пересечения;
union type---Тип, представляющий значение одного из нескольких типов, обозначаемый символом |;
intersection type---Тип, объединяющий несколько типов в один через символ &;
generic---Параметризированный тип, позволяющий писать переиспользуемый код, работающий с разными типами;
unknown---Безопасная альтернатива any, требующая проверки типа перед использованием значения;
never---Тип значения, которое не может существовать, используется в функциях с throw или бесконечным циклом;
void---Тип возвращаемого значения функции, ничего не возвращающей;
any---Тип, отключающий проверку типов, делая значение совместимым с любым типом;
enum---Именованный набор констант, представляющий перечисляемое множество значений;
tuple---Массив фиксированной длины с типизированными элементами в определённом порядке;
readonly---Модификатор, запрещающий изменение свойства после инициализации;
Partial---Утилита, делающая все свойства типа опциональными;
Pick---Утилита, выбирающая подмножество свойств из типа.
```
