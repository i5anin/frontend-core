# Каррирование в [JavaScript](../Работа/JavaScript)

## Пример функции с каррированием

Каррирование — это техника, при которой функция принимает аргументы не сразу все, а по одному, и возвращает новую функцию для обработки следующего аргумента.

**Пример:**
```javascript
function sum(a) {
    return (b) => a + b;
}

const result = sum(5)(10); // Передаём 5, затем 10
console.log(result); // 15
````

**Как это работает:**

1. `sum(5)` вызывает функцию `sum` с аргументом `a = 5`.
2. Функция возвращает новую функцию `(b) => a + b`, в которой `a` уже "замкнуто".
3. `(b) => a + b` вызывается с `b = 10`.
4. Выполняется вычисление `5 + 10`.
5. Результат `15` возвращается и выводится в консоль.

---

## Каррирование — пошаговый процесс

Каррирование — это трансформация функции с множеством аргументов в последовательность вложенных функций, каждая из которых принимает по одному аргументу.

**Пример обычной функции:**

```javascript
function add(a, b) {
    return a + b;
}
console.log(add(5, 10)); // 15
```

**Пример с каррированием:**

```javascript
function add(a) {
    return function (b) {
        return a + b;
    };
}

console.log(add(5)(10)); // 15
```

---

## Зачем использовать каррирование:

**1. **Повторное использование функций****

Вы можете создавать специализированные функции:

```javascript
const add5 = sum(5); // Создаём функцию, добавляющую 5
console.log(add5(10)); // 15
console.log(add5(20)); // 25
```

**2. **Читаемость****

Каррирование помогает разделять логику по шагам.

**3. **Функциональное программирование****

Активно используется в таких библиотеках, как `lodash` и `ramda`.

---

## Ещё один пример:

**Каррирование для умножения:**

```javascript
const multiply = (a) => (b) => a * b;

const multiplyBy2 = multiply(2); // Частичное применение
console.log(multiplyBy2(10)); // 20
console.log(multiplyBy2(5)); // 10
```

Каррирование — это мощный инструмент, который улучшает **читаемость**, **модульность** и **переиспользование кода**.
