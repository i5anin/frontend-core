# 🟨 JavaScript — карточки для Quizlet

> Карточки готовы для импорта в Quizlet. Разделитель: `---` / `;`

---

## 📦 Базовый набор (20 карточек)

```
Замыкание---Функция, которая запоминает область видимости, в которой была создана, даже после завершения выполнения внешней функции;
Promise---Объект, представляющий результат асинхронной операции, который может находиться в одном из трёх состояний: pending, fulfilled или rejected;
async/await---Синтаксический сахар над промисами, позволяющий писать асинхронный код в синхронном стиле;
this---Контекст выполнения функции, который зависит от способа вызова функции;
setTimeout---Функция, которая откладывает выполнение кода на определённое количество миллисекунд;
setInterval---Функция, выполняющая код через заданный интервал времени до явной остановки;
Map---Коллекция, хранящая пары ключ-значение, где ключи могут быть любого типа;
Set---Коллекция, хранящая только уникальные значения;
typeof---Оператор, возвращающий тип переданного значения;
null---Специальное значение, представляющее отсутствие значения или пустую ссылку;
undefined---Значение, присваиваемое переменной, если ей не было присвоено явное значение;
let---Оператор для объявления переменной с блочной областью видимости;
const---Оператор для объявления переменной, значение которой нельзя переопределить;
var---Устаревший оператор объявления переменной с функциональной областью видимости;
spread оператор---Оператор (...), который разворачивает массив или объект в список элементов;
rest параметры---Оператор (...), который объединяет переданные аргументы в массив;
ES6 (ECMAScript 2015)---Версия стандарта JavaScript, включающая let/const, стрелочные функции, классы и модули;
Prototype---Механизм, с помощью которого объекты наследуют свойства и методы от других объектов;
Event Loop---Механизм, обеспечивающий асинхронное выполнение кода в JavaScript;
Web API---Набор браузерных API, предоставляющих доступ к DOM, fetch, localStorage и другим возможностям.
```
