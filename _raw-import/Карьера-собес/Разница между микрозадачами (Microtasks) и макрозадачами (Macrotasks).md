В [JavaScript](../Работа/JavaScript) цикл обработки событий ([event loop](#)) состоит из нескольких очередей. Основные из них — это очередь **макрозадач** и очередь **микрозадач**. Вот как они работают:

---

****Микрозадачи (Microtasks)****

Микрозадачи имеют **высший приоритет**. После выполнения текущего стека вызовов (synchronous stack), **все микрозадачи выполняются перед переходом к макрозадачам**.

Примеры микрозадач:

- `.then()` и `.catch()` из промисов.
- `queueMicrotask()`.
- Обработчики `MutationObserver`.

---

****Макрозадачи (Macrotasks)****

Макрозадачи имеют **низший приоритет** по сравнению с микрозадачами. Они выполняются только после того, как текущий стек вызовов и все микрозадачи будут обработаны.

Примеры макрозадач:

- `setTimeout` и `setInterval`.
- `setImmediate` (в Node.js).
- Обработчики событий (например, `click`, `keydown`).

---

****Порядок выполнения****

1. Выполняется весь текущий стек вызовов (синхронный код).
2. Выполняются все микрозадачи, которые были добавлены в очередь.
3. Переходит к первой макрозадаче из очереди.
4. Повторяет цикл.

---

**Пример кода:**

```javascript
console.log('Start');

setTimeout(() => console.log('Macrotask: setTimeout'), 0);

Promise.resolve().then(() => {
    console.log('Microtask: Promise.then');
    return Promise.resolve().then(() => console.log('Another Microtask'));
});

console.log('End');
```

**Разбор:**

1. Синхронный код: `console.log('Start')` и `console.log('End')` → **`Start`, `End`**.
2. Микрозадачи:
    - `Promise.then` → **`Microtask: Promise.then`**.
    - Вложенный `Promise.then` → **`Another Microtask`**.
3. Макрозадача `setTimeout` → **`Macrotask: setTimeout`**.

**Итоговый вывод:**

```
Start
End
Microtask: Promise.then
Another Microtask
Macrotask: setTimeout
```

---

**Визуализация Event Loop:**

1. **Stack** (Стек вызовов):
    
    - Выполняет синхронный код.
2. **Microtask Queue**:
    
    - После выполнения стека выполняются **все** микрозадачи.
3. **Macrotask Queue**:
    
    - Выполняется только одна макрозадача после завершения всех микрозадач.

---

**Почему это важно?**

- Управление порядком выполнения задач помогает оптимизировать код и избежать неожиданных ошибок.
- Понимание микрозадач позволяет эффективно работать с `Promise` и асинхронным кодом.
