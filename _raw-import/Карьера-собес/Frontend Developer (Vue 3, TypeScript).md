Коммерческая разработка интерфейсов на **Vue 3 + TypeScript** в роли **Frontend Developer (middle)**. Интересуют проекты с реальной сложностью на фронтенде: сложные таблицы, конфигурируемые интерфейсы, интеграции с REST API, работа с данными.
