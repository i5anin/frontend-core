# 📋 Формат импорта в Quizlet

## Правила

| Разделитель | Что разделяет |
|---|---|
| `---` | Термин ↔ Определение |
| `;` | Карточки между собой |

---

## 📝 Шаблон

```
Термин 1---Определение 1;Термин 2---Определение 2;Термин 3---Определение 3
```

---

## 🔹 Мини-пример

```
Vue.js---Фреймворк для создания интерфейсов;Docker---Платформа для контейнеризации;PostgreSQL---СУБД реляционного типа;API---Интерфейс для взаимодействия между программами
```

---

## ⚙️ Как импортировать

1. В Quizlet: **Создать набор** → **Импорт**
2. Разделитель термина: `---`
3. Разделитель между карточками: `;`
4. Вставить текст из любого файла-карточки
5. **Импортировать**

---

## 💡 Промт для ChatGPT

> Используй когда нужно быстро сгенерировать карточки.

```
Создай 20 карточек по теме [JavaScript / Vue / TypeScript].
Формат строго:
Термин---Определение;Термин---Определение

Условия:
- определение в одно предложение
- без переноса строки внутри карточки
- между карточками только `;`
- термины уровня "middle frontend"
```
