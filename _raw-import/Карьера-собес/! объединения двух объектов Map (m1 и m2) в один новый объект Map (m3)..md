[Map](#)
На изображении представлен пример объединения двух объектов `Map` (`m1` и `m2`) в один новый объект `Map` (`m3`).

---

**Код из изображения:**

```javascript
const m1 = new Map();
m1.set(1, 1);
m1.set(2, 2);

const m2 = new Map();
m2.set(3, 3);
m2.set(4, 4);

const m3 = new Map([...m1.entries(), ...m2.entries()]);

console.log(m3);
```

---

**Разбор кода:**

1. **Создание `m1` и `m2`**
    
    - `m1` содержит пары:
        
        ```
        1 → 1
        2 → 2
        ```
        
    - `m2` содержит пары:
        
        ```
        3 → 3
        4 → 4
        ```
        
2. **Метод `.entries()`**
    
    - Метод `m1.entries()` возвращает итератор всех пар ключ-значение из `m1`.
    - Например, результат вызова `[...m1.entries()]` для `m1`:
        
        ```
        [[1, 1], [2, 2]]
        ```
        
3. **Создание `m3`**
    
    - `m3` создаётся как новый `Map` из объединения итераторов `m1.entries()` и `m2.entries()`.
    - С помощью оператора расширения `...` пары из обоих `Map` преобразуются в массив:
        
        ```
        [[1, 1], [2, 2], [3, 3], [4, 4]]
        ```
        
    - Затем `new Map()` использует этот массив для создания нового `Map`.
4. **Результат**
    
    - Новый объект `m3` содержит:
        
        ```
        1 → 1
        2 → 2
        3 → 3
        4 → 4
        ```
        

---

**Итоговый вывод:**

```javascript
console.log(m3);
// Map(4) { 1 => 1, 2 => 2, 3 => 3, 4 => 4 }
```

---

**Важные моменты:**

1. **Объединение нескольких `Map`:** Можно объединять несколько `Map`, используя комбинацию `entries()` и оператора расширения `...`:
    
    ```javascript
    const m3 = new Map([...m1.entries(), ...m2.entries()]);
    ```
    
2. **Повторяющиеся ключи:** Если в объединяемых `Map` есть одинаковые ключи, значения из последнего `Map` в массиве перезапишут предыдущие:
    
    ```javascript
    const m1 = new Map([[1, 'a'], [2, 'b']]);
    const m2 = new Map([[2, 'x'], [3, 'y']]);
    
    const m3 = new Map([...m1.entries(), ...m2.entries()]);
    console.log(m3);
    // Map(3) { 1 => 'a', 2 => 'x', 3 => 'y' }
    ```
    
3. **Альтернатива без `.entries()`:** Можно использовать напрямую `...m1` и `...m2`, так как `Map` поддерживает итерацию:
    
    ```javascript
    const m3 = new Map([...m1, ...m2]);
    ```
    

Этот способ проще и также работает корректно.
