[Set](../Работа/Set)

На изображении представлен пример работы с объектами, оператором расширения `...` и использованием `Set`.

---

**Код из изображения:**

```javascript
const a = { a: 1 };
const b = a;
const c = { ...b };
const d = c;
const e = { a: 1 };

const s = new Set([a, b, c, d, e]);

console.log([...s]);
```

---

**Разбор кода:**

1. **`const a = { a: 1 };`**
    
    - Создается объект `a` с единственным свойством `a: 1`.
2. **`const b = a;`**
    
    - Переменная `b` ссылается на тот же объект, что и `a`. Это одна и та же ссылка в памяти.
3. **`const c = { ...b };`**
    
    - Используется оператор расширения `...`, который создаёт новый объект с копией свойств объекта `b`. Теперь `c` — это новый объект, но с теми же значениями.
4. **`const d = c;`**
    
    - Переменная `d` ссылается на тот же объект, что и `c`. Это одна и та же ссылка в памяти.
5. **`const e = { a: 1 };`**
    
    - Создается новый объект `e` с таким же значением свойства, как у `a`, но это **новая ссылка в памяти**.

---

**Работа `Set`:**

`Set` — это структура данных, которая хранит **уникальные значения**. При добавлении объектов в `Set` сравнивается их ссылка, а не содержимое.

```javascript
const s = new Set([a, b, c, d, e]);
```

- `a` добавляется в `Set`.
- `b` не добавляется, так как это та же ссылка, что и `a`.
- `c` добавляется, так как это новый объект.
- `d` не добавляется, так как это та же ссылка, что и `c`.
- `e` добавляется, так как это новый объект.

---

**Итоговый вывод:**

При вызове `console.log([...s])`:

- Результат: `[ { a: 1 }, { a: 1 }, { a: 1 } ]`

Элементы `Set`:

1. Первый объект `{ a: 1 }` — это `a` (и `b`).
2. Второй объект `{ a: 1 }` — это `c` (и `d`).
3. Третий объект `{ a: 1 }` — это `e`.

---

**Объяснение:**

Объекты в JavaScript сравниваются по ссылке, а не по значению. Поэтому, несмотря на то, что объекты `a`, `c` и `e` содержат одинаковые данные, они имеют разные ссылки в памяти, и `Set` считает их уникальными.
