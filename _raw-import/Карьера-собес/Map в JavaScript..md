На изображении представлен пример работы с объектом `Map` в JavaScript.

---

**Код из изображения:**

```javascript
const m1 = new Map();
m1.set(1, 1);
m1.set(2, 2);

const m2 = new Map();
m2.set(3, 3);
m2.set(4, 4);
```

---

**Разбор кода:**

1. **Создание объекта `Map`**
    
    ```javascript
    const m1 = new Map();
    ```
    
    - `Map` — это структура данных в JavaScript, которая хранит пары ключ-значение.
    - В отличие от объектов `{}`, в `Map` ключами могут быть **любые типы данных** (например, числа, строки, объекты).
2. **Добавление элементов в `Map` с помощью `set`**
    
    ```javascript
    m1.set(1, 1);
    m1.set(2, 2);
    ```
    
    - Метод `.set(key, value)` добавляет новую пару ключ-значение в объект `Map`.
    - Здесь добавляются два ключа `1` и `2` с соответствующими значениями `1` и `2`.
3. **Создание второго объекта `Map`**
    
    ```javascript
    const m2 = new Map();
    ```
    
    - Создается новый независимый объект `Map`.
4. **Добавление элементов в `m2`**
    
    ```javascript
    m2.set(3, 3);
    m2.set(4, 4);
    ```
    
    - Аналогично, в `m2` добавляются пары ключ-значение: `3 → 3` и `4 → 4`.

---

**Что хранится в `m1` и `m2`?**

- **`m1` содержит:**
    
    ```
    1 → 1
    2 → 2
    ```
    
- **`m2` содержит:**
    
    ```
    3 → 3
    4 → 4
    ```
    

---

**Дополнительные операции с `Map`:**

**1. **Получение значения по ключу****

```javascript
console.log(m1.get(1)); // 1
console.log(m2.get(4)); // 4
```

**2. **Проверка наличия ключа****

```javascript
console.log(m1.has(2)); // true
console.log(m2.has(5)); // false
```

**3. **Удаление элемента****

```javascript
m1.delete(1);
console.log(m1.has(1)); // false
```

**4. **Размер карты****

```javascript
console.log(m1.size); // Размер объекта m1
console.log(m2.size); // Размер объекта m2
```

**5. **Итерация по `Map`****

```javascript
for (const [key, value] of m1) {
    console.log(`Key: ${key}, Value: ${value}`);
}
```

---

**Итог:**

Объекты `Map` полезны для хранения данных, где ключи могут быть любыми типами. В данном коде `m1` и `m2` являются независимыми объектами, каждый из которых хранит свои пары ключ-значение.
