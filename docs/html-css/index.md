# HTML / CSS

Основа любого интерфейса. HTML — структура и семантика, CSS — визуальное представление. Современный CSS включает Grid, Container Queries, `clamp()`, cascade layers и custom properties.

- [БЭМ](/html-css/bem) — методология именования классов, Block / Element / Modifier
- [Псевдоклассы / элементы](/html-css/pseudo) — `::before/::after`, `:nth-child`, `:has`, `:is`, порядок LVHA
- [Адаптивность](/html-css/responsive) — media queries, mobile-first, `rem/em/vw`, `clamp()`, Container Queries
- [Анимации](/html-css/animation) — `transition`, `@keyframes`, `will-change`, техника FLIP
- [DOM / CSSOM](/html-css/dom-cssom) — Critical Rendering Path, Reflow/Repaint, архитектура браузера
