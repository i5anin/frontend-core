# SPA, CSR, SSG, SSR

## CSR — Client Side Rendering

```
Сервер:           HTML (пустой)    JS bundle
                      ↓                ↓
Браузер:    [пустая страница] → [загрузка JS] → [рендеринг]
                                   ~3-5 сек
```

**Как работает:**
1. Сервер отдаёт минимальный HTML + большой JS
2. Браузер загружает и выполняет JS
3. React/Vue рендерит страницу

**Плюсы:** интерактивность, быстрые переходы после загрузки  
**Минусы:** плохо для SEO, медленный первый рендер (FCP)  
**Примеры:** CRA (Create React App), Vue CLI

---

## SSR — Server Side Rendering

```
Запрос → Сервер генерирует HTML → Браузер получает готовую страницу
              ~100-300ms                    + гидратация JS
```

**Как работает:**
1. Браузер запрашивает страницу
2. Сервер рендерит HTML (с данными)
3. Браузер показывает контент сразу
4. JS "гидратирует" страницу (делает интерактивной)

**Плюсы:** хорошо для SEO, быстрый FCP  
**Минусы:** нагрузка на сервер, сложнее деплой  
**Примеры:** Next.js, Nuxt.js

---

## SSG — Static Site Generation

```
Время сборки:  данные + шаблоны → HTML файлы
Деплой:        HTML на CDN
Запрос:        отдаётся сразу из CDN (~10ms)
```

**Как работает:**
1. При сборке (`build`) генерируются все HTML страницы
2. Деплоятся на CDN
3. Запрос — мгновенный ответ

**Плюсы:** максимальная скорость, дешёвый хостинг, SEO  
**Минусы:** нужно перестраивать при изменении данных  
**Примеры:** Gatsby, VitePress, Astro

## Гибридные подходы

### ISR — Incremental Static Regeneration (Next.js)
```js
// Страница генерируется статически, но обновляется по времени
export async function getStaticProps() {
  const data = await fetchData();
  return {
    props: { data },
    revalidate: 60 // пересобрать через 60 секунд
  };
}
```

### Partial Hydration / Islands Architecture
- Статический HTML с "островками" интерактивности
- Только нужные компоненты гидратируются
- Примеры: Astro, Fresh

## SPA — Single Page Application

```
Первая загрузка: HTML + весь JS
Навигация:       JS меняет контент без перезагрузки
URL:             History API (pushState)
```

**Маршрутизация на клиенте:**
```js
// Vue Router
const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About }
];
// Клик по <router-link> → не перезагружает страницу
```

## Когда что использовать

| Тип | Когда |
|-----|-------|
| **CSR** | Дашборды, внутренние инструменты, SaaS без SEO |
| **SSR** | E-commerce, новости, соцсети (SEO важен + динамичные данные) |
| **SSG** | Блоги, документация, лендинги (контент редко меняется) |
| **ISR** | E-commerce (SEO + регулярное обновление цен/товаров) |

## Метрики производительности

```
FCP  — First Contentful Paint   (когда появляется первый контент)
LCP  — Largest Contentful Paint (главный контент загружен)
FID  — First Input Delay        (задержка на первое взаимодействие)
CLS  — Cumulative Layout Shift  (насколько прыгает layout)
TTFB — Time To First Byte       (время до первого байта от сервера)

Core Web Vitals (Google):
  LCP < 2.5s  ✅
  FID < 100ms ✅
  CLS < 0.1   ✅
```
