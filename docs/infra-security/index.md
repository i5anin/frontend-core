# Инфраструктура и безопасность

Инфраструктура обеспечивает доставку и стабильность приложения. Безопасность защищает пользователей и данные. Обе области неразрывно связаны в современной разработке.

---

**Разделы:**

- [GitLab](/infra-security/gitlab) — Git workflow, Conventional Commits, GitLab CI/CD, Git Flow, HotFix
- [Сборка](/infra-security/build) — Webpack vs Vite, Tree Shaking, Code Splitting, Bundle analyzer
- [Конфиги сборки](/infra-security/config) — `.env` файлы, алиасы путей, ESLint/Prettier, Husky, `tsconfig.json`
- [Auth](/infra-security/auth) — JWT, Access/Refresh токены, OAuth 2.0, PKCE, сессии
- [Client Security](/infra-security/security) — XSS, CSRF, CORS, HTTPS, CSP, SameSite cookies, SRI
