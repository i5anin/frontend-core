# TypeScript

TypeScript — надстройка над JavaScript со статической типизацией. Даёт автодополнение, проверку типов на этапе компиляции и самодокументирование интерфейсов.

> 📘 [Официальный TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)

---

**Разделы:**

- [Типы данных](/typescript/data-types) — `any`, `unknown`, `never`, `tuple`, `enum`, discriminated union, `Readonly`
- [Union / Intersection](/typescript/types) — type narrowing, type guards, `keyof`, `typeof`, `as`
- [Интерфейсы](/typescript/interfaces) — `interface` vs `type`, `extends`, declaration merging, utility types
- [Дженерики](/typescript/generics) — `<T>`, constraints, conditional types, mapped types, `infer`
