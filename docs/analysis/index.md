# Анализ и проектирование

Фундамент разработки: сначала понять задачу, потом спроектировать решение, затем реализовать. Этот порядок снижает стоимость ошибок на порядок.

---

**Разделы:**

- [Анализ задачи](/analysis/task) — входные/выходные данные, уточняющие вопросы, edge cases, DoD
- [Декомпозиция](/analysis/decomposition) — Story Points, разбивка крупных задач, критерии готовности
- [Проектирование](/analysis/design) — FSD, Atomic Design, State Management, Repository Pattern, UML
