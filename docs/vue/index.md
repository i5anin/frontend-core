# Vue 3

Прогрессивный фреймворк для построения UI. Vue 3 основан на реактивности через `Proxy`, поддерживает Composition API, TypeScript, Teleport, Suspense и Fragments.

---

**Разделы:**

- [Options API](/vue/options-api) — `data`, `computed`, `methods`, `watch`, lifecycle hooks, `v-model`
- [Composition API](/vue/composition-api) — `setup`, `ref`/`reactive`, `watch`/`watchEffect`, composables
- [Компоненты](/vue/components) — props, emits, `v-model`, async components, Teleport, dynamic import
- [Слоты](/vue/slots) — default, named, scoped slots, `useSlots()`, renderless components
- [Provide / Inject](/vue/provide-inject) — реактивный provide, Symbol ключи, замена props drilling
- [Render](/vue/render) — render functions, `h()`, JSX, functional components, `v-once`
- [Store](/vue/store) — Pinia: `defineStore`, actions, getters, Composition API store
- [Router](/vue/router) — routes, navigation guards, lazy loading, `meta`, query параметры
- [i18n](/vue/i18n) — `vue-i18n`, `useI18n()`, lazy loading переводов, форматирование дат/чисел
