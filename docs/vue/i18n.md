# i18n — Локализация

## Установка vue-i18n

```bash
npm install vue-i18n@9
```

```js
// i18n.js
import { createI18n } from 'vue-i18n';

const i18n = createI18n({
  locale: 'ru',
  fallbackLocale: 'en',
  messages: {
    ru: {
      hello: 'Привет, {name}!',
      nav: { home: 'Главная', about: 'О нас' },
      items: 'нет предметов | {n} предмет | {n} предмета | {n} предметов'
    },
    en: {
      hello: 'Hello, {name}!',
      nav: { home: 'Home', about: 'About' },
      items: 'no items | {n} item | {n} items'
    }
  }
});

export default i18n;
```

```js
// main.js
import { createApp } from 'vue';
import App from './App.vue';
import i18n from './i18n';

createApp(App).use(i18n).mount('#app');
```

## Использование в компоненте

```html
<template>
  <div>
    <!-- t() — перевод -->
    <h1>{{ $t('hello', { name: 'Alice' }) }}</h1>

    <!-- Вложенные ключи -->
    <nav>
      <a>{{ $t('nav.home') }}</a>
      <a>{{ $t('nav.about') }}</a>
    </nav>

    <!-- Pluralization -->
    <p>{{ $tc('items', 0) }}</p>  <!-- нет предметов -->
    <p>{{ $tc('items', 1) }}</p>  <!-- 1 предмет -->
    <p>{{ $tc('items', 5) }}</p>  <!-- 5 предметов -->
  </div>
</template>
```

## Composition API

```js
import { useI18n } from 'vue-i18n';

export default {
  setup() {
    const { t, locale, availableLocales } = useI18n();

    function switchLocale(lang) {
      locale.value = lang;
    }

    return { t, locale, switchLocale, availableLocales };
  }
};
```

## Переключение языка

```html
<template>
  <div>
    <button
      v-for="lang in ['ru', 'en', 'de']"
      :key="lang"
      :class="{ active: locale === lang }"
      @click="locale = lang"
    >
      {{ lang.toUpperCase() }}
    </button>
  </div>
</template>

<script setup>
import { useI18n } from 'vue-i18n';
const { locale } = useI18n();
</script>
```

## Ленивая загрузка переводов

```js
// Загружать только нужный язык
const i18n = createI18n({
  locale: 'ru',
  fallbackLocale: 'en'
});

async function loadLocale(locale) {
  const messages = await import(`./locales/${locale}.json`);
  i18n.global.setLocaleMessage(locale, messages.default);
  i18n.global.locale.value = locale;
}
```

## Форматирование дат и чисел

```js
const i18n = createI18n({
  locale: 'ru',
  datetimeFormats: {
    ru: {
      short: { day: 'numeric', month: 'short', year: 'numeric' },
      long: { weekday: 'long', day: 'numeric', month: 'long' }
    }
  },
  numberFormats: {
    ru: {
      currency: { style: 'currency', currency: 'RUB' }
    }
  }
});
```

```html
<p>{{ $d(new Date(), 'short') }}</p>  <!-- 12 апр. 2024 -->
<p>{{ $n(1234.56, 'currency') }}</p>  <!-- 1 234,56 ₽ -->
```
